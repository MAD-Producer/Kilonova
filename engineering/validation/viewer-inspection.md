# 查看器通道、快照与预览区域验证

本改动让每个查看器独立选择彩色或 R/G/B/A 显示、捕获并保存 PNG 快照、对比快照和当前画面，以及选择或清除预览区域。区域仅影响预览，导出保持完整画面；这些状态不进入工程或撤销历史。跨工程、合成或图形设备的快照会失效，关闭浮窗会释放该窗快照。快照捕获与保存由现有工作线程执行，不新增重试。

## 证据与限制

- 旧着色器负对照在 Alpha 检查时输出透明像素；修复后的真实 GPU 测试覆盖四种表面格式、四种通道、彩色恢复和导航变换。额外渲染测试覆盖区域切换后的清理、快照资源租约和分割比较。
- 提交 `4521c7ac` 的 Windows 原生测试通过了 14 项参考线单元测试，以及主窗和浮窗的双语通道像素、参考线和快照保存/比较、旧快照失效与实际失败日志。独立的四项区域状态测试覆盖规范化坐标、失焦取消、跨窗口取消、窗口与设备身份及拖动释放的输入归属。这些结果来自合并主分支前的版本；整合后的结果须另行记录。
- 测试提交 `1892b7f4` 的实际菜单测试在浮窗坐标 `0.25000003` 与精确 `0.25` 的比较处失败；已按浮点坐标使用明确的 `1e-6` 容差，后续结果以对应回执为准。界面保存对话框的原生用户操作尚未自动验证；命令路径测试单独检查菜单动作及 PNG 工作线程。
- 合并主分支后的首次桌面测试编译因新增的九处原生测试夹具缺少查看器字段而失败，未执行测试；补齐默认状态后，`b3592c01` 上的 14 项参考线测试、4 项区域状态测试、4 项效果取样测试和三个 Windows 原生窗口测试均通过。原生通道测试从菜单实际发出捕获、比较、保存和选择区域的动作，并验证 PNG 和像素，覆盖 900×600、1600×1000 和浮窗、1×/1.5×/2× 缩放以及中英文；保存对话框本身仍未自动操作。
- 在相同代码上，`motion-render` 的 `presentation`（8 项）和 `sdr_preview`（6 项）GPU 测试全部通过，涵盖 `raw_viewer_channels_keep_alpha_intensity_and_leave_color_and_source_unchanged`、`retained_inspection_in_normal_present_clears_old_pixels_and_keeps_snapshot`、`viewer_snapshot_is_independent_and_refusal_keeps_previous_pixels` 及 SDR 快照资源复用。运行期间仅添加验证文档，未改变测试代码。检查了主窗最小/默认尺寸和浮窗的区域截图；未留存检查菜单展开截图。
- 增加默认窗口尺寸后的首次测试错误地假定缩放后比较开关为关闭状态；实际该状态属于窗口并会保留。重测先验证开关改变原状态，再验证开启后的像素；失败回执保留。
- 快照与区域仅驻留界面/呈现状态，原生测试比较项目 JSON、修订、撤销/重做状态和导出 PNG；不声称已覆盖所有工程格式或所有设备。正常取消对话框和失焦不作为故障；捕获/保存实际失败由工作线程记录到默认日志和 stderr，并检查 stdout 隔离。
