## 问题与原实现对照

`Track::sample` 原来直接返回值，分离轴重建依赖 `expect("validated vector dimensions")`。公开 `Tween` 允许一种值类型只接受整数分量、混合时四舍五入。其向量关键帧及拆分后的存储都能通过现有验证，但在 5.5 帧对拆分轴采样时无法重建该类型，原 API 实际 panic。单独探针调用旧构建的真实模型库验证了该现象；没有修改仓库源文件，没有 GPU，也不声称它是普通 GUI 内置浮点类型的复现。

原始证据保存在仓库外 `artifacts/pr-ci-followups/animation-sampling-baseline-probe-*`：库、探针和模型源 SHA-256、实际 panic stderr、成功退出的对照收据。第一次编译探针因未载入 MSVC 的 link.exe 环境失败；随后载入既有环境后编译成功。环境失败与产品 panic 分开记录，均保留原始日志。

## 功能边界

| 编号 | 本批处理 | 实际边界 |
|---|---|---|
| A1 | `Track::sample` / 内部采样返回模型 `Result` | 不可重建的中间值、向量键与分离轴混存、轴中继续嵌套轴返回有类型的原始错误，包含阶段、帧、键数和最多 128 字符的类型名；不制造采样值。 |
| A2 | 模型几何、摄影机、音频、效果、矢量与核心编辑传播 `?` | 调用方不得继续使用一个伪造的零值；当前批次不等于审计完所有模型 panic。 |
| A3 | Scene 构造和宿主切换 | 初始摄影机可失败；宿主先构造新 Scene，再提交活动上下文，失败不留下半切换。组合构造使用实际组合视图，不为初始化复制整个工程。 |
| A4 | 表达式原生原因 | 采样进入 JS 前直接传播；回调失败保留首个原始模型原因，以 `ExpressionSampling` 的 source 返回。既有其他 JS 错误仍有字符串边界，不宣称整个表达式引擎已类型化。 |
| A5 | 旧桌面媒体 API | 在既有 String 边界显式转字符串；不宣称越过此协议仍保留原生身份。 |
| A6 | 属性、图表和编辑交互 | 使用既有 `observe!` 记录失败并拒绝无效编辑或图表；失败的效果参数仍占原行，后续属性保留位置。图表先收集 `Result`，不把失败点绘制成零值。 |

正常语义保留：NaN 时间仍返回静态值，正负无穷仍取端点；上层宿主继续负责拒绝无效时间。已有非有限采样值仍按原合同返回原值并触发现有模型观察器，不能借本次迁移悄悄改成钳制或默认值。常规 cache miss、取消和无关键帧不是本批新故障。

## 观察与信道

新采样错误交给现有宿主回复和日志设施；不在模型热路径另加文件 IO。桌面 `observe!` 和模型非有限值观察器的计数均沿用既有的**固定调用点、进程生命周期累计**策略：饱和递增，首次 Warn、累计第 60 次 Error，健康邻居不重置另一个坏行的计数。它不是连续失败计数，也不能将 60 次叫作一秒。

新增模型用例覆盖真实泛型拒绝、错误存储、失败不变性、健康采样恢复和 RawTrack 维度拒绝。新增桌面子进程用例已在默认日志级别通过真实采样错误检查宿主的原生 Model 变体、回复、文件日志、Error stderr 和 stdout 隔离；独立保留三条原始原因、文件与 stderr 各三条 Error，stdout 无故障输出。它使用手动 Flight 上下文，**不能证明完整 Engine worker 调度或真实 UI 注入**。

## 首轮 macOS CI 的对齐夹具失败
