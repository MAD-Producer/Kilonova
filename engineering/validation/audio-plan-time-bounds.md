# 音频规划的时间边界校验

Refs #131、#138。直接调用 `Project::audio_voices` 时，畸形的内存模型原先可以绕过工程导入校验：NaN 经浮点到整数转换后变成合法采样边界，反向区间变成空音轨，超范围的帧率或时长也可能返回音轨列表。本批在换算前复用已有区间校验，并校验实际进入的根合成和子合成时钟。

不改变合法区间的取整、48 kHz 时间基、源偏移、嵌套比例和音量语义；静音或合法的不可见区间仍是正常分支。没有更改工程格式、渲染语义、资产或依赖。

| 项目 | 处置与边界 |
| --- | --- |
| A1：新增校验 | 整数裁剪先验证顺序、范围和局部时间偏移；精确裁剪先验证有限值、顺序、范围与整数包络。错误发生在空区间跳过和采样换算之前，不返回部分规划结果。 |
| A2：时钟 | 根合成及进入的子合成遵循既有模型的 fps/frames 上限。零根帧率继续使用 `invalid_frame_rate` 原协议；子合成在参与偏移换算前检查，避免零时钟进入除法。 |
| A3：原始原因 | 新增 `AudioTimeline` 原生错误包装，保留合成、图层、阶段和声明的 `Box<Error>` 原因，不把原始 `Invalid` 字符串化。包装中的合成上下文最多保留 64 字符，与合法合成 ID 上限一致。原有有理数运算预算与 `audio_time_limit` 协议保持；不认领该既有包装的全面错误身份整改。 |
| A4：正常路径 | 已验证的负起点、小数裁剪和负偏移仍得到 begin/end/offset = 0/2000/-1600；合法的时间范围外音轨和静音不报错。所有查询保持输入不变。 |
| A5：可观测性边界 | 没有新增日志点、工作线程、重试或默认错误信道协议。这里是模型库的返回错误，调用方已有混音、宿主快照和导出边界负责转交；混音入口本来就先调用完整 `validate`，不把这组直接内存调用冒充真实媒体文件或桌面默认 file/stderr/stdout 的新验收。 |
| A6：合集范围 | 本批不证明任意编码媒体的畸形时间戳、第三方解码器、缓存可见性或线程退出。#131 和 #138 的广义验收继续保留，不关闭合集或提前勾选对应大项。 |

## 回归证据

四项测试覆盖根/嵌套精确区间的 16 组非法值、三组非法整数区间/偏移、八组合成时钟/时长边界，以及正常音轨的精确样本与静音。错误原因通过实际 `source()` 及原生 `Box<Error>` 下转检查，查询前后数据保持一致；NaN 的原始位也保持。

最终同一夹具在旧实现真实执行为一项正常用例通过、三项非法输入用例失败；修正后四项通过。原始输出与输入摘要保存在 `artifacts/pr-ci-followups/audio-time-regression-before-final.*`、`-after-final.*`，旧源码对照结束后按字节恢复修正，未修改产品或既有断言来获得通过。

完整模型回归、五个实际音频编辑/合成测试目标和三个混音测试目标全部通过，保留一项既有忽略。收据 `audio-time-final-validation.json` 逐阶段记录命令、日志摘要和源码不变性。独立四项回归与完整模型运行中的相同测试不重复计数。上述验证基于 `00627cdb`，与最新主线的组合和远端 CI 另行验证，不把独立工作树结果改称最终组合验收。

保留新测试初稿的两个错误：音轨误带空间属性导致四项夹具初始化失败；随后把 `thiserror` 明确保留的 `Box<Error>` 误当作直接 `Error` 下转，导致两项错误身份断言失败。只修正本批新夹具和原生包装的检查方式，继续要求明确的原生错误类型；不把这两轮失败当作原产品缺陷。正常范围外夹具另外设置合法源偏移并执行完整模型校验。
