# 受管预览取色的颜色端点

本批继续 #83。普通 `sample_view_cell` 对受管工程读取已发布工作图像的一个
Float32 像素，再返回工程声明的 authored_input 空间、范围与 Alpha 约定。
显示变换、检查通道、ROI 与 UI 遮罩不进入参数颜色；不修改面板或渲染语义。

| 编号 | 分类与处置 | 证据与限制 |
| --- | --- | --- |
| MCP-01 | 功能 | 从完整已呈现组读取一个 texel；保持完整配置/工作空间/范围/Alpha/精度身份。不是从 SDR8 显示图像反解颜色 |
| MCP-02 | 明确创作端点 | working→authored_input 使用原生 OCIO CPU 处理器；不能替换成 default_input 或工程 output。先解工作 premult，再转换、编码创作范围，并按创作 Alpha 约定输出；保留负值和超一值 |
| MCP-03 | 正常分支 | 未附着、没有已发布组、过期帧/视图/质量/窗口身份返回正常 None；全透明 premult 像素没有可恢复的 RGB，返回创作黑电平及零 Alpha |
| MCP-04 | 功能边界 | 首次非透明的明确取色操作才准备反向处理器，成功或失败均在独占 sampler 内缓存；新工程/合成 owner 重建时重置。打开工程和 Present 不要求反向处理器可用；没有自动重试或 native handle 克隆 |
| MCP-05 | 既有错误信道 | 反向准备/执行保留类型化原始 native cause，GPU 分配、提交、poll、回读映射错误直接传播；宿主补充工程代次、修订、owner、cell、帧和阶段。无新日志 sink、stdout、文件 IO 或 Present 日志。调用仍须处于既有显式非 Present worker 的 start/in-flight 范围 |
| MCP-06 | 错误与负对照 | 实际错误输入验证空间、范围、Alpha、精度、非有限值和除法溢出的原始 native admission；越界 texel、错误设备和半精度目标在回读前拒绝。旧断言未放宽；映射设备故障与阻塞不是本批新造故障的覆盖声明 |
| MCP-07 | 真实 GPU | 固定 CPU golden 的 144 组完整/受限范围取色往返，包含创作空间与默认输入不同的工程；实际单 texel 值不量化。另有二维坐标、负值/超一值/透明像素的精确存储对照；回读 payload 为 16 字节、staging 为 256 字节 |
| MCP-08 | 实际窗口 | 单/双/四视图在通道/ROI 检查开启时返回同一创作值；错误 owner、过期 clock/view、空视图与非法坐标不增加回读次数。取色不触发重新渲染，工程完整 JSON 不变 |
| MCP-09 | 桌面保护 | 受管预览缺失时禁止回退到旧 scratch；返回 preview_pending。效果消费者本身仍受已有 managed admission 约束，本批不宣称已经支持受管效果渲染或完整用户可见取色流程 |
| MCP-10 | 未完成与基线 | 不修改依赖、资产、UI token、工程格式、效果包或已有像素 golden；DESIGN §0.7 各项保留。此前原生异常、其他消费者/输出和 #83 的剩余资格仍未完成，不能关闭 issue 或将 PR 标为就绪 |
