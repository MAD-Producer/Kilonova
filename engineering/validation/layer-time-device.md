# 图层时间映射：真实音频设备验收

新增显式忽略的硬件用例，通过 `AudioOutput::start`、实际混音线程及 CPAL 原生设备回调验证正向二倍速、半速、倒放、冻结、往返重映射和 30→60 fps 嵌套倒放。没有替换生产混音器或设备回调，没有修改生产行为或既有断言。

## 结果与边界

Windows 本机实际输出设备使用 48 kHz。六种场景均消费 24,000 帧 PCM，设备播放头单调到达合成第 15 帧，underrun 为零，无设备错误；实际回调测量的双声道峰值符合夹具预期，冻结输出严格为零。峰值允许 0.0001 的绝对误差，覆盖插值和受支持整数设备格式的量化，不调整生产阈值。嵌套场景还验证父子音量相乘。

这证明真实设备回调消费了映射后的信号，不等于对物理扬声器录音的逐样本比较。半速场景的峰值不能单独区分半速与普通速度；精确源采样地址继续由既有离线 `layer_time_audio` 用例负责，不把峰值报告当作逐样本映射的替代证据。高速自适应低通与其他操作系统／硬件尚未在本轮验证。

同一最终测试二进制运行 `audio_output::`：27 项通过、2 项显式硬件用例忽略；随后新增硬件用例以完整名称和 `--ignored` 单独通过。音频回归包含既有真实 PCM 读取失败、受控阻塞开始信号、默认文件日志／Error stderr／stdout 隔离、panic／设备失效和恢复验证。新硬件用例另验证六次默认 Info 开始记录及日志中无 Error，不为健康回调添加日志。

源码、二进制 SHA-256、逐场景设备报告和原始输出保存在[证据清单](layer-time-device-evidence/manifest.json)与[证据包](layer-time-device-evidence/evidence.zip)。新硬件用例默认忽略，避免让无声卡 CI 的测试结果取决于是否安装设备；只有实际显式运行结果计入硬件验收。
