# 时间轴隐藏标记与列表筛选验收

关联 #256。分支 `feat/timeline-shy-layers` 基于 `97842545`，检查开放 PR 和本地分支后未发现重复实现。其他线程正在处理节点绘制查找和图形裁剪，本分支未接管这些工作。

## 实际行为

- 图层行增加 Shy 隐藏标记，复用原有 Checkbox、Minimize 图标、完整 `icon.slot`、行高和状态样式；工具条同图标控制隐藏已标记行。中英文提示明确“列表组织，不影响渲染”。无新增依赖、第三方素材或复制界面资源。
- `Layer.shy` 与 `visible` 分离；`SetLayerShy` 走已有原子编辑、版本检查、撤销及默认错误信道。锁定图层拒绝修改，缺失 ID 返回原始对象错误。图层类型不限制该组织标记。
- 工程显式保存 `shy`，当前版本由 23 升为 24，只接受当前版本，未增加默认补值或迁移。`timeline_hide_shy` 是工作区偏好，缺失时不隐藏；总开关不会写入工程撤销栈。
- 时间轴搜索、全选、追加范围选择、上下导航和关键帧导航跳过隐藏行。隐藏当前时间轴选择时整理选择及轨道上下文，其他面板不会绘制旧选择一帧。合成画布仍能选中、编辑已标记图层；此时不会因为时间轴隐藏而丢失画布选择。
- 拖动排序以完整图层栈的稳定 ID 解析插入位置，保留隐藏图层的相对顺序。隐藏只投影列表，父级、效果、图层数量、可见性、采样与最终输出不变。关闭总开关可以找回全部标记行。
