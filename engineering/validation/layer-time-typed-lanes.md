# #257：普通时间轴的类型化局部关键帧

本阶段继续 `feat/layer-time-mapping`，基于 `ecd56ea6`。音频策略按用户确认采用
音高随速度变化。**#257 未完成，不关闭 issue。** 开工核对时唯一开放 PR #575
负责原生预渲染，不修改其分支或审阅其改动。

## 功能边界

普通时间轴的蒙版标量/路径节点、平面矢量、分组矢量、效果标量/曲线参数和音频
左右声道，复用作者局部关键帧地址与共同时间格拖动。图层汇总和展开行使用同一
份投影缓存；伸缩和倒放后的半帧位置不转成整数地址。复用既有选中、预览、
碰撞、来源守卫和单事务撤销，保留原有点击容差和样式 token。

缓存键增加 document_generation，避免打开同路径、同 revision 的另一会话时继续
复用旧时钟。缺失 generation 的旧最小测试快照仍按既有 None 身份复用，不能将
此改动描述为所有缺失身份情况的全面拒绝。

平面矢量显示树的虚拟组变换、常量尺寸/位置和静态 miter 选项没有作者 Track，
正常发现时排除；已包装分组的真实同名动画轨道必须保留。损坏的真实轨道仍使
整行映射缓存失败，禁用该行关键帧编辑，不能退回整数监听或返回部分成功。

三次回归失败均未放宽断言。原始编译、失败回归和诊断原因随最终证据保留。
