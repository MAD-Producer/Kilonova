# 效果定义与参数顺序的借用访问（#134 增量）

基于 #600 堆叠。开始前核对开放 PR 和本地近期分支；#599 的 22 个文件不涉及本批，#587 的完整 411 文件列表包含 effect_controls.rs 和 effect_timeline.rs，本批只调整目录读取和参数遍历，不处理其图层时钟。修改后的精确提交合并检查尚待完成。

## 修改范围

此前效果面板计算高度、绘制效果以及时间轴绘制各属性行时，均克隆所命中效果的完整 JSON 定义；效果面板另收集引用 Vec 并稳定排序参数。现在从当前目录借用定义，在一次绘制内保留一个 Arc 目录句柄；参数以两个借用迭代器先普通、后曲线遍历，各组原顺序保持。不保留历史目录、不新增缓存或失效规则。

包 hash、插件 ID、版本和效果 ID 均沿用原来的精确比较与首匹配规则，包括第一个包匹配却没有效果时返回 None；不跳到后续同名包。曲线判断仍为 JSON 字符串精确等于 curve，其余类型沿用普通参数处理。不存在新参数类型、编辑命令、布局、颜色、尺寸、命中区或第三方依赖。

## 当前证据与边界

独立分配探针包含生产借用模块，单独安装计数 allocator，不修改桌面程序的分配器。四项测试通过：精确身份/首匹配、2187 种混合参数顺序及畸形元数据、目录替换与引用生命周期，以及 120 次访问的分配窗口。旧查找/排序按原生产实现保存为对照。

| 参数数 | 原查找克隆与排序，120 次分配请求 | 借用访问，120 次分配请求 |
|---|---:|---:|
| 0 | 480 | 0 |
| 1 | 1800 | 0 |
| 200 | 216720 | 0 |
| 2000 | 2160840 | 0 |

这些数字只覆盖目录查找、Arc 保活及参数遍历；不代表整个面板帧零分配、内存峰值或 FPS。夹具构造不计入窗口，旧流程非零同时验证计数器能捕获分配。

真实面板回归、与原生产路径的完整绘制对照、分配回归负对照及最终 CI 正在补齐，先提交草稿。首次构建发现时间轴仍调用旧方法，编译错误原样保留并修复；一次启动被本机 PowerShell 脚本签名策略拒绝，随后仅对本次 pwsh 子进程指定 ExecutionPolicy Bypass，未修改全局策略。
