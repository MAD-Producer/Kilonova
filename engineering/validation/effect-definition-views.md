## 修改范围

此前效果面板计算高度、绘制效果以及时间轴绘制各属性行时，均克隆所命中效果的完整 JSON 定义；效果面板另收集引用 Vec 并稳定排序参数。现在从当前目录借用定义，在一次绘制内保留一个 Arc 目录句柄；参数以两个借用迭代器先普通、后曲线遍历，各组原顺序保持。不保留历史目录、不新增缓存或失效规则。

包 hash、插件 ID、版本和效果 ID 均沿用原来的精确比较与首匹配规则，包括第一个包匹配却没有效果时返回 None；不跳到后续同名包。曲线判断仍为 JSON 字符串精确等于 curve，其余类型沿用普通参数处理。不存在新参数类型、编辑命令、布局、颜色、尺寸、命中区或第三方依赖。

## 当前证据与边界

独立分配探针包含生产借用模块，单独安装计数 allocator，不修改桌面程序的分配器。四项测试通过：精确身份/首匹配、2187 种混合参数顺序及畸形元数据、目录替换与引用生命周期，以及 120 次访问的分配窗口。旧查找/排序按原生产实现保存为对照。

| 参数数 | 原查找克隆与排序，120 次分配请求 | 借用访问，120 次分配请求 |
|---|---:|---:|
| 0 | 480 | 0 |
| 1 | 1800 | 0 |
| 200 | 216720 | 0 |
| 2000 | 2160840 | 0 |

这些数字只覆盖目录查找、Arc 保活及参数遍历；不代表整个面板帧零分配、内存峰值或 FPS。夹具构造不计入窗口，旧流程非零同时验证计数器能捕获分配。

真实面板回归 114 passed、0 failed、4 项既有手工原生验收 ignored，包括效果、动画、身份与效果时间轴模块；结合独立探针，去重共 118 项通过，其中本轮新增 5 项。没有把重复采集、对照或子进程重复计数。四个既有忽略标记与断言保持原样，范围与 #600 相同，不声称物理键鼠或全部 UI 验收已完成。

用同一真实面板用例分别执行优化路径及临时恢复的原生产入口：恢复 Controls::definition 的 JSON 克隆、原参数 Vec 稳定排序，以及时间轴原调用，断言不变。效果面板为中英文 × 220/420 宽度 × 折叠状态 8 组；时间轴为中英文 × 900/1400 宽度 × 主/浮动窗口 8 组。原目录及替换目录的 32 份完整 shapes/colors/glyphs/order/命中区记录一致，效果面板同时比较 y 与高度。16 组更换定义名称的对照均改变实际绘制，换回后恢复，没有编辑命令，工程快照不变。这是实际绘制指令对照，不冒充新增 GPU 像素或物理窗口截图验收。

另仅在生产参数迭代器中恢复原 Vec 收集与稳定排序，保留测试：零分配断言实际失败，单参数 120 次访问分配 120 次，退出 101。随后逐字节恢复源码并重新构建；正常路径再次通过。原生产绘制对照与分配负对照分开记录，前者应保持行为相同，后者应被性能断言拒绝。

带 FFmpeg 的正式桌面程序及测试程序编译通过；仅编译器使用 RUST_MIN_STACK=33554432，实际测试移除该设置。三个新增 Rust 文件 scoped rustfmt 与 git diff --check 通过，不扩大成全工作区格式验收。首次构建发现时间轴仍调用旧方法，编译错误原样保留并修复；一次启动被本机 PowerShell 脚本签名策略拒绝，随后仅对本次 pwsh 子进程指定 ExecutionPolicy Bypass，未修改全局策略。

[证据包](effect-definition-views-evidence/evidence.zip) 保存命令、原始编译失败、前后完整绘制、分配统计、负对照退出和恢复收据。[清单](effect-definition-views-evidence/manifest.json) 记录生产/测试源码及归档 SHA-256。当前最终提交的 CI 仍需独立验证，整个 #134 保持开放。
