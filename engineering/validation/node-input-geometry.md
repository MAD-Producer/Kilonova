## 变化与验证

之前，draw 在处理数值输入前无条件构建卡片，库添加、属性栏删除、工具栏撤销和返回父图随后使它失效，导致同帧重复解析端口。现在卡片按需构建：数值编辑及画布控件命中仍在原顺序读取旧几何，其余路径在工具栏、库和属性栏操作后构建最终文档几何。没有重排输入、延后提交、改变同帧布局区域，或跨帧保留卡片。

- 原生产路径配同一新增测试夹具，中英文、两种区域尺寸、四种实际操作共 16 组均构建两次，新计数回归实际 exit 101；其功能、撤销/重做和独立重建几何断言先全部执行成功。夹具最初一次编译遗漏显式打开库，未运行；补齐后才采集原路径运行证据。
- 优化后 16 组均只构建一次。前后 64 帧完整 shapes/colors/glyphs/order、响应、EditorSnapshot、undo 和 redo 长度逐项精确相等；没有删字段或归一化。
- 既有父图测试要求 `builds >= 2`，优化后实际失败。保留原失败，在完整功能对照通过后收紧为 `builds == 1`，父图、revision、preview_revision、view 和独立绘制几何断言全部保留，不是放宽验收以掩盖错误。
- 最终 **214 项不同的桌面定向测试通过**：节点编辑器 188、帧布局缓存 4、面板 13、Shell 输入事务 7、工作区成本 2；0 failed、0 ignored。独立探针与套件重叠，不重复计数。
- 视口/拖动记录器再次完成 312 帧，并与原视口优化前的完整记录精确相等。合计 376 帧输出与状态等价；不是像素截图、GPU Present 或全窗口视觉验收。
- 两条既有真实 Shell 工作负载分别覆盖 48 组稳定拖动和 48 次布局变化，原断言不变。面板 `frame_builds` 是 calculate_frames 计数，不能解释成全部底层求解调用。
- FFmpeg 测试与正式 dev 构建通过；独立 LOCALAPPDATA 下 `--command-list` exit 0，stdout 完整 JSON，stderr 空，运行时未覆盖 RUST_MIN_STACK。这不证明默认配置目录权限、原生窗口或 GPU 呈现。

逐项源码、原始失败、编译与完整对照哈希见 [manifest](node-input-geometry-evidence/manifest.json) 和 [证据包](node-input-geometry-evidence/evidence.zip)。manifest 同时区分本地编译输入字节与 Git 归一化 blob。正式程序哈希和精确命令保留在其中。

## 错误处理处置

| 条目 | 处置与证据 |
| --- | --- |
| NI-BUILD | 功能修正：只移除画布外操作之前无用的旧卡片构建；16 组实际输入及完整状态对照通过。 |
| NI-INLINE | 功能保持：活跃数值编辑和画布命中仍先构建其所需几何，保持提交、取消、弹窗和修饰键处理顺序；188 项节点回归通过。 |
| NI-OBSERVE | 既有覆盖：最终实际绘制的卡片仍经原有 sockets 观察路径；没有吞 Err、panic 或失败返回，没有新增热路径日志/文件 IO。 |
| NI-NORMAL | 正常分支：未物化的卡片属于尚未需要计算，不是失败；结构变化及身份失配仍执行原重建。 |
| NI-CI | 独立配置调整：#602 原 macOS 任务因超过 90 分钟被取消，详见 [CI 记录](ci-macos-line-tables.md)。测试与期限未改变，实际改善仍待新提交原生 CI。 |
| NI-PENDING | 整个 #134 仍开放：画布内结构变化帧、通用同帧求解上限、原生呈现、整帧耗时/峰值及最新 main 完整集成尚未完成。 |
