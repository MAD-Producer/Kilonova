# #252 逐关键帧速度、影响与区间插值的映射边界

接续 #218 的共享对话框和原子命令，明确已有模型能表达的内容，并验证真实采样及冻结输出。没有新增永久“连续”标记，没有修改采样器、工程版本、效果包或渲染语义。UI 与默认错误信道证据见 [#218 验收](keyframe-interpolation.md)。

## 精确定义

区间的缓动数据属于起始 key。选中中间 key 时，入侧对应前一区间的末端，出侧对应后一区间的起端。先合并同一区间的两侧计划，防止相邻多选的修改相互覆盖。

归一化时间为 `t`、时间进度为 `q(t)`、空间／属性插值为 `P(q)`，实际速度为：

`dP/ds = P'(q) × q'(t) × fps / (后键帧号 − 前键帧号)`。

| 表示 | 读数／编辑边界 |
|---|---|
| 进度三次贝塞尔 | 出侧斜率 `control1.y / control1.x`，入侧斜率 `(1 − control2.y) / (1 − control2.x)`。影响是对应时间横向距离乘 100；改变影响且未填速度时保留该侧原斜率，另一侧手柄精确保留。 |
| 进度二次贝塞尔 | 可无损升阶到三次表示，再编辑指定的一侧；不是任意重采样近似。 |
| 线性／二次／平滑预设 | 使用各自真实端点导数映射为进度三次曲线。该表示改变会保存在工程中，不冒称只改视图。 |
| 保持 | 存在跳变，没有可编辑的有限跨跳变速度；需要明确选择贝塞尔才能替换。不能把“0”读数理解为跳变处连续。 |
| 速度空间／弹性 | 使用模型真实采样器读取端点速度；替换整段函数需明确选择贝塞尔。端点导数相等不代表整段函数相同，不做隐式近似转换。 |
| 等值标量／无空间切线的等值向量 | 当前进度插值不能产生非零属性速度，非零请求原子拒绝；没有伪造手柄或值。 |
| 等端点空间环路 | 有非零空间切线时可有非零物理端点速度；端点位移平均为零，相对倍数的现有读数为空。倍数 1 仍只表示位移／时长，不表示环路弧长。 |
| 颜色曲线等非数值对象 | 可以调整归一化进度，不能声称存在 px/s 等物理速度。布尔／枚举只允许保持。 |

标量使用有符号速度；设置两侧相同物理速度可以匹配一阶导数，包括后一段端点值反向、需短暂超调的情况。向量物理速度是速率大小，保留已有方向；**相同速率只在空间方向也一致时才构成 C1 连续**。本次匹配之后再改单侧没有持续约束；独立入出侧就是当前模型的断开编辑语义。读数不会把值图／速度图切换混同于 `CurveSpace` 修改。

## 独立于读数的实际采样验证

新增四项测试直接调用生产 `Track::sample`，没有用 `timing::profile` 的返回值替代采样结论：

| ID | 实际场景与负面对照 |
|---|---|
| KB-01 | 不透明度三键，前段上升、后段下降；两侧设 10 %/s。相邻 0.01 帧的实际 f32 采样差分均在目标 ±0.1 %/s 内；原线性负面对照为大于 40、低于 −20。保存重开、撤销／重做的完整工程精确相等，重开后的采样读数完全相同。 |
| KB-02 | 不等时长向量区间均设 12 px/s。实际采样差分速率在目标 ±0.2 px/s 内；直线路径的两侧速度向量相近，直角路径的向量差仍大于 16 px/s。证明同速率不能修平空间拐角。 |
| KB-03 | 等值标量的保持与弹性表示。未明确转换时拒绝，明确转换但要求非零速度仍拒绝；选择零速度后全部实际采样保持原值。拒绝路径沿用完整工程／修订／撤销不变断言。 |
| KB-04 | 相同端点、非零空间切线的环路。相对速度无现有读数，物理 15 px/s 可以精确表达；实际端点附近差分在目标 ±0.2 px/s 内，两个已创作端点仍精确不变。 |

差分容差只覆盖有限步长截断与 f32 量化；没有对作者数据、持久化、相反手柄或整个工程引入容差。完整模型关键帧回归包含原有及新增用例；初始新增模块曾因 path 属性未指向子目录而编译失败，修正测试模块路径后四项通过，原失败日志保留。

## 真实冻结输出

手动 GPU／FFmpeg 测试实际生成并解码四段六帧 MP4：

1. 修改物理入出速度后冻结的工程。
2. 同一工程保存、重开后冻结的对照。
3. 未修改的线性插值负面对照。
4. 活动编辑器撤销、删除图层后冻结的负面对照。

冻结之后，活动编辑器已经撤销、删除图层并关闭会话。前两段的全部解码 RGBA 帧精确相等；中间帧与线性对照确有像素差，全部帧与删除图层对照确有像素差。不能用模型 JSON 一致代替输出一致，也不能用编码字节数代替像素结论。MP4 的帧数和总时长分别验证为 6 帧、200000 微秒。

```powershell
$env:MOTION_KEY_TIMING_MOVIE_ARTIFACTS = '<新的空证据目录>'
```
