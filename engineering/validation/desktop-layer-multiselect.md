# 图层多选与批量操作验证

关联 [issue #200](https://github.com/MAD-Producer/motion-studio/issues/200)。选择为共享桌面运行状态，不写入工程；图层、片段和效果编辑通过现有原子事务保存，支持单步撤销。锁定图层可以被选中，移动、复制、删除和效果添加会跳过它们；相机不加入图层批次。

## 可复现检查

使用三个普通图层，并锁定中间图层。在中文和英文界面各运行一次，随后将时间轴拆为原生浮窗重复操作。

1. 单击第一行，Shift 单击第三行：三行高亮，第三行成为主选。Shift 改点第二行：范围缩为前两行，起点保持第一行。Ctrl 单击切换成员，Ctrl+Shift 单击追加范围。点击空白后全部取消。
2. 时间轴或合成获得焦点后 Ctrl+A 全选；Ctrl+Shift+A 清空。节点、路径、曲线、关键帧、搜索框、数值编辑及输入法组合时，这些快捷键由各自上下文处理。
3. 全选后拖动未锁定图层条：可移动图层保持原来的时间偏移，锁定图层不变。松开后 Ctrl+Z 一步恢复。再次拖动后按 Esc，或使窗口失焦：所有移动目标恢复，手势结束。
4. Ctrl+D 生成未锁定图层的副本，Delete 删除未锁定目标；各自 Ctrl+Z 只需一步。删除主选后保留仍存在的成员；撤销后选择不会引用失效 ID。切换合成会清空选区，即使新合成使用相同 ID。
5. 从效果库、效果控件添加入口或效果搜索选择效果：未锁定目标收到同一批添加。选区含音频图层，或给调整图层添加非图像效果时，整批拒绝并提示原因，原有效果和撤销历史保持不变。
6. 保存并重开工程，核对复制、删除、片段位置和批量效果结果。重新打开时重新选择图层，选择状态不属于工程数据。

## 自动验证

```powershell
cargo test -p motion-desktop -p motion-host --locked -- --test-threads=1
```

`panels::selection_tests` 覆盖选择失效、合成 ID 重用、实际时间轴点击、主窗与浮窗快捷键、中英文语义、文本/输入法/节点/路径/关键帧隔离、批量复制删除的撤销与保存重开，以及实际时间轴拖动的提交与 Esc 取消。

宿主 `batch_effect_add_deduplicates_targets_and_roundtrips_with_one_step_undo` 和 `invalid_batch_effect_targets_fail_atomically_and_leave_history_unchanged` 覆盖真实内置效果、重复目标去重、保存重开、单步撤销重做，以及锁定、调整图层、音频、缺失 ID、空集合和非法目标输入的原子失败。

自动测试复用主窗和浮窗的输入路由及面板绘制路径；原生窗口拖动与系统失焦的目视检查按上面的步骤执行，不能将路由测试等同于完整原生窗口手动验证。
