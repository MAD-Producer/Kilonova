# 折叠与展开复用本帧节点规格（#134 增量）

基于 #603 的 `c14f20f5b157775b4ced4c8806f16e267fdba10a`，继续合批在同一 PR，不另建 PR。开始前及提交前核对其他开放 PR 的完整分页文件清单，当前没有 `desktop/app/src/node_editor/` 重叠；没有编辑其他分支或根工作树。

## 实现与边界

之前，点击节点折叠箭头后，非语义 revision 变化会使本帧卡片整体重建，端口规格重复解析。现在保留展开时的插口行位置、端口行数和当前折叠状态；折叠或展开后只更新高度、插口位置及可连接状态。普通视口变化继续复用高度，不额外扫描控件。

调用方先检查 epoch 和 preview revision；非语义 revision 可以复用，但必须先验证全部节点数量、顺序、ID 和源对象身份，全部符合后才修改任何卡片。语义变化仍重建。组插口改名虽不增加 preview revision，却会替换文档；实际测试验证它因身份变化而拒绝复用，保留原重建路径。指针只用于本次 draw 的身份比较，不解引用、不跨帧保存。

每个本帧 Card 增加一个 `usize` 行数及一个折叠状态字段，不宣称零内存开销。端口行数保留有效零端口与解析失败回退一行的原区别。尺寸、颜色、命中容差、输入顺序、提交及撤销语义没有改变。

## 证据

- 同一新增夹具先运行原生产路径：中英文、两种面板尺寸、两种缩放和普通／默认输入／组节点共 24 组配置，48 次实际折叠与展开都构建两套卡片，卡片端口规格解析次数均为节点数的两倍。功能、撤销／重做及独立重建几何断言先执行成功，新的单次计数断言实际 exit 101。没有改既有断言来获得通过。
- 优化后同样 48 次操作都只构建一套卡片、每个节点解析一次卡片规格。216 帧完整 shapes/colors/glyphs/order、响应、EditorSnapshot、undo 和 redo 长度与原路径精确一致，没有删字段或归一化。
- 所有内置示例，加有效零端口和有意缺失参数的端口形状，在三种缩放下的折叠／展开几何均与完整重建相同。源身份损坏的负对照验证拒绝前不会部分更新。组端口改名负对照验证非语义文档替换仍被拒绝。
- 最终 **218 项不同桌面定向测试通过**：节点编辑器 192、帧布局缓存 4、面板 13、Shell 输入事务 7、工作区成本 2；0 failed、0 ignored。独立运行的探针与套件重叠，不重复计数。
- 既有视口记录 312 帧、画布外编辑记录 64 帧再次与各自优化前的记录精确一致；连同本批 216 帧，合计 **592 帧完整输出与状态对照**。这是 CPU 绘制命令与状态对照，不是像素截图或 GPU Present 验收。
- 两条真实 Shell 工作负载分别覆盖 48 组稳定拖动及 48 次布局变化，原断言不变。`frame_builds` 仍表示 calculate_frames 次数，不能据此宣称全部底层求解每帧一次。
- FFmpeg 测试与正式 dev 构建通过。独立 LOCALAPPDATA 下 `--command-list` exit 0，stdout 是完整 JSON、stderr 空，运行时没有覆盖 RUST_MIN_STACK。该检查不证明默认配置目录权限、原生窗口或 GPU 呈现。

原始记录、实际编译输入、Git blob、命令及可执行文件哈希见 [manifest](node-collapse-geometry-evidence/manifest.json) 与 [证据包](node-collapse-geometry-evidence/evidence.zip)。此前两批证据包保持不变。

准备夹具时曾遗漏默认输入所需的格式版本，完整文档断言如实失败；随后尝试默认输入编辑 API，因不存在已存默认值而被正常拒绝。最终按构造 fixture 的规则设置默认值并提升最低版本，再采集上述原路径计数。另一次 rustc 以 `STATUS_ACCESS_VIOLATION` 终止，原输出保留；确认进程终止后以同一构建命令完成编译。三类记录均不是性能负对照，也没有因此修改产品重试、期限、预算或返回值。
