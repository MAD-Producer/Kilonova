# #257：有界音频素材时钟与冻结导出

本记录是 `feat/layer-time-mapping` 的音频执行阶段，基于 `9f9bccd6`。
开始前核对打开的 PR 与修改路径：另一 agent 的 #575 负责预渲染，当前音频模型、
混音器、独立原生导出测试和 producer 观察测试不与其文件重叠。没有修改该 PR。
#566 的诊断计数比较授权与负对照已在该 PR 合并，本阶段不重复更改它。

## 实现与边界

- `Project::audio_voices` 为首个时间映射及其后代创建不可变 `AudioTimePath`，
  编译合成 ID、对象、fps、精确区间、offset、时钟、重映射与电平轨道。
  嵌套路径共享步骤；沿用合成深度 16 / 实例 1024 的既有预算。
- 映射之前的合成祖先仍使用原有有理数 origin；映射之后逐输出样本计算来源，
  每层应用方向敏感的区间、先属性时钟/电平，再素材 remap，引用处换算 fps。
  首末 PCM、子帧 trim、source offset、引用 volume 和声道归属有独立断言。
- 冻结、Hold 与正常区间外是无样本，冻结不读取 PCM，不反复输出某个值作为直流。
  没有时间映射的声音保留既有整段有理数混音分支，不改变其取整与逐位输出。
- 映射叶子就近量化到既有 1024 相位 / 64-tap 插值表，整数进位一次完成。
  此规则只用于新映射分支；未映射分支的有理数 floor 与历史重采样语义保持。
- 每批最多 256 个输出点，排序合并它们的实际读取窗口，只额外合并最多 32 个
  原生样本的间隙。单批读取总量不超过 `256*(64+32)` 个原生帧，独立于素材跨度。
  scratch 保留容量可由已有 `memory_info` 查询；该报告仍明确不覆盖工程、voice、
  容器与 OS 文件缓存，不能冒称完整进程内存预算。

没有引入依赖、第三方资产、兼容分支或工程格式变更。测试正弦和 PCM 独立生成。
没有修改生产 logger、返回约定、worker 预算、超时、重试或错误阈值。

## 实际验证

先为旧混音器运行四个新用例：1 项模型计划通过，倒放、冻结与非单调输出的
3 项实际失败。接线后同一预期通过，没有修改既有断言来达成验收。

11 项 PCM/计划测试覆盖未映射逐位相等、倒放首末样本、双重嵌套反转、混合 fps、
未映射祖先的 offset/source-start、子帧 trim、source offset、本地电平、半速正弦
插值和非顺序分块读取。插值误差与解析正弦比较，阈值 0.001；整数 PCM 严格相等。
远距离读取用 19.2 MB PCM，在请求窗口之间注入 NaN；实际混音跳过该间隙且 scratch
容量小于 2 MB。这个负对照会使“读取首末极值之间整段”的实现报错，不能仅凭
观察数组容量就宣称读取有界。

原生冻结导出用四种模式各导出映射与平铺对照，共 8 份实际 MP4；逐份解码 AAC。
每对完整解码样本严格相等（含编码器尾部 padding），有效项目长度均为 9600 帧，
本机实际解码长度均为 10240。冻结工程后修改活动工程、源文件与 PCM，仍保持结果。
只比较声音，不以该用例宣称画面、所有渲染效果或完整 UI 通过。

首轮默认并行回归出现 6 项工程打包 publication 测试失败：`Publication::drop`
在 task 尚未设置时 unwrap。打包器保留全局最多 2 个 worker 的预算；多个该类测试
同时占用预算会在注入点之前退出。CI `.github/workflows/ci.yml` 本来就使用
`--test-threads=1`。按同一配置补跑，保留原始失败，不放宽预算或现有测试。
成功配置只证明既有 CI 运行方式；并不宣称修复默认并行运行时的测试隔离问题。

## 错误与可观测性审计

| ID | 类别 | 证据与处置 |
|---|---|---|
| TIME-A-01 | 功能修正 | 编译不可变路径、逐样本地址、冻结静音与有界窗口；实际 PCM / AAC 对照。 |
| TIME-A-02 | 新观察上下文 | 映射与文件读取失败返回 asset、输出 sample/区间、源起点/长度与 phase；保留类型化 cause。 |
| TIME-A-03 | 真实失败 | mixer 构造后截断缓存；严格检查原始 Io/UnexpectedEof，不改成成功/静音、不重试。另注入已请求 PCM 的 NaN，保留样本和声道。 |
| TIME-A-04 | 既有信道 + 新验收 | 真实倒放读取失败经过桌面 `spawn_producer`；受控阻塞期间先验证 Info start 已落文件。释放后仅一条 Error，含 playback/operation/elapsed/phase/asset/输出区间，写文件和 stderr；stdout 没有业务日志。 |
| TIME-A-05 | 既有覆盖 | 音频生命周期、panic、队列满、回调缺失、取消、EOF、首要故障保留等既有 producer/watchdog 测试原断言保留。 |
| TIME-A-06 | 正常分支 | 冻结、区间外和源范围外零填充；无新计数、日志 IO、故障阈值或热路径警告。 |
| TIME-A-07 | 待完成 | 最终实际设备实时播放、各编辑入口、卡住的系统文件读取与更多速度/高频 DSP 场景未由本阶段穷尽验收。 |

TIME-A-04 的子进程移除 `MOTION_LOG`，使用默认 Info。只在测试加入控制通道；
生产 worker、日志策略和锁顺序保持。类型化原因在媒体边界验证；桌面原有 textual
边界仍按原语义传递完整原因。测试不是模拟成功返回，也不是预先编造的错误字符串。

## 剩余范围与设计基线

音高随采样位置变化，不是保持音高 DSP。当前沿用按素材原生采样率选择的 sinc 表；
尚未提供随瞬时来源速度变化的抗混叠截止频率，不能以低频正弦用例声称高倍加速的
频谱质量完整。还需完整实时性能与设备验证、非单调预取、映射区间/resize、普通
属性 Hold/摄影机反向边界、多采样 shutter、模型动画、连续编辑、缓存/预渲染身份、
可见入口和双窗口/两语言/焦点/取消验收。#257 保持打开，不将本阶段称为整体交付。

DESIGN §0.7 D01–D12 全部保留，原因分别为本阶段未编辑对应面板：路径步进、
路径双列、路径按钮尺寸、路径数字输入、路径布尔、效果行高、效果布尔、效果枚举、
效果悬停、效果层级、时间轴列坐标、时间轴吸附线。§12 UI 验收待可见入口阶段；
本阶段不以编译或 MP4 文件替代 UI 截图。
