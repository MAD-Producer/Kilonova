# 图层时间映射：关键帧投影与形状快照阶段

接续 `25ad26b1` 的工程数据和原子命令，继续在 `feat/layer-time-mapping` 实现 #257。
本阶段没有完成整项需求，不关闭 issue，也未发布伸缩/倒放可用的 UI 入口。

## 功能与协议

- 时间轴关键帧的 `frame` 是连续合成时刻，`local_frame` 保留存储身份。
  变换、独立摄影机、蒙版标量/向量/节点几何、分离轴和连续空间关键帧统一使用
  图层时钟的逆映射。整数时刻仍写成 JSON 整数；分数时刻不取整。
- 倒放只改变显示时刻，不重排本地键、不改值、不反转归属在本地区间的缓动。
  后续曲线绘制须按时钟采样，不能将倒序的派生坐标排序后沿用错误的缓动方向。
- 保留在可见 clip 外的键仍投影，不能因其合成坐标超过采样预算而丢失。
  派生投影和实际采样是两个边界：原有采样坐标限制与拒绝断言保留。
- 非有限输入返回带 object/phase/cause 的模型错误；关键帧序列化也显式拒绝非有限
  时刻，不能让 JSON 将其变成 null。没有新增 logger 或改变故障阈值。
- 宿主形状参数快照由旧的 `frame - offset` 改为同一个属性时钟。它与实际 Scene
  轮廓采样、变换属性和保存重开后的状态一致；未映射图层保留原采样行为。

## 原始失败与修正

- 投影旧实现实际返回 11 而非 11.5，以及 10 而非 100；原测试断言保留。
- 宿主旧实现未映射对照通过；150% 时长伸缩在 C=40 返回角度 60，固定预期 40，
  证明参数快照仍使用旧 offset。修正读取路径后原用例通过。
- 新测试夹具首轮误用 0–100 不透明度单位而被项目验证拒绝；第二轮将首时刻透明度
  设为零，Scene 正常剔除了不可见轮廓。分别修正夹具单位和可见性后才得到上述真实
  时钟偏差；不把前两次夹具失败作为产品缺陷或负对照。原日志全部保留。
- 初版投影测试辅助函数的 JSON 类型编译错误也保留，不能当成行为失败。
- all-targets 和定向编译检查找到 clip、分离轴及锚点测试的五条断言类型不匹配：
  `TimelineKey.frame` 改为连续时刻后，仍使用整数比较字面量。仅将预期值改成
  相同数值的浮点字面量；精确相等、本地键和缓动断言不变，不增加容差或减少检查。
  三组既有用例 22 项通过，最终 all-targets 检查通过。各次失败日志均保留。
