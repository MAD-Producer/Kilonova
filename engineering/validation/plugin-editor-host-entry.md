## 行为与检查

证据目录为本页同名目录。原始日志保留字节，截图来自原生 GPU 捕获或实际程序屏幕，
不是重绘稿。测试驱动与 OS 消息驱动的范围分别列出，不能互相替代。

| ID | 类型 | 检查与边界 |
| --- | --- | --- |
| H1 | 功能 | 同进程独立作者窗口、不同 WindowId；通过生产 Shell 路由发送指针/IME，主输入、播放、工程及撤销状态不变 |
| H2 | 功能 | 关闭主窗口先询问作者草稿；继续编辑取消主关闭，保存后完成回收再恢复主关闭流程 |
| H3 | 功能 | 关闭工具不退出主窗口；缺失源文件只影响工具，显示原始原因并可关闭 |
| H4 | 实际运行 | 启动产品二进制，经“窗口 → 插件编辑器…”和系统文件选择框打开示例，打开教程，再关闭工具/主窗口；退出码 0，stdout 空 |
| E1 | 新观察 | 一个任务/一个回复上限；独立 request、阶段、耗时；阻塞前 in-flight 与 Info start 已发布，非返回操作保留可观察状态 |
| E2 | 新观察 | 受控阻塞后释放、handler panic、观察状态中毒；原始 panic hook 保留，错误同时进入文件和 stderr，stdout 不包含产品日志 |
| E3 | 既有覆盖 | M3 源码读取/保存/编译失败保留草稿、LSP 故障与取消、过期回复；通过原回归再次检查 |
| N1 | 正常分支 | 文件选择取消、已打开时聚焦、打开忙时等待、接收方退出后的协议回复放弃，不记为故障 |
| B1 | 功能边界 | 预览仍为隔离示例引擎；包发布、真实宿主 session、主时间轴共享及新建向导均未实现 |
| P1 | 待验证 | 灾难性 GPU 退出后原生 Save/Discard/Cancel 恢复矩阵、实际系统 IME、DPI、多平台、驱动永久阻塞与清理失败 |

原生生命周期测试使用真实 Shell、窗口与 GPU；注入的 Winit 事件经生产分发器，
测试屏蔽无关桌面指针事件。它没有调用完整主软件 about_to_wait，不能证明整个调度器。
另外的实际产品 smoke 使用真实主窗口和事件循环、已知 PID 的 Win32 消息及屏幕捕获，
补足菜单入口和正常退出；该 smoke 没有编辑草稿，也不验证系统 IME 服务。

最终产品和测试编译通过，分别保留 29/26 个既有告警。最新显式回归为 **17 通过、1 失败**，
失败即下面保留的诊断计数整快照断言；不能将本轮套件称为全绿。
此前同一功能状态的回归曾 18/18 通过，最新增加观察状态中毒的错误信道断言后该新检查通过。
真实产品的菜单、系统文件选择框、同进程教程窗口及关闭检查通过。

## 首轮失败及未解决的不稳定项

- 首轮测试构建缺少测试模块导入和新增 App 字段，修正夹具后编译通过；没有删改断言。
- 首轮关闭验收点到编译期间禁用的保存。改为等待实际 busy 结束，保留禁用行为和断言。
- 实际主软件首次启动栈溢出：把完整 App 内联存入 Hosted/Shell 占用主线程栈。
  已改为 Box 持有；真实主软件启动、菜单打开与退出重新验证。未增加线程栈预算。
- 一轮测试进程未加载 MSVC 环境，受控 LSP helper 的 rustc 找不到 link.exe。
  加载同一构建环境后重跑，保留环境失败日志。
- 另一轮严格整状态断言失败，唯一差异为 `/desktop/diagnostics/droppedRecords` 从 0 到 1。
  Diagnostics 的 record 使用 try_lock，与异步 reporter 竞争时允许记录丢弃。
  工程、帧、revision、撤销及其他状态无差异。**该整快照断言的不确定性仍未修复**；
  保留原断言、原始失败以及差异摘要，不以再次通过声称问题已消失。
- Vulkan loader 的 Epic overlay JSON 缺失是本机既有环境错误；原始输出保留，
  未屏蔽或当成工具窗口功能修复。
