# 裁剪时按需建立索引映射

Refs #129，基线 `6bdb692a7f6878dc8c78742a80561ee28937d145`。`PaintList::clip_to` 即使保留全部图形和字形，仍每次分配两张索引表。现在只在压缩使某个保留元素的索引实际移动时建立映射；此前的连续前缀使用恒等映射。只有尾部删除时也无需映射，颜色按保留前缀截断；顺序表仍检查公开索引边界并丢弃无效项。

图形裁剪几何分支与基线逐字节相同，字形裁剪和 UV 算法未改。颜色配对、公开缓冲区 zip 截断、混合顺序、重复命令和非法索引丢弃保持。没有为 PaintList 增加字段、缓存或常驻容量；确实需要重排时仍按需分配。三角形/部分四边形的几何输出等其他分配仍存在，不声称整个 UI 零分配或帧率提升。

## 可复现结果

两个新增测试在原实现下 7 通过、1 预期失败：零分配断言实际测到 40 次分配。修改后该目标 8 项全通过；完整 motion-ui 包启用 gpu-tests，21 个测试目标/文档宿主共 167 项通过、0 失败/忽略，包含真实 GPU 像素与错误观察回归。8 项定向测试已包含在 167 项内，不重复相加；既有 compile_fail 文档测试按预期拒绝不合法生命周期，不是构建故障。

| 同一探针，20 次裁剪 | 原实现分配 | 修改后分配 |
| --- | --- | --- |
| 256 retained quads | 20 | 0 |
| 54 contained icons | 20 | 0 |
| retained shape and cropped glyph | 40 | 0 |

测量使用独立测试二进制的线程局部 System 分配计数器，已有实际 Box 分配探针确认计数有效；输入构建和断言在计量窗口外。混合用例包括保留的图形、部分裁切但未删除的字形、UV/尺寸更新、重复绘制顺序、额外颜色及无效索引，存储地址保持。它验证的是实际 clip_to 调用，不是替代实现或整个桌面帧。

另一项测试枚举 32 种图形显隐 × 32 种字形显隐 × 4 种颜色长度，共 4096 个场景，但只计作一项测试。按独立输入标签核对实际绘制命令的颜色和位置，覆盖首次删除的位置、尾部删除、双映射、短/长颜色数组、重复和越界顺序。既有六项裁剪/文字保留测试的断言未修改。

最初新夹具使用 1 像素矩形，却错误假设产物为 Quad；生产代码在该尺寸使用 Procedural，因此那轮 6 通过、2 失败。将新夹具改为实际 Quad 的 2 像素矩形后，同一原产品源码的功能枚举通过，只有真实分配断言继续失败。首次日志、回执和精确初始测试源码保留；没有为通过而改动已有产品断言。
