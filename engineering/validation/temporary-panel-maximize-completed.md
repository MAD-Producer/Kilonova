## Delivered behavior

- An exact, initial Backquote (U+0060) press expands the dock under the pointer. Outside the dock area, the focused visible main-window panel is the fallback. A second press restores the layout.
- The original tree remains the ownership and persistence source. The transient projection borrows its existing dock, preserving split ratios, tabs, active-tab changes, hidden panels and floating ownership. Serialization and named/preset layout capture omit the projection.
- Main chrome, composition GPU viewport, node overlay and node repaint scheduling use the same display tree. Resizing recalculates geometry from the current window size.
- Text/IME, modifier variants, repeats, menus, workspace dialogs and active pointer/editor gestures retain priority. Backquote remains text in an active search field. Idle Effects panels are eligible without changing existing document-shortcut routing.
- Workspace selection/reset and panel show/close/float/redock restore the full layout. Focus loss alone retains the temporary view. Dock splitter and tab dragging resume after restoration; explicit panel actions restore before changing ownership.
- Floating windows already contain one full-size panel. Their Backquote input follows the existing floating interaction path and leaves native window geometry, maximized state and main ownership unchanged.
- View commands emit no editor commands and do not change project content, revision or undo history. No dependencies, third-party assets, colors or dimensions were added to product painting code.
