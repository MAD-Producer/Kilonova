# 数值输入提交与取消契约验收

对应 #215，堆叠于 #557 的 `36c60f15a8f7c09a831bdd89e7cdc0d15d5d1b12`。本轮先核对其他 worktree 与 PR，避开后台预渲染、模型库、媒体范围和节点源等待工作。

## 已核实的问题与改动

- 效果参数原先在字段外按下时取消草稿；跨面板点击还会先切换焦点，导致变换草稿一并丢失。现在先处理原窗口所属的数值草稿，再把有效点击交给目标面板。
- 有效输入外部点击提交；无效输入保留草稿与既有 Invalid 样式，阻止该次点击切走焦点。Esc、明确失焦和目标锁定取消，不把未提交文本写进工程。输入法拥有的点击帧保留文字输入，暂不转移鼠标焦点。
- `NumberEditor::commit` 复用 Enter 的验证与事务事件；空草稿按变换字段已有规则取消。文本取消后立即释放效果字段，解决失焦后仍停留在 editing 状态的问题。
- 变换字段补充锁定／只读检查与字段错误状态。两类字段继续使用已有拖动阈值和 Shift 精调／Ctrl 加速规则；变化读数统一两位小数，编辑仍保留原始精度。
- 参数名选择、轨道／表达式上下文、hover、紧凑字段与单次手势历史沿用现有实现。本轮实际执行既有选择与上下文失效测试，不把既有能力重复归为新增功能。各参数已有范围及 clamp 语义保持原样。

## 实际验收

命令、最终执行结果、源码／二进制／截图 SHA-256 见同名 JSON 与证据 ZIP。

- 效果／变换 × 主窗／浮窗路由 × 中英文，验证外部提交、非法值、IME、Esc、失焦、锁定、无改动／空草稿、撤销与重做保留。
- 使用真实 Engine 和模型历史验证精调／加速、阈值内不改值、连续拖动一次撤销、取消恢复。提交后实际保存并重新加载工程，验证保留输入精度。
- 原生验收建立两个独立 HWND 和 GPU surface，分别用主窗和浮窗所有者截图；两类参数 × 两种语言 × 两个所有者 × idle／invalid／committed，共 24 张 900×720、1× 截图。截图来自产品 PaintList；输入为归一化 Input，不冒充物理 OS 输入、多显示器或全 DPI 验收。
- 既有变换、效果、参数选择、右键文字菜单和跨原生窗口剪贴板测试保留原断言。UI framework／input ownership／failure boundaries 验证底层输入规则。
- 固定共享 LGPL FFmpeg 桌面构建与配套 DLL 的独立 runtime `--help` 成功；样式 consumer 检查和 `git diff --check` 通过。现有 warning 未抑制；不声称本机完成 Linux／macOS 验证。

## 错误信道与边界

| 项目 | 处置与证据 |
|---|---|
| 新元数据读取观察 `effects.numeric_close_parameter` | 实际破坏投影参数 min 的类型，连续调用 120 次：草稿保留、没有命令或工程变更；默认日志仅首条 Warn 和第 60 条 Error，stderr 仅 Error，stdout 无记录。恢复有效投影后同一草稿成功提交并可撤销。 |
| 采样 Result 边界 `effects.numeric_close_sample` | 保留原始 Err、上下文和默认错误信道，不吞错或重试。正常真实采样已执行；本轮没有独立诱发该 Err，不能把元数据解析失败算成采样故障覆盖。 |
| 计数范围 | 复用既有 panel observation 的每调用点、进程生命周期饱和计数；成功或换字段不重置，避免混合列表反复警告。最多两条记录，上下文截断至 4096 字符；60 次不是一秒。 |
| 正常分支 | 空草稿、无改动、IME、失焦取消、目标删除／锁定不是故障；无新增逐帧 IO、Present 记录、线程、超时或重启。 |
| 既有覆盖 | Engine 编辑、历史、保存的 Info start 与故障回复继续走原信道；参数选择、文字菜单及剪贴板仍走原路由。 |
| 功能边界 | 本次改变的是外部点击提交、非法输入焦点保留及取消状态；未修改工程格式、参数范围、面板布局、图标、尺寸或颜色 token。 |
