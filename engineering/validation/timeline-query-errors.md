## TQE-01：原实现的实际失败

三个直接公开模型用例实际执行原实现，全部 panic：`Project::timeline_layers` 引用不存在的视频资源，`Track<f32>::timeline` 被直接赋予分离维度，以及向量轴中的标量轨道被赋予嵌套维度。原始 `timeline-errors-before.log` 为 0 通过、3 失败，初版用例保存为 `timeline-errors-before-test.rs`。

这些测试使用公开字段构造畸形模型；正常工程加载和 core Engine 构造已有验证。这里没有据此声称已经复现正常 GUI 工程或 GitHub 预览版的崩溃。

## TQE-02：功能与原生错误

静态值、轨道时间轴、工程时间轴及宿主快照改为 Result；原生错误沿调用方传播，不转成成功快照、空集合、默认值或伪造数据。模型错误保留 object 和原生 source；静态维度错误只附有界类型名，资源错误附内置操作、资源 ID 和帧号，不包含用户图层名称或完整工程数据。混合向量键与分离轴、标量轴再次分离、非有限查询时间明确拒绝；缺失音频资源不再伪造零时长，没有音轨的视频仍正常返回 None。

宿主先构建可失败的时间轴投影，再执行原有采样。正常快照的字段与类型不变；测试夹具新增 unwrap 只确认成功构造，没有放宽原有断言。编辑已提交后的其他采样失败仍按原有 renderError 契约处理；本次没有增加回滚、重试或重启策略。
