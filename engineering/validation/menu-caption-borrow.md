# 菜单标题复用与重复截断

#129 的分配子项，合入 #572 一并交付，不关闭整个 #129。基线 `2a2f67f7600b056543eba3cd16e8888240990b7e`。实施前检查所有本地工作树相关路径与开放 PR；`workspace-switch-observability` 正在修改 text/style，未编辑这些文件。本批生产改动只有 `widgets/menu.rs`，不引入依赖、资产、布局、字体、颜色、尺寸或输入规则。

菜单原先先调用 `atlas.ellipsize` 创建临时 String，再把该字符串交给 `text_style`；后者经 `text_clipped` 本就按同一值区做字素边界截断。现在直接借用 Entry 的原始标题，让已有文字绘制路径负责截断。快捷键列隐藏、禁用/选中状态、子菜单标记、滚动和选择仍沿原路径。

## 实测

两种语言 × 四档宽度（80/160/220/480）× 三档 DPI（1/1.5/2）× 三档行数（1/8/24），共 72 场景；标题含中文、组合重音和 ZWJ emoji，行含快捷键、禁用、复选、分隔和子菜单。真实菜单每场景预热三帧、测量八帧，两阶段各 576 个测量帧。全部绘制列表（形状、字形、颜色、图像及绘制顺序）与菜单状态快照逐字节一致，72 组线程内分配次数/申请字节均下降。

220px 英文普通 DPI 每帧分别减少 1/8/24 次申请、42/336/1,022 字节，对应 1/8/24 行。不将这个局部优化换算为 FPS 或总内存下降。测量不计其他线程和 GPU；探针与全局分配器不进入产品。

移除探针后，`cargo test -p motion-ui --no-default-features --locked --offline -- --test-threads=1`：169 通过、0 失败、27 忽略，包含一个编译失败文档测试。另行 `--features gpu-tests --test text_bounds`：9 通过、0 失败、0 忽略，包含五档 DPI 的真实 GPU 文字、裁剪和像素对照；部分 CPU 用例与前组重叠，不累计为178个独立用例。未增加对生产实现逐句镜像的永久测试，保留已有菜单输入、宽窄布局、字素和绘制断言。

首轮临时探针误用不存在的 Response 字段，编译失败；修正探针为真实 chosen/hovered 字段后才开始基线测量。原始编译日志保留，该失败没有运行结果。正式源文件与测试断言未因验收失败而放宽。
