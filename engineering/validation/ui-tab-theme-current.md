# 标签页主题透传与布局复核（#129）

本批基于 #607 的 650477e4，在独立 test/tab-theme-propagation 分支补充回归。
开始前核对相关本地分支的 tabs/dock/workspace 文件，没有他人未提交改动；
其他开放 PR 没有修改 desktop/ui。没有重复修改已有实现。

## 已有实现与新增证据

- 标签页读取 PaintList 继承的不可变主题。PanelHost::set_stylesheet 更新宿主
  后，PanelHost::draw 构造带当前主题的子列表；tabs::draw 从该列表读取图标
  样式。它没有新增一个可能与列表主题冲突的独立 &StyleSheet 参数，这属于
  与原 issue 提议不同的 API 传递方式；自定义主题仍完整到达实际菜单图标。
- 新回归走真实 PanelHost→PanelFrame→tabs::draw→绘制列表链路，覆盖主窗/
  浮窗标识、中英文及 100/304/800 三种宽度，共 12 种上下文。每种上下文
  热切换两套图标颜色，验证实际菜单网格颜色、坐标不变、命中仍派发 Menu，
  再恢复默认主题。默认图标颜色与两套目标颜色均不同，作为旧硬编码主题的
  负对照。本测试是命令、几何及输入验证，不是 GPU 或原生 HWND 截图验收。
- 完整 dock_constraints 六项通过，包含四边拖拽共同最小尺寸规则、大窗像素
  下限、已保存窄分隔、嵌套手柄、不修改已有分割树、非有限输入。
- 完整 tabs 三项通过，保留标题动作、当前面板身份及浮动/关闭保存布局。

本轮三个目标共 10 项不同测试通过、0 失败、0 忽略、0 过滤。只新增一个测试，
没有修改既有断言、生产代码、API、样式、资产、期限或预算。正常主题替换、
默认主题恢复与菜单点击不是故障；没有新增 Err、panic、阻塞或日志边界。
