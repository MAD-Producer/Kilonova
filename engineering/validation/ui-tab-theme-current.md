# 标签页显式样式输入与主题回归（#129）

tabs::draw 现在显式接受 &StyleSheet，标题、背景及菜单图标使用同一输入。
桌面窗口传入 chrome 已读取的当前窗口样式；PanelHost 调用方传入
PanelFrame.styles。直接调用者也能在普通 PaintList 中指定样式，无需先修改
列表上下文。四处调用点均同步适配，未保留额外的旧签名或兼容分支。

开始前核对相关本地分支的 tabs/dock/workspace 文件及其他开放 PR，没有他人
占用这些改动。唯一面板改动是传递已有样式引用，不增加颜色、尺寸或样式名。

## 验证范围

- 新直接调用回归：普通 PaintList 的默认主题不能覆盖显式传入的自定义主题。
  使用默认样式的同几何网格作为负对照，要求实际图标颜色不同、几何完全一致。
- 真实 PanelHost→PanelFrame→tabs::draw 调用链覆盖主窗/浮窗标识、中英文及
  100/304/800 三种宽度，共 12 种上下文；每种上下文热切换两套图标颜色，
  验证菜单颜色、网格位置、原位点击派发和默认主题恢复。这是命令、几何和
  输入验证，不是 GPU 或原生 HWND 截图验收。
- 完整 dock_constraints 六项覆盖四边拖拽共同最小尺寸规则、大窗像素下限、
  已保存窄分隔、嵌套手柄、原分割树保留、非有限输入。
- 完整 tabs 三项保留标题动作、当前面板身份及浮动/关闭保存布局。

最终三个目标共 11 项不同测试通过、0 失败、0 忽略、0 过滤。既有测试只适配
新增参数，保留全部断言；没有修改期限、忽略项、性能预算或生产编译配置。
