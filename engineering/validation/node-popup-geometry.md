# 节点下拉菜单的单次卡片构建

本批继续推进 #134，基于 #604 的 `5d56e61b`，在独立本地分支 `perf/node-popup-anchor` 验证。下拉菜单原先只为读取所属节点的屏幕原点，就调用 `cards()` 解析全部节点端口并分配全部卡片和插口。现在从当前文档查找该节点，把位置投影到当前视图，再调用原有的局部矩形变换函数。

没有缓存旧文档或旧视图的 Card，也没有使用节点索引替代身份判断。查找仍保留第一个相同 id，Escape、失焦、节点缺失、锚点不可见及空间不足仍沿用原有关闭分支。下拉菜单的尺寸、翻转、裁剪、滚动、命中、选择和应用逻辑没有修改。

## 原路径对照

新增两项测试使用真实 `NodeEditor::draw` 和输入，覆盖中英文、两种窗口大小、两种缩放、数学节点的两个下拉字段，以及取消、外部点击和操作应用，共 40 组、320 帧。每组包含首次绘制、点击打开、释放、视图移动/缩放、菜单滚动、键盘导航、关闭与稳定帧；应用操作后另核对实际撤销重做。

原生产代码下，功能及独立新鲜卡片几何断言均通过，构建次数断言真实失败：224 帧重复构建整图卡片，端口解析数与 `builds * nodes` 一致。原始退出码为 101；完整记录器另一次执行退出 0。仅修改生产锚点计算后，同一组测试全部通过：320 帧均一次卡片构建、每节点一次卡片端口解析。

修改前后完整 CPU 绘制命令、FrameResponse、EditorSnapshot、选择、视图、notice、diagnostic、菜单内容/选择/滚动以及完整 undo/redo 记录逐帧相同，无删除或归一化字段。既有七组完整记录也与其各自原路径逐帧相同，共 3240 帧。该数量包含本批 320 帧，不额外重复计算记录器执行。

## 观察、设计及剩余工作

- **现有观察覆盖**：真实画布的卡片构建仍解析并观察节点端口；本批只删除菜单定位触发的额外整图解析。损坏端口的累计计数不再由菜单额外增加，仍按实际解析发生次数计数，未改动阈值或抑制规则。
- **正常边界**：Escape、失焦、缺失节点和不可见锚点仍为原有关闭行为，没有新增 Error。测试没有穷举所有损坏工程、重复身份或菜单应用失败组合，不把保留代码等同于该范围全部验收。
- **功能/协议边界**：无新增错误结构、观察键、超时、重启、重试、依赖或协议变化。此次只验证数学节点两个菜单；既有节点测试覆盖其他菜单，不据此宣称所有节点类型的原生验收完成。
- **DESIGN §0.7**：12 项既有面板视觉问题全部保留，原因是本批仅改变节点菜单锚点的计算成本，没有修改 panels、样式 token、行布局、容差或外观。CPU 绘制记录一致不冒充实际截图或 GPU 验收。
- **待完成**：同帧跨子图/结构或端口变化仍可能重新构建；原生查询辅助函数仍可能独立构建卡片。完整工作区的原生/GPU 拖动与静止开销、所有路径的单次 dock 求解、物理输入/DPI 和最终跨平台 CI 尚未在本批证明。#134 保持开放。
