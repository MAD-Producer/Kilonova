# 工作区命中与绘制共享底层布局结果（#134，合批于 #603）

基线为 #603 的 `9ae6b16b75f0b67b99b6c48b4ab13639735b9046`。开始前分页核对全部其他开放 PR 的文件清单：#575、#580、#581、#582、#583、#584、#586、#597、#599 均未修改本批 dock 模块或两个面板计数文件；清单及精确 head 存于证据。只检查文件范围，没有审查其他 agent 的 PR 代码，也没有修改根工作树。本批继续并入 #603，不新增堆叠 PR。

## 生产变化

原面板帧缓存覆盖不到 `motion_ui::Workspace` 的标题命中与停靠目标查询：它们直接调用 `dock::solve`。现在底层求解器在同一线程复用一个有界结果，与面板绘制、标题命中和停靠目标共用。命中检查完整布局结构、节点种类、边、浮点位模式、子节点顺序、DockId、tabs/active，以及 Rect 四个坐标的位模式，既不靠地址，也不靠有碰撞风险的摘要。

每线程最多保存一个条目，结构键最多 128 项、placement 最多 128 项，两块缓冲区在条目替换时复用。非有限或超限输入不进入缓存；可选 TLS 槽借用冲突或销毁后，继续原计算。返回值仍是调用方独占的 Vec，修改返回值不影响后续调用。现有面板帧缓存继续存在，本批增加的是一个额外的有界底层缓存；不称为零分配，也不修改超限、输入或错误语义。

没有改布局尺寸、最小尺寸策略、命中区域、停靠边选择、窗口所有权、绘制顺序、样式或持久化格式。结构变化后计算新布局，旧结果不会用于新树。

## 计数的范围更正

此前 `panels::workload_tests::Counts.solves` 实际记录 `calculate_frames` 调用，没有覆盖全部底层调用。本批将字段和入口改为 `frame_builds` / `record_frame_build`，断言的数值保持不变；旧测试名和旧源码快照保留历史身份。之前的 Shell 记录证明面板帧构造次数，不能冒充所有实际底层求解次数。

新增测试仅在 cfg(test) 下，于缓存未命中、进入原 `solve_into` 根递归前计数。因此统计的是实际整树求解，不是缓存查询或每个递归子节点。生产热路径没有新增观察计数、日志或文件 IO。

## 实际验证

- 原生产路径加新测试后，三个性能回归真实失败：同一布局的绘制/实际工作区正文按下查询为 6 次而非 1 次；预热后的标题命中为 1 次而非 0 次；分隔条变化后的五次查询为 5 次而非 1 次。两个行为对照通过。没有改动这些失败断言，加入复用后全部通过。
- 新测试用真实 `Workspace::interact` 验证正文按下、标题拖放与分隔条拖动。标题释放改变树后只计算一次新树，保留两个面板并合并为一个 tab 组。不是物理鼠标或原生窗口验收。
- 130 种布局/区域组合各查询三次，共 390 次原递归与公开求解器输出对照，逐项比较 DockId 和所有坐标位模式；包含四个边、不同 split、active、空 tabs、区域原点/尺寸、signed zero 和非有限输入。另验证相同分配地址上的原位结构编辑和返回 Vec 被调用方修改。
- 借用冲突、线程 TLS 确实已销毁、超限和非有限键的实际路径都保留原结果；恢复正常输入后再次命中。键与结果缓冲区的保留项数和容量均验证有界。
- CPU UI 库 **76 passed、0 failed、15 ignored**，其中 8 项新增；15 项为既有 `gpu-tests` 条件忽略，本次未改属性。另有 6 项停靠约束集成测试通过。桌面节点/缓存/面板/输入事务/工作区套件 **212 项不同测试通过、0 failed、0 ignored**，合计 **294 项不同测试通过**，不把重复单项复跑累加。
- 最终程序再次记录中英文、两种区域、三个缩放、折叠/展开的 24 种配置、312 帧；完整 shapes/colors/glyphs/order、响应、EditorSnapshot 与 undo 长度，与节点视口优化前的独立进程记录精确一致，没有删除或归一化字段。48 个真实 Shell 稳定拖动样本和 48 次实际预设/尺寸/最大化/active 标签变化的原断言也保持。
- 带 FFmpeg 的测试与正式 dev 程序编译通过。正式程序 SHA-256 `b783bdd7b80214d181b9eef5fee810ac8efa1f0de0c42923539cc13099a3cee3`；独立 LOCALAPPDATA 下命令列表 exit 0、stdout 完整 JSON、stderr 空，运行时没有覆盖 RUST_MIN_STACK。不据此认定原默认配置目录权限问题或原生 GPU 呈现已修复。

计数重命名初次编译漏改一处测试结构体初始化，产生 E0560；保留该次编译原始输出，补齐字段名后重新编译并运行以上回归。没有修改断言数值、生产超时或重试。UI 库测试中故意注入的剪贴板 poison panic 为既有测试的受控故障，不隐藏其 stderr。
