## 实现

原拾取操作取到正确位置或颜色后，将合成播放头向下取整并提交旧 Effect Set。
3/2 伸缩、offset=2 的图层，在 6.5 合成帧恰好对应有符号局部键 -3；取整会丢失
这个地址。另一些时刻，取整会错误地允许写入附近整数键。

映射图层的拾取现在使用已有 TrackAt，携带票据里的原始合成时间和效果参数地址。
复用核心精确投影、局部整数键可表示性、原子事务、参数验证与撤销，不新增协议或
默认重试。未映射图层保留原有拾取命令和行为。拾取位置仍用真实图层平面反投影，
颜色仍来自实际当前预览；没有更换坐标空间或颜色空间，也没有改动渲染语义。

原有 source/revision/generation、播放头、锁定、窗口和预览有效性守卫保留。
正常过期、预览未就绪、超范围和取消仍返回原有 editorAction；不能以正常取消
掩盖核心拒绝的非法局部时间。

新增原生用例通过生产参数按钮和 chrome 合成点击，覆盖两种方向、中英文和
主窗／浮窗，分别拾取坐标及真实 GPU 颜色。跨窗口失焦不提交，Esc 可取消；
提交后比较完整工程，保留其他键和通道。保存后在另一个进程重开，核对完整工程
和空历史。核心非法时间经过真实串行 worker，在默认 MOTION_LOG 下验证 Info
start、原始原因、Error 文件与 stderr 以及 stdout 隔离。

首轮编译暴露新增原生测试从 panels 导入私有 Input/Key/Locale/MouseButton；
改用这些类型的定义模块，不放开生产可见性，也不改验收断言。
首轮运行遗漏本机测试使用的 TEMP/TMP 配置，系统临时目录拒绝创建夹具；保留
失败日志，并使用既有可写的构建临时目录重新运行同一程序。随后新增重开夹具
在原 worker 仍持有工程锁时打开同一目录而失败；修正测试生命周期，先正常关闭
原 worker 再重开，没有修改生产锁行为。中间程序的原生验证与最终源码的结果
分开保留，最终冻结后的三份源码哈希在执行结束再次核验。
