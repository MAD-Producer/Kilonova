# 原生播放超时的 CI 现场留存

推进 #135 的验收证据缺口。开始前检查工作树和开放 PR：#395 及其后续曝光预算分支负责资源分配，精度分支负责渲染语义。本次仅修改 Windows 原生采样测试和 CI 证据上传，不修改生产渲染、播放策略、面板或公共协议。

## 问题与边界

#393 的 Windows job `119116745689`（run `39568462493`）在原生采样的 Present 回复等待中超时。子进程以 101 失败，等待期限为十秒。该 PR 的 Linux、macOS 及 Rust/GPU 检查通过，随后 #394 的 Windows 同一用例也通过；这些成功不能解释先前的超时。

现有 CI 只在非 PR 事件上传完整桌面验收目录。失败子进程虽然在本地留下部分成本数据和日志，PR job 结束后没有可供下载的采样现场。因此本次补诊断，不能将它算作该超时根因的修复。
