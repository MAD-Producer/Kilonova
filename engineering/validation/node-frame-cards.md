# 节点卡片几何的同帧复用验收

关联 #134 的卡片重复构建子项；合集其他范围保持开放。
起始主线为 `28880872182dd986ac37223006c793f476feabb8`。

## 范围和重复检查

开始前核对开放 PR、396 个分支引用、23 份不同的节点视图源码及
107 个工作树。两处未提交的同文件改动属于快捷键适配和已有导航测试，
没有同帧几何复用；没有修改其他工作树。前批 #480 已通过五项必需 CI
并合入，上述基线包含它；仍开放的 #481 修改 UI 文字保留，不涉及本次
节点几何构建与输入阶段。

当前 `NodeEditor::draw` 会为行内控件、画布输入、最终绘制各调用一次
`cards()`。每次遍历全部节点、解析端口并分配卡片、插口和 ID；静止帧
同一结果被构建三次。产品改动只在一次 draw 内沿用已有卡片，在阶段
之间确认文档/视图状态变化后才重建，不跨帧保存几何缓存。

同帧状态包含 epoch、revision、preview_revision、pan、zoom。
行内编辑和常规文档变更推进修订；组导航只推进预览修订，也必须失效。
节点拖动在写入历史前会直接改变位置，因此画布输入前后任一侧存在
节点拖动时保守重建。平移、缩放、小地图导航和取消通过视图状态失效。
卡片构建、命中、画布绘制和各输入处理函数的产品正文保持原文。

## 修改前回归

新增“静止帧只构建一次”测试在原实现上实际失败：得到 3、期望 1。
另四项新增行为测试在原实现通过，覆盖：

- 中英文滚轮缩放、水平/二维平移与中键拖动，不写工程或历史。
- 小地图拖动以及 Esc、失焦、丢失按键取消，恢复原视图。
- 按下与较新鼠标位置同帧到达、未提交节点移动、松开单步历史及撤销、取消。
- 返回父组时保持相同视图和文档修订，但预览修订变化，必须使用新图的卡片。

测试在实际 `paint_canvas` 入口记录收到的卡片、矩形、全部插口属性及
坐标；测量结束后独立重建当前几何逐项比较。计数和快照钩子只在
`cfg(test)` 编译，测量范围由线程本地作用域控制，额外 oracle 构建
不计入 draw 的构建次数；正式产品不含这些钩子。

初次新测试夹具出现视图类型不支持直接相等比较和临时探针缺少导入的
编译失败，已留存。仅将新夹具改为比较完整 pan/zoom 并补探针导入，
没有给产品类型增加比较实现，也没有修改已有断言或执行预算。
