# 文字保留流程的临时分配验收

关联 #129 的绘制分配工作；仅交付一个局部优化，不关闭整个 issue。
基线为 `e6576504b7b68a31ce863a5ede011bc264170232`。

## 范围与重复检查

开始前核对开放 PR、395 个分支引用、22 份不同的 `paint.rs` 和
106 个其他工作树。所见 `retain_glyphs` 均保留原有每次分配索引表的实现；
三个工作树的未提交绘制改动属于已合并的三角形优化或独立的 wgpu 适配。
没有修改其他工作树，也没有重复实现它们的工作。

产品只改 `PaintList::retain_glyphs`：第一次实际移除字形时才建立旧到新
索引表，并补齐此前保留的恒等索引。全部保留时无需重排创建顺序，
仍检查公开缓冲区内的字形索引，保留原先的越界 panic。
节点小地图每帧调用此函数；菜单、提示及其他调用者共用同一入口。
没有改变文字布局、图集、裁剪、绘制命令、命中区或面板代码。

## 修改前后对照

新增分配回归在原实现上失败：256 个字形、连续 20 次全部保留产生
20 次分配，目标为 0。三个新增行为测试在原实现上全部通过，连同
原有交错绘制测试共 4 项，形成修改前的行为基线：

- 枚举长度 0 到 8 的全部保留掩码及正常、反向、重复索引三种顺序，
  共 1533 组；检查谓词严格按存储顺序调用一次、剩余字形及绘制顺序。
- 对 0/1 个字形的无效公开索引，分别全部保留或移除；谓词执行后仍发生
  与原实现同内容的越界 panic，不能因快速路径隐藏损坏状态。
- 谓词在已有移除后 panic 时，原始原因、已访问字形、部分压缩和未修复的
  创建顺序保持原行为，不吞掉异常或更改返回约定。

临时探针分别调用修改前后的真实 `NodeEditor::draw`，打开小地图，使用
仓库现有节点夹具和系统中英文字体。预热三帧后，计数当前线程 20 帧的
System 分配/重分配请求及申请字节；另记录完整形状、颜色、字形、创建
顺序，并确认文档和 revision 不变。四份有限输入的绘制数据合计
328,454 字节逐字节一致；各份哈希和原始输出保存在本地验收记录中。

| 场景 | 20 帧分配请求：前 → 后 | 20 帧申请字节：前 → 后 |
|---|---:|---:|
| 英文 900×600 | 11660 → 11660 | 5893440 → 5893440 |
| 英文 1600×1000 | 11960 → 11940 | 6008340 → 5906260 |
| 中文 900×600 | 11380 → 11380 | 4871420 → 4871420 |
| 中文 1600×1000 | 11700 → 11680 | 5063120 → 4990160 |

窄窗口确实移除小地图下的文字，仍分配一次索引表；默认窗口中全部保留，
每帧少一次分配，英文少申请 5104 字节、中文少申请 3648 字节。
申请字节不是峰值内存，分配次数不是帧耗时；没有声称消除全部绘制分配
或获得整机帧率提升。探针及其绝对路径均在正式回归前移除。

## 正式回归

完整 UI CPU 模式 140 项通过、0 失败，25 项 GPU 用例按既有开关忽略，
其中包含新增 4 项测试及原有的预期编译失败文档用例。默认 GPU 模式下
analytic、path_antialiasing、retained_text 共 15 项通过、0 失败/忽略；
其中 5 项重复 CPU 用例，10 项为此前未执行的 GPU 用例。因此 UI 合计
150 项不同测试通过，其余 15 项 GPU 用例未在本地执行。

完整 `node_editor::` 155 项通过、0 失败/忽略，覆盖真实窗口剪贴板、
小地图、菜单和既有默认日志的文件/stderr/stdout 隔离、降级阈值及恢复。
这些是既有覆盖，不记为新增观察能力。合计 305 项不同测试通过；
修改前的重复运行及两次临时绘制探针不计入该数字。

产品编译检查通过，保留既有 20 项桌面警告和 1 项渲染警告；测试构建
保留既有 19 项桌面警告。没有修改忽略、断言、执行预算或 CI 配置。
产品差异校验确认仅修改 `retain_glyphs`，两份测试的原内容前缀完整保留，
节点编辑器的临时接入点已按原始字节恢复。
