# 序列控制字符的界面字形回退（#129 子项）

基线 `72f1037aea7a71047f1920347756d63dedf3e41b`。本次仅修复原生界面字形图集对连接控制符和变体选择符的标量回退，不关闭整个 #129。开工核对开放 PR 与本地文字/字体分支；共享菜单工作不修改 text.rs，未重复其功能或编辑其他工作树。

正常的变体序列在当前界面字形引擎不支持字形替换时，应回退显示原字符；控制符自身不应占位或被当成缺失的可见字形。依据为 [Unicode 官方回退说明](https://unicode.org/faq/unsup_char.html)及[序列定义](https://www.unicode.org/versions/Unicode18.0.0/core-spec/chapter-3/#G3.6.2)。代码独立编写，处理蒙古文变体选择符、VS1–VS256、ZWNJ/ZWJ；没有引入依赖、字体文件、第三方代码或素材。

`advance` 与 `glyph_at` 采用同一分类。控制符返回无墨迹、零推进量，不创建缺字事件；原非法尺寸和图集上限诊断保留。普通未支持字符继续保留正推进回退与既有缺字记录。未修改编辑数据、grapheme 边界、剪贴板、工程格式、历史、样式或属性行。
