# 图层时间映射：根合成视频执行阶段

接续 `4679fcc4` 的关键帧投影与形状参数快照，继续实现 #257。本阶段只接通
根合成视频来源，不代表伸缩、倒放和重映射的完整桌面功能已交付；不关闭 issue。

## 行为与边界

- `Layer::video_source_time_us` 统一属性时钟、素材 remap 与最终视频微秒换算。
  倒放按排他边界减去一个解码微秒，不能减去一整个合成帧。冻结段保留画面请求。
- Scene、时间轴视频元数据、`VideoFrames` 与 `PreviewInputReader` 使用这一入口。
  原有“保持首画面”策略在来源时钟之后应用；负时间仍是正常区间外，不夹到首画面。
- 请求后修改图层时钟时，已有读取协议拒绝发布失效帧。先检查有符号素材区间，再将
  时间转为无符号缓存键，避免负时间转换为巨大时间戳。没有增加重试或重启。
- 未映射视频复用原有 `VideoClip` 取整顺序。模型用 240 组输入分别精确比较原始
  时间与首画面策略，并比较整个图层不变；没有改旧素材区间验证或解码语义。
- 非视频图层、非有限坐标、非法 fps 和素材身份不符保留对象、阶段及原始 cause。
  本轮不增加 logger、热路径 Info、故障计数或默认输出策略。

## 实际视频与像素验证

使用仓库既有 CFR `silent-24fps.mp4` 与 VFR `variable.mp4`，没有添加素材或依赖。
实际 libav probe 的 PTS 与 fixture manifest 比较，然后运行实际桌面解码 worker，
没有以模拟帧或构造成功返回值替代。

34 个固定采样点覆盖未映射、150% 伸缩、倒放、非单调 remap 和冻结段。逐点验证：

1. Scene、时间轴和原始来源输入的时间戳符合独立硬编码预期。
2. 实际解码帧 PTS 对应 fixture 的前驱样本，完整 RGBA 与独立 Decoder 读取相同。
3. 原始来源输入的完整 RGBA 与上述实际帧相同，整个工程未被采样重写。
4. 每种非默认映射完成读取后重置时钟，原请求不能发布旧帧。

另对 CFR 倒放和 VFR remap 各捕获一个真实 `FrameFreezePlan`，通过实际 JSON 命令
重置活动工程时钟，构造未映射的同来源时间对照，再关闭 Session 后执行冻结导出。
两组实际 Vulkan PNG 与对照的完整 32×32 像素精确相同，验证冻结计划保存原映射。
这是离线冻结 PNG 证据，不是桌面交互预览、带音频视频导出或截图验收。

本轮完整模型 **202 项**、宿主选定回归 **13 项**、渲染选定回归 **7 项**、上述原生媒体
**2 项**通过，共 **224 项不同测试，0 失败、0 ignored**。三项新增模型测试包含在
202 项中，不重复累计。全工作区 all-targets 检查通过（排除 Android，启用桌面
FFmpeg 与宿主 diagnostics），保留已有告警。

实际测试计数、命令、文件身份和原始输出见
[证据清单](layer-time-video-evidence/manifest.json)。编译检查不计作执行用例。

## 保留的原始失败

- 旧实现实际在 CFR 倒放首时刻返回 `2250000`，固定预期 `2249999`，证明视频叶子
  没有消费负向素材时钟。修正执行路径后原边界断言通过。
- 首轮修正后的新夹具将短 VFR 素材放入 24 fps 的过长 clip，被既有来源区间验证
  拒绝。将该夹具的合成 fps 改为 48，并按实际 fps 独立给出预期；没有放宽生产验证。
- 扩展失效读取断言时，新测试对不实现 Debug 的帧使用 `unwrap_err`，导致编译失败。
  改为显式匹配结果；拒绝旧帧的行为断言不变。该次不是产品行为负对照。

上述失败日志均与最终通过日志一起保存，不覆盖原证据。

## #257 的剩余范围

1. 嵌套合成传入方向、不同 fps、remap 转折处的定向区间选择与叶子一次量化；
   非单调图像预取不能只用区间两端推算来源覆盖。
2. 映射后来源范围验证与 resize、深度来源及其失效判断的错误传播、模型动画时钟。
3. 有界非单调 PCM、倒放和冻结静音，未映射音频快路的实际样本对照。
4. 连续关键帧编辑和所有桌面消费者；带音频视频导出、缓存与后台预渲染身份失效。
5. 可见入口、主窗/浮窗、中英文、输入焦点/取消及实际截图；当前最终 PR 完整 CI。

没有修改面板、样式或菜单。DESIGN §0.7 的 D01–D12 保留，原因是不在本阶段范围；
§12 的 UI 验收仍待可见入口接通后执行。
