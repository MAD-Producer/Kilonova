# #273 音频电平、源波形与声道平衡

音频面板以实际设备回调消费的 PCM 显示主输出左右声道峰值和 dBFS，跨 UI 采样间隔保留峰值，达到满幅后提示保留一秒。停止清空读数。读数位于现有混音限幅之后，因此“满幅”表示实际提交给设备的样本达到 0 dBFS，不声称测得限幅前的超限幅度。

源波形与主输出明确区分：选中音频或带音轨的视频后显示片段范围内、增益和静音处理之前的源波形，包含 source_offset、图层 offset、裁剪和子帧边界；源范围之外补静音。子合成可调平衡，但波形提示选择源音频，不冒充合成后的混音波形。

平衡是独立的静态参数，居中不改变声道；向一侧调节只衰减另一侧，保留原有左右 dB 关键帧。嵌套合成逐级相乘，实时预览和冻结导出共用混音计划。能力快照明确声明 supported、范围、线性衰减规则和 animated=false，不支持的后端禁用并说明原因。
