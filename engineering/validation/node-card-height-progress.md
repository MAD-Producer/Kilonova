# 节点卡片高度复用端口规格

关联 #134，基线 `4afb6cfc036393d3ec02062ae7a846a26403b1df`，代码提交 `c1d7a7c12a14e328267de295529da8a46f7e9eb4`。

## 问题与改动

创建卡片时，原实现先在 `node_height` 中调用 `node_ports` 分配端口映射，再为插口调用 `node_port_specs`；后者内部已经调用同一 `node_ports`。现在只解析插口所需规格一次，同时借用其输入/输出数量求高度。共用扩展高度公式，其他调用者仍按原方式解析；折叠节点仍仅使用原头部高度，错误仍使用一行回退并走原 `canvas.sockets` 观察路径。

本改动不涉及 #502 的绘制标签规格复用，不缓存跨帧对象，不新增字段或持久内存，也不改变行高、插口坐标、卡片尺寸公式、控制项或命中区。开放 PR 与 433 个引用的 15 个版本、120 个工作树已核对，未发现相同卡片构建优化。
