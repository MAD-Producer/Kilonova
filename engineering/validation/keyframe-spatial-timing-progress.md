# 空间路径度量：Roving 的计算基础

本轮基于 `a265ecfc` 增加独立的空间路径准备 API。它不改变工程格式、作者键、现有
`Track::sample` 或渲染语义，也没有启用 Roving。#260 仍打开；时间身份、持久化、
编辑器命令和实际 Roving 输出是后续工作，不能用本页的几何测试代替。

## API 与计算边界

`Track::prepare_spatial_path` 仅接受耦合的 2D/3D 数值轨道，并返回自包含的不可变路径。
宿主仍须验证参数语义：位置与锚点可以属于空间路径，缩放或 RGB 即使存储为三维数值
也不能因此开放 Roving。标量、四通道打包值和拆分轴在本层直接拒绝。

没有手动空间手柄的区间沿用真实 sampler 的直线定义；有手柄的区间用实际三次控制点。
自适应细分同时限制弧长估计误差和参数到位置的误差，覆盖端点重合的回环，以及几何上
为直线但参数为 `t³` 的非匀速曲线。算法独立编写，无新增依赖或第三方资产。

整条路径最多 16384 段、65536 个节点、65536 次细分，深度不超过 24；调用方可进一步
收紧预算。默认相对容差为 `1e-5`。深度、节点、细分或分配失败返回带区间上下文的
原始错误，不重试、不退回直线，不保留半成品。查询不分配内存。

`constant_speed_times` 返回每个作者键对应的小数时刻，不四舍五入、删除重复点或
添加 epsilon。重复位置可以对应相同派生时间；全静止路径保留作者时间比例。
固定区间按局部长度求和，`sample_interval_distance` 直接取样局部距离，避免一个
极长前缀抵消后续短段。全路径的距离查询仍受单个 f64 累计距离的表示精度限制；
不能用它代替精度敏感的局部约束求值。
