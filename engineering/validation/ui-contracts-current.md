## 逐条处置与剩余工作

- #129 图集增长/写入边界：已有增长实现，本轮补充高度与无效尺寸验证。
  与既有实际 GPU 增长回归合用，覆盖该条；没有在中途清空旧内容。
- 长 scrub 标签与数值重叠：已有修复，本轮文字边界与 GPU 负对照验证通过。
- NumberEditor/Button：按释放按键结束、IME/重复过滤均通过。Button 使用共享
  key_presses 的过滤逻辑，没有字面调用 KeyChord::pressed；行为已覆盖，原复合
  清单的 API 写法差异明确保留，不以功能相同冒称按原文字全部完成。
- Router 去重/跨窗口、轻量输入视图：当前实现与 I1/I2 对应验证通过。
- 分配复用：T2 与 I2 范围内通过；公开 ellipsize 仍按 API 返回 String，绘制热路径
  使用借用 fitted_text。不据此勾选不限定范围的“每帧分配量”验收。
- tabs::draw 从 PaintList 继承样式，没有显式 &StyleSheet 参数；最小尺寸与 split
  的六项通过，但本轮没有自定义主题验证，原复合条目保持未完成。
- grapheme 编辑九项通过；测量仍逐标量累加，绘制仍逐 chars 发字形，尚未完成
  组合标记、连字与 emoji 序列的塑形。编辑/绘制/测量一致性条目保持未完成。
- 新增错误观察：无。本轮不改错误返回、重试、日志、断言或性能预算。
  组件成功不替代全应用默认日志通道与阻塞状态的验收。
- DESIGN §0.7：面板既有问题按原状保留，本批未修改 panel、样式或产品外观。
  离屏读回不代替实际窗口、物理输入、扫描输出或全帧性能。
