## 实际变更

- 选区使用带类型的地址：普通键仍是属性通道和整数合成帧，空间键是属性通道和稳定 ID。
  同时刻的不同空间键不会合并；不把 `9.5` 截断为 `9`，也不向旧单键控制器伪造整数地址。
  两类键共用文档范围、revision 缓存、选区所有权、主选中项、元数据上限和同一输入记录器。
- 汇总行、展开属性行的空间键真实绘制和命中进入既有点击、框选、全选与拖动流。
  不额外增加一套鼠标监听。空间键主选区只投影所属轨道，不投影旧整数关键帧。
- 拖动中只绘制原键和预览；松手时合并普通键变换与各空间通道的 `Move`，通过一个
  `EditorAction` 原子提交，一次撤销恢复完整工程。取消、失焦、来源变化、缩放和视图变化
  继续使用原有终止机制。鼠标已松开后的移动不会补发编辑。
- 新增稳定 ID 成组移动命令。所有选中键先读取同一份旧解算时间，再一起改变固定时间，
  最后解算与安装；不会因为逐个移动产生临时锚点交叉而拒绝合法整体平移。
  零位移保持 Roving 所有权和历史不变；移动非零时固定所移动键的时间。
- 时间轴的 `incoming_length` 来自已准备的弧长缓存，仅用于派生状态。预览检查合成边界、
  固定键次序和零时长的移动区间，不在每次指针事件重新剖分几何。静止区间允许键时间重合。
- 支持按 ID 删除仍能保留至少两个空间键的选区；保存重开和撤销保留其他 ID。全删空间轨道、
  跨固定键重排以及其他未表示的操作没有伪装成已支持。

空间拖动现在采用整帧相对位移，保留来源的小数时间。连续吸附与空间曲线编辑仍待后续，
没有声称本轮已完成任意亚帧位移。命中同一通道同一时刻的多个空间键时选中全部命中 ID；
单独区分完全重叠键的专门选择入口未交付。

## 错误、正常分支与功能边界

| ID | 分类 | 本轮处置与证据 |
| --- | --- | --- |
| RD-01 | 新功能／核心事务 | 成组移动先验证候选；非法 ID、重复或空选区、非有限时间、次序错误保留工程、revision、undo 和 redo；核心 8 项用例 |
| RD-02 | 新的桌面身份校验 | 原始工程中的 ID 存在性有界检查；文档范围变化及已删除 ID 作为正常过期选区处理；撤销恢复后同一 ID 可再次有效 |
| RD-03 | 正常输入分支 | 取消、失焦、只读、锁定、过期来源和延迟松手不派发部分编辑；中英文及主窗／浮窗用例 |
| RD-04 | 既有错误信道扩充验收 | 真实 worker 分别拒绝旧的非法 `Time` 和新增非法 `Move`；文件与 stderr 各保留两条原始错误，stdout 无业务日志；含 request ID、操作、对象、阶段、键与原始原因 |
| RD-05 | 新的快照降级观察 | 无效空间 ID／时间或畸形原始数组复用面板有界观察器；作用域沿用既有每站点进程生命周期累计规则，不解释为连续一秒；没有为正常过期选区新增错误 |
| RD-06 | 功能拒绝边界 | 整数剪贴板和时间插值编辑尚未表达空间 ID；包含空间键的整组选区禁用这些旧入口，不只处理普通子集，也不回退到图层剪贴板。预设维持模型的显式拒绝，本轮未改预设 UI |
| RD-07 | 实际 UI／worker | 8 组真实 GPU 截图和真实 worker 松手提交；每组均验证预览时工程未变、一次提交、一次完整工程撤销 |
| RD-08 | 现有机制未改动 | worker 在途发布、非 Present Info start、panic、阻塞观察、Present 静默策略与日志阈值未更改；本轮没有新增超时、重启或产品重试 |
| RD-09 | 待接入／验收 | Roving 菜单启用／固定化、准确类型状态、稳定 ID 曲线交互、剪贴板和预设、连续吸附、完整 OS 输入与 DPI、跨平台 CI、实际 Roving 编码输出 |

RD-06 是明确的暂缺功能，不算修复。RD-05 的新增站点没有独立受控畸形快照阈值验收；
复用的观察器已有测试，本轮不把它宣称为每个新站点均完成阈值／恢复专门测试。
新 `Move` 拒绝不覆盖仍未实现的重排或连续吸附算法。
