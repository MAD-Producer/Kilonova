# 节点静止拖动的浮点位移

## 问题与修复范围

在 #134 子图夹具中发现：按下/释放节点而未移动鼠标，也可能把位置从
`380` 改为 `379.99988`，产生无意义的撤销记录；取消路径还会发布多余 revision。
原因是 `(start + point) - origin` 的加减顺序引入舍入。
本次先计算 `point - origin`，再加到节点的原始位置；保留原坐标变换、
范围钳制、提交/取消、丢失按钮与历史流程，不加入 epsilon 或忽略小幅真实移动。

开始前核对开放 PR 文件与本地工作树。除自己的 #604，未发现其他节点编辑器改动；
#575 的相邻 CI 变更未接手。本批以 #604 的 a9763370 为基线独立开发，
不因等待其 CI 而重复推送或取消该已在运行的检查。

另验证真实多节点移动仍提交一个可撤销重做的编辑。
