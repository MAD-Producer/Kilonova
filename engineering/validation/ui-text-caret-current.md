# 完整行字素光标、选区与语法着色验收

本批继续处理 #129 的文字编辑一致性，基于 #609 的 `5468e210`，最终实现源为 `56d55e78`（首轮完整回归源 `a8ec5ff9`）。不关闭整个缺陷合集，不改面板排列、主题值、快捷键路由、字体选择、旧工程兼容或图形预算。

## 原因与最终行为

原单行光标单独测量源前缀；多行点击和选区也反复塑形前缀；语法高亮把每个颜色片段独立塑形。因此 AV 字距、从右到左文本和阿拉伯文连写会与已绘制的完整行不一致。修复共享整行塑形结果：每个扩展字素保留逻辑起止对应的视觉位置，点击选择最近合法字素停点，逻辑选区绘制独立视觉区段，语法颜色附着于原字形簇。单行实际选区可替换、删除、Shift 扩选和撤销；超宽编辑内容按光标滚动，非编辑标签仍使用原截断路径。

制表符保留源字节与展开文本的映射，无制表符路径借用原文本。塑形器可能把变体选择符或其他不可见控制拆成子簇，必须归一到完整字素；不能要求这些子簇本身就是编辑边界。连字内部按原总前进量等分到源字素，不重新塑形，也不在 emoji 序列内部增加停点。

语法回调只能提供展示颜色。它返回的片段若不再等于原文本，生产路径记录有界 `editor_syntax` 故障并绘制原文，防止替换源字形。此前仅有 Debug 断言；这是一项明确的生产行为修正，不能当作新增日志本身。回调自身 panic 继续传播，未新增捕获、重试、重启或修改默认 panic hook。

## 新观察、既有覆盖和剩余边界

`editor`、`caret_boundary`、`editor_syntax` 新故障路径有上述实际默认级输出。`editor_pointer`、`expanded_boundary`、`editor_selection` 是输入/内部映射完整性观察，复用同一有界实例计数器；前两项已由下方补记真实注入，`editor_selection` 仍未单独注入，不宣称其故障验收完成。合法的查询 None、空文本和正常撤销空栈不是故障。

计数沿用既有图集生命周期语义，健康布局和清图集不清计数；替换图集重置。不是“连续 60 次”等同一秒。沿用最多 128 个观察 key、128 字符 key 上限和原有错误上下文；不记录完整源文本。正常绘制不新增文件 IO、告警或全局锁。新逻辑没有工作线程/信道或可能永久等候的新生产操作，原栅格化和字体源故障观察仍保留。

每个缓存行增加每字素两个 f32 及其 Vec 容量，已纳入原布局/截断缓存字节核算，原 128 条、1 MiB 限制不变。冷缓存增加分配；不宣称全帧零分配、所有 emoji 字体支持、整个窗口时延改善或峰值内存下降。双向交界使用“后一个逻辑字素的前沿，EOF 取前一个后沿”的单一停点，不实现双光标 affinity、完整视觉方向键导航或字体 GDEF 连字专用停点；这些边界继续开放。

## CI 回归：空草稿的全选状态（486abeb6）

#610 的 Linux job 127063032673 与 Windows job 127063032649 都在原搜索框测试 `long_unicode_paste_is_bounded_without_selecting_the_retained_text` 失败：预期 128 字，实际只剩 8 字。Windows 其余 1704 项通过、69 项忽略；Linux 其余 1658 项通过、4 项忽略，不能把这两轮称为通过。

根因是 `begin("")` 的全选状态没有实际字节区间，`remove_selection` 提前返回，没有清掉选择标志。第一次插入后该标志仍在，下一次输入便替换前文。现在先消耗选择状态，再按有无区间删除；不改搜索框的长度限制或原断言。非空选择仍替换，撤销可恢复原来的空草稿全选，重做恢复插入后的未选中状态。

三项新增测试在原生产源下实际全部失败，覆盖普通输入、原生剪贴板及多行 Ctrl+A；修复后首次完整 UI 运行 32 个目标、288 项通过（含 compile-fail 文档测试），零失败、忽略和过滤，405.415 秒。随后 FFmpeg 桌面测试编译发现共享 target 混用了另一工作树的 FrameRate 依赖，与本分支源码仍为 u32 不符；保留这次失败，并强制重新编译本分支源进行独立复核。该首次 UI 结果不作为重新编译后的依赖身份结论。

生产修正不增加错误观察、线程、重试或超时：空选择是正常编辑状态。无面板、样式、尺寸、token、菜单或像素绘制修改，DESIGN 十二项既有处置不变；前述截图只证明原绘制范围，不额外宣称本次整窗验收。初次本地命令句柄丢失，后续链接报告本测试的 PDB 损坏；只删除报错指定的本测试 PDB 再构建。另一轮命令误写了不存在的 multiline 测试目标，未执行测试。均保留原输出，没有算入通过数。
