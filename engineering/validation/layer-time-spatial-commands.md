# #257：连续空间关键帧命令的属性时钟

接续 `e380cd73`，提交到已有草稿 PR #579。开工核对开放 PR 与最新本地分支：
#575 负责原生预渲染，#580 负责外部跟踪／校准相机导入，没有发现相同的空间
关键帧时间命令工作。本阶段不审查或改动这两个分支。

## 功能与边界

`SpatialKeyEdit::Time` 和 `Move` 原先声明使用合成时间，执行时却只扣除 clip
offset，或者直接把合成增量当作局部增量。现在使用图层的属性 `LayerClock`：
单键时刻执行完整仿射映射，整组平移乘以带方向的时钟速率。属性时钟和素材
重映射保持分离，命令不读取 source remap，不改动存储格式、采样器或几何值。

按初始整帧选择转换 Roving 时，通过 `integer_key_frame` 恢复确切的有符号局部
键；非整数局部时刻拒绝转换，不取整。倒放使显示次序反转，转换后的局部选择
恢复 authored 顺序，不反转路径几何。已有分数合成投影仍需要后续局部身份入口，
本次没有把它伪装成 u32 帧地址。

连续空间键仍按稳定 ID 改时间。若请求时刻精确等于该 ID 的已有投影，复用该键
原始 f64 局部时刻，避免正反算相差一 ULP 产生伪改动。此恢复只针对指定 ID，
没有 epsilon、邻键匹配或整数舍入；Roving 键主动设时刻仍按原契约固定该键。
保留候选先校验再写入，以及核心的整批事务和既有锁定／通道／范围约束。

## 验证

38 个不同测试通过：新增核心时间映射 5、既有空间核心 8、真实 worker 7、空间
选区交互 8、Roving 菜单计划 10。选区组的 3 项手工原生 GPU 验收未运行，不能
计为通过；本阶段没有改动任何面板或菜单布局，也没有生成新的 UI 样式截图。

新增用例覆盖正放和倒放、负局部时间、分数合成时刻、整组平移、精确投影的
无改动语义、JSON 工程与包保存重开、整次撤销重做，以及未知 ID／非有限时间／
越序／不可表示的初始整帧转换拒绝。成功和失败都比较完整工程，失败还核对
revision、历史和 redo，未只比较返回值或选中的几个字段。

实际桌面 worker 在两个方向执行 Move、Time，再执行先有效移动后未知 ID 的
失败批次；完整工程、revision 和 history 未改变，撤销与重做仍恢复两次成功操作。
默认 MOTION_LOG 下文件和 stderr 各保留两条带原始原因的 Error，stdout 不含
应用日志，私有夹具名称不进入日志。另回归已有六个 worker 错误与取消用例。

逐组核对运行前后二进制 SHA-256，所有桌面组使用同一最终编译文件；四个改动
Rust 源码的哈希与编译后的内容一致。结果和哈希见
[清单](layer-time-spatial-commands-evidence/manifest.json)，复现／构建／测试／
失败信道原始输出见[证据包](layer-time-spatial-commands-evidence/evidence.zip)。
带 FFmpeg 的 workspace all-targets check 通过（3 分 23 秒），样式消费者、
本阶段模型／新增测试模块 rustfmt 及 git diff --check 均通过。

首次新夹具给纯色层设置 source remap，触发现有模型拒绝；新夹具移除不属于
该内容类型的映射，未移除生产校验。首轮转换夹具还包含无法表达为 u32 的
6.5 帧投影；改用确切整帧投影，并保留非整数局部拒绝的独立断言。首次测试
过滤器误用了源码文件名而非 Rust 模块路径，得到零测试，脚本主动判失败；
修正为实际模块路径后运行 8 项。原始失败均保留，既有断言没有修改。
