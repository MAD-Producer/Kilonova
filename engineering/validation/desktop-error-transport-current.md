## 行为与证据

| 项目 | 处理 | 当前证据与限制 |
|---|---|---|
| E1 worker 原生错误 | 新功能修复 | Engine 的同步/异步信道保存共享 Host 错误；真实 worker 的缺失图片 IO、模型 JSON、合成错误保持类型，工程与撤销状态保持，之后仍可处理命令。 |
| E2 所有权 | 新功能修复 | 线程回复保留非零尺寸自定义 IO 原因的地址和类型，错误克隆共享同一原生实例，最后所有者退出后释放。 |

| E4 默认错误信道 | 新增实际验证，沿用既有观察 | 子进程移除 MOTION_LOG 覆盖；三次真实 worker 错误在文件和 stderr 各三条，stdout 零条，文件中开始信号先于错误。没有新增热路径日志，也不把本项当作全部持续降级阈值验收。 |
| E5 正常分支 | 保持 | 离开的回复接收者不停止 worker；受控阻塞触发的超时保留请求和操作，in-flight 可见，释放后恢复；关闭状态有类型。正常取消沿用已有导出提供方契约。 |
| E6 完整回归 | 待验证 | 专项 4 通过、0 失败；全桌面与宿主回归及新提交跨平台 CI 尚未完成。 |

## 原始失败

首次命令因 PowerShell 丢失参数分隔符而未执行测试。随后首轮专项为 3 通过/1 失败：实际子进程通过，但新收集器错误读取 logs/motion-studio.log，真实 logger 写在初始化目录本身。只修正新测试路径，并让子进程失败先保留其输出，不修改生产返回值或既有断言。初次编译被中断且没有完成记录，保持不完整，不计通过。最终专项完整执行通过，源码前后哈希一致。

## 范围

界面提示、MCP JSON 的显示文字在现有文本边界格式化。异步控制器及原测试辅助接口同步接受新类型；原来比较文字的断言显式格式化，预期内容保持。没有依赖、资产、渲染语义或 panels 生产排版改动；DESIGN §0.7 的视觉整改项全部保留，原因是本批仅调整信道与测试接口，不声称截图/交互整改验收。

导出、插件准备等提供方本身的 String 协议、锁失败等剩余文本包装，以及“所有畸形模型返回 Err”的完整验收仍未完成。清单 remaining-text-boundaries.json 只是源码分类，不是已修复或运行验收。不要将本批当作 #138 整体完成。
