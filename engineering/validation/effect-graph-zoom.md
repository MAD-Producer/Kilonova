# 效果曲线垂直缩放验收

基线：主线 `97842545cbb2e980380d25aa96b78c120daa71a7`。
分支：`fix/effect-graph-zoom`。修复 #259 涉及的效果曲线缩放一致性缺陷；
选区适配、锁轴、高倍率采样及迷你图剩余范围仍开放，不关闭该 issue。

## 原问题和修复

Ctrl+Alt+滚轮原来更新 `graph_y_zoom` 后，仍用更新前的局部缩放值计算
本轮绘制。下一次绘制才使用新比例；同时绕范围中心缩放，没有保持鼠标
下的数值。主窗和浮窗共用这段逻辑。

现在更新本轮局部比例，并按原/新比例差调整已有 `graph_y_offset`，让
鼠标处的数值保持相同位置，再用该比例立即绘制。沿用既有 0.25–64
范围、输入条件和编辑期间保护，没有新建视图状态。计算中的 0.5 和倒数
为归一化比例，不是新增 UI 尺寸。时间缩放、偏移和工程数据不参与修改。

源码对照确认只有局部缩放变量和该分支的数学计算改变；参数读取、
采样、绘制、命中区、键/手柄编辑、原错误处理与其余源码保持原文。
本次是功能修复，不把它描述成日志改造或样式整改。

第一轮绘制的差异由实际 panel API 验证；Shell 可能再进行确认绘制，
本次不声称所有原生窗口都肉眼可见一帧延迟。鼠标锚点漂移在随后中性
重绘仍存在，独立回归覆盖了这个不同问题。

## 查重和实际回归

实施前检查 387 个分支引用、两份不同效果图源码、112 个工作树及开放
PR。相关缩放分支均为原算法，没有该文件的未提交改动。没有代为编辑
工具状态、节点查询、剪贴板或三角形裁剪分支。

新增三个测试复用已有真实效果包、Engine、图层、参数轨道以及主窗
`chrome` / 浮窗 `floating_chrome`。测试同时读取实际绘制时登记的关键帧
命中矩形，验证位置，而不是仅检查缩放字段已赋值。

- 原实现两个行为测试实际失败：轮滚帧的键间距为 -158.72726，预期
  -221.52174；中性重绘后锚点为 601.76086，原鼠标位置 570.36365。
  既有输入/取消边界测试通过。原日志是 `before-tests.log`。
- 修复后三个新增测试全部通过。中英文与主窗/浮窗四种组合验证本轮
  距离立即按比例改变、鼠标所在关键帧仍固定、下一次重绘没有跳变，
  水平视图保持、无编辑动作、工程相同且没有新增撤销步骤。
- 锚点验证覆盖放大、缩小、已有非零垂直偏移，以及最大有限滚轮值触发
  两个既有缩放上限/下限；连续八次触及同一限制不累积漂移。位置允许
  小于 0.01 逻辑像素的浮点舍入，未修改任何已有断言。
- 零/NaN/正负无穷滚轮、缺少修饰键和区域外输入保留既有行为；真实
  按下关键帧后，静止拖动期间滚轮不改变垂直视图，Esc 取消没有编辑
  或撤销记录。没有通过伪造成功回复证明这些行为。

最初新夹具给 Escape 传了 bool，实际类型要求 Modifiers，编译失败记录
保留在 `test-fixture-type-failure.log`；只修正新夹具的类型，随后才获得
上述原实现行为失败。没有把编译失败当成行为负面对照。

冻结源码后的最终回归为效果时间轴 12 项、时间轴快捷键 48 项、相关
曲线/采样 6 项，共 66 项不同测试通过、0 失败、0 忽略；包含三个新增
与 63 个既有测试，专项重复运行不累计。产品检查通过，保留产品 20 项、
测试 19 项既有警告。来源、样式使用、新文件格式和差异检查通过。
精确提交的五项 CI 与合入组合仍待核验。

上述为真实逻辑面板输入与绘制，不冒充 HWND、物理鼠标、系统焦点/IME、
多种 DPI、GPU 像素或全应用视觉验收。视图操作不写持久工程；既有效果
编辑的保存重开、单步撤销和失效取消仍由未修改的时间轴回归验证。
