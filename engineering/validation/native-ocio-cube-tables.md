# 原生 OCIO 的有界 3D 表适配

本批继续 #83，把 OCIO 描述器产生的 3D 表接入现有数值缓冲区路线。
没有采用 Float32 硬件过滤、3D 纹理近似或 atlas，没有改动 Naga 或 OCIO
上游源码。2D 表沿用原字符串、样本和编译身份；其 depth 缺省为语义上的
一层，序列化时不增加字段。立方表必须显式给出等宽高深和三个通道。

原生桥合并读取 2D/3D 描述器，保留每张表的原 shader binding，Rust
适配器再为数值缓冲区重新分配绑定。不得把 OCIO 描述器索引误当 shader
binding，也不得再次翻转其着色器已经处理的 RGB 轴。立方表最近邻与
三线性取样由本项目独立实现；四面体分支和权重仍由 OCIO 生成的原始
着色器决定，它请求最近邻只为读取四个顶点，不代表最终颜色采用最近邻。

每表仍限制 262144 个 texel（立方边长 2–64），最多四表。形状、维数、
有限样本、精确数量和乘法溢出在编译/上传前检查。使用已有不可变数值
缓冲区、预算准入、纹理身份与在途资源保留，不新增播放热路径分配或 IO。
原生 ABI 改动随精确桥源码身份一起资格化，不能加载旧桥冒充新结构。
