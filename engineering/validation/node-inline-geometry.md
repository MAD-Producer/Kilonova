## 实现与限制

数值编辑此前先构建整图卡片来查找控件，修改常量、默认输入或公开参数后又因预览版本改变而重建整图。现在活动编辑只查询目标节点原点和原控件行；新按下则逆序查找卡片矩形，只对横向和顶部范围内的候选解析高度。工具栏、库和属性编辑完成后才构建最终卡片和端口规格。

这保留原来的最前卡片命中顺序、半开矩形边界、坐标转换和控件布局。重复节点 ID 的损坏输入仍使用命中卡片的矩形及原先的首个同 ID 节点，没有顺手改变查找语义。普通拖动、参数滑块、文本提交、无效文本、IME、文件快捷键、取消和撤销／重做的行为保持。

候选高度仍可能调用原 `node_ports`，因此“卡片端口规格解析 N 次”不能解释为整帧所有端口 API 总共 N 次。横向／上方未命中不解析高度，重叠卡片的最前命中立即停止；这些由独立计数验证。本批没有改变后续画布语义／结构编辑的重建边界，也没有引入跨帧几何缓存。

## 可复核证据

- 同一新增事务夹具先运行原生产路径。中英文、两种面板尺寸、两种缩放，覆盖常量、默认输入和公开参数三种值源；拖动按正常提交、Escape、焦点丢失结束，另验无效文本和 IME 提交，共 **96 组配置、744 帧**。功能、独立完整几何和历史断言先执行，新的单次构建断言实际 exit 101；168 个数值变化帧均构建两次、解析 2*N 份卡片端口规格。这个实际失败与准备夹具时的 API 编译错误分开保存。
- 优化后，同一事务的 744 帧全部只构建一次卡片、解析 N 份卡片规格；新增计数断言通过，既有断言没有修改。
- 744 帧完整 shapes/colors/glyphs/order、响应、EditorSnapshot、undo／redo、数值输入的绑定／文本／光标／选区／错误、拖动状态和事务前历史，与原路径完整字符串精确相同。没有删除字段或归一化。
- 所有内置图，加重叠、重复 ID、缺失公开参数、有效零端口、折叠／展开和三种缩放，共 **19,992 次命中查询**与原卡片逆序查询的 ID 及矩形浮点位模式相同；包含边角、排除的最大边界、空白和非有限坐标。独立候选计数确认左／右／上方未命中为零次高度解析，完全重叠的前景命中为一次；均未构建完整卡片或解析卡片端口规格。
- 最终 **222 项不同桌面定向测试通过**：节点编辑器 196、帧布局缓存 4、面板 13、Shell 输入事务 7、工作区成本 2；0 failed、0 ignored。独立探针与套件重叠，不重复计数。
- 原视口 312 帧、画布外编辑 64 帧、折叠／展开 216 帧再次与各自原路径记录精确相同；加本批 744 帧，合计 **1,336 帧**。两条真实 Shell 工作负载还分别验证 48 组稳定拖动和 48 次布局变化，保留原断言。
- 带 FFmpeg 的测试及正式 dev 构建通过。独立 LOCALAPPDATA 下启动 `--command-list` exit 0，stdout 为 JSON、stderr 空，未覆盖运行时 RUST_MIN_STACK。这不是原生窗口或 GPU 呈现验收。

## 报错及设计处置

| 条目 | 处置及边界 |
| --- | --- |
| NI-BUILD | 功能优化：168 个实际数值变化帧从两次卡片构建降为一次；同一事务完整记录相等。 |
| NI-HIT | 功能保持：19,992 次独立查询与原完整卡片矩形查找相同；不以计数代替命中结果验证。 |
| NI-ERROR | 既有覆盖：最终实际 `node_port_specs` 仍经过 `observed("canvas.sockets", ...)`；候选高度沿用原 `node_height` 回退，之后仍执行最终卡片的错误观察。没有吞掉 Err／panic、清除错误、添加重试或新增热路径文件 IO。减少的重复卡片解析也会减少重复错误观察次数，不宣称日志次数完全相同。 |
| NI-NORMAL | 正常边界：控件未命中、取消、正常输入拒绝、零端口仍保留原返回和交互；不将它们升级为故障。 |
| NI-FIXTURE | 夹具准备：最初将 Result 当作 Option 调用，编译 E0599；按真实 API 修正后才取得原路径运行证据。不是性能负对照，也没有修改产品错误策略。 |
| NI-SCOPE | 卡片构建计数不涵盖候选高度及图验证；测试记录是 CPU 绘制命令和状态，不是截图、实际 Present 或全帧性能。 |
| NI-PENDING | #134 保持开放：画布内语义／结构变化、通用每帧求解上限、原生 Present／GPU、整帧耗时和峰值、最新 main 完整集成仍未完成。上一批原生节点验收在原125秒期限内未通过，本批不沿用或改写成通过。 |
