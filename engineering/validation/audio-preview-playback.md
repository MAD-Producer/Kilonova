# #274 音量轨道与仅音频预览

新增合成菜单“仅音频预览 / 停止”和可配置的 `Num .`。沿用现有音频输出、混音器、预览范围、起点及循环设置；再次按 `Num .` 或空格停止。手动定位和 scrub 先停止声音，scrub 保持静音，播放与定位不增加工程历史。

音量轨道复用既有实现：音频面板的“在时间轴调节”展开音频属性，增益、左右声道关键帧及静音仍由原命令处理。本次没有再建一套音量模型，也不包含 #273 的电平表、声像和波形面板工作。

| 要求 | 实现与直接验证 |
| --- | --- |
| 音量导航、编辑、持久化与撤销 | `panels::audio::tests` 覆盖左右声道、局部时间、静音、数值输入、关键帧导航、取消、失效来源、保存重开和独立撤销；此次重新执行 |
| 明确的仅音频入口 | 合成菜单实际点击启动真实声卡；浮窗面板输入入口发出相同命令；普通句号、重复、修饰键和 IME 不误启动 |
| 小键盘键位 | 主窗和浮窗共用物理键适配器；区分本地化小数点/逗号与普通标点，NumLock 关闭时保留 Delete；加入改键目录、格式化和序列化 |
| 音量与导出一致、边界不重叠 | 复用 `AudioMixer` 与 Producer；`motion-media/tests/audio_levels.rs` 比较逐样本 dB、分割边界及冻结的导出混音；原有范围/重采样测试验证独占尾边界和循环两侧取样 |
| 有界停止及历史不变 | 实际声卡停止耗时断言；受控阻塞混音的既有取消测试继续通过；回调时钟实际 PCM 经生产 ring/callback 后驱动 Shell，scrub 停声且 revision/历史不变 |
| 纹理保持与恢复 | 真实 GPU 先呈现独立蓝色探针，播放中逐像素比较合成区域，呈现计数不增加；停止后计数增加一，不能沿用冻结纹理的旧时间戳 |

## 呈现与功能边界

`SeekAudioPreview` 同步宿主采样状态但保留最后呈现的纹理身份，`PresentFrozen` 只在文档、视图、表面、窗口、尺寸、质量等身份仍有效时忽略时间差进行复用。保留原帧时间戳，普通呈现恢复时按当前时间重新渲染。UI 截图只读取纹理，不再使它失效。

没有有效纹理、视图/表面变化、内存压力或精度变化时，仍沿用正常重建与拒绝策略，不承诺这些情况下零渲染。宿主采样、编辑叠加层及 UI 绘制继续运行；“仅音频”没有关闭整个 UI。PCM 在已有后台生产者和设备回调中推进，不等待合成呈现门禁。没有新增超时、重启或生产重试。

原生验收使用真实 Windows 隐藏窗口、GPU 和声卡；主窗菜单为真实绘制和指针命中，浮窗面板使用生产 `floating_chrome` 输入入口，未宣称向 OS 注入小键盘按键或手工热拔插设备。中英文改变标签，不改变命令。源 PCM 是独立生成的静音探针；非零声道内容另外经生产回调测试。没有第三方依赖或资源。

## 错误信道与观察审计

| ID | 处置 | 证据与限制 |
| --- | --- | --- |
| O-A1 | 既有覆盖 | 音频启动、混音在途、设备错误、panic、回调停滞和阻塞取消沿用已有观察；此次音频回归重新执行，未修改线程或返回语义 |
| O-A2 | 新增防御观察 | 错误音频计划与仅音频模式丢失输出记录 Error，携带阶段及可用的合成/帧上下文；受控计划错误验证原始原因返回。不是空音频分支，也不把协议防御当成真实设备拔插验证 |
| O-A3 | 既有框架接入 | 新时钟命令沿用非 Present 的请求 ID、处理前 Info/in-flight 与完成清理；冻结呈现仍命名为 `present`，保持健康热路径安静并保留 panic 回复类型 |
| V-A1 | 实际失败验证 | 缺失 PCM 的真实 OS 2 经生产混音工作线程触发停止，Shell 显示原始路径与原因；默认文件和 Error stderr 均保留，stdout 隔离，输出冻结于归档 |
| N-A1 | 正常分支 | 无音频给出提示并保持停止；正常取消和片尾不记录故障，不启动无声墙钟回退；真正缺失 PCM 仍按 V-A1 报错 |
| B-A1 | 明确限制 | 设备启动/释放仍使用原 CPAL 调用，真实本机停止测试通过不等于所有驱动都具有相同延时上限；未加入隐藏线程重启来规避驱动阻塞 |
