# 钢笔子工具验收记录（#232）

分支 `feat/path-node-tools` 基于 #377 的 `4ebcff7`，按该父分支提交堆叠 PR。实施前读取根 AGENTS、DESIGN §0.7/§12、dark.json 和原生绘制/控件源码，核对开放 PR 与本地分支；#349/#362 修改属性筛选和展开，本批只修改查看器钢笔入口及独立 pen_tools 模块。未引入依赖、第三方资产、节点/UI 编辑器架构或新工程格式。

## 功能与协议边界

- 查看器内使用现有 Dropdown 显示绘制与选择、添加顶点、删除顶点、转换为平滑点、转换为角点。枚举不使用按钮循环。菜单宽度首先定义于 dark.json 的 `path.tools.width`，其余几何及颜色复用已有 token；模式提示不属于属性树行。
- 加点在源坐标中进行三次曲线细分，更新相邻手柄并赋予新稳定 ID；命中在投影后的屏幕坐标中求最近参数，保留 7px 容差。开放路径没有虚构闭合边。
- 平滑保留锚点及已有非零手柄长度，方向优先沿已有出手柄；没有手柄时按邻接锚点生成长度。角点收起手柄。转换只写当前局部帧，保留其他节点及其他关键帧。
- 普通路径、几何组和蒙版复用现有 Vector Replace / Mask Path 命令。组、重复器、绘制项及重复节点 ID 的归属通过 item/path/node 寻址保留。参数形状继续使用已有属性栏转换为路径流程，角点宽高操作不被子工具代替。
- 点击准备命令但不修改工程，自己的松键位置有效时只提交一次。Escape、失焦、丢失按键、工程/时间/修订/目标/只读状态变化取消准备；迟到的松键不提交到新上下文。既有引擎串行命令入口负责开始/结束及错误信道，没有新增后台任务或重试协议。

**动画加点语义**：用户确认“保留各关键帧形状”。两端使用相同关键帧时间和缓动，或者其中一端静止时，细分在所有小数帧保持形状。相邻节点使用不同时间或缓动时，新顶点在整条路径所有节点的关键帧时间并集及当前局部编辑帧上生成对应值，随后采用现有线性关键帧插值。相邻原节点仅缩放被细分边的手柄，保留原时间、缓动、自定义时间曲线和另一侧手柄；无关节点完整保留。因此所有已编写的路径关键帧形状与当前帧保留，不声称独立时钟情况下所有未设关键帧的中间形状也逐点相同。没有逐帧烘焙或新增工程格式。

早期检查点 d35655d 对独立时钟拒绝；依据这次明确的功能选择，将它改为上述支持，并增加正向关键帧形状验证。仅本批原有的拒绝夹具改为真正的稳定 ID 溢出失败，不以删除阈值、日志或形状断言代替验收。
