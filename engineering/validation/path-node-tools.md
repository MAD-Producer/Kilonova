# 钢笔子工具验收记录（#232，进行中）

分支 `feat/path-node-tools` 基于 #377 的 `4ebcff7`，尚未发布。实施前读取根 AGENTS、DESIGN §0.7/§12、dark.json 和原生绘制/控件源码，核对开放 PR 与本地分支；#349/#362 修改属性筛选和展开，本批只修改查看器钢笔入口及独立 pen_tools 模块。未引入依赖、第三方资产、节点/UI 编辑器架构或新工程格式。

## 功能与协议边界

- 查看器内使用现有 Dropdown 显示绘制与选择、添加顶点、删除顶点、转换为平滑点、转换为角点。枚举不使用按钮循环。菜单宽度首先定义于 dark.json 的 `path.tools.width`，其余几何及颜色复用已有 token；模式提示不属于属性树行。
- 加点在源坐标中进行三次曲线细分，更新相邻手柄并赋予新稳定 ID；命中在投影后的屏幕坐标中求最近参数，保留 7px 容差。开放路径没有虚构闭合边。
- 平滑保留锚点及已有非零手柄长度，方向优先沿已有出手柄；没有手柄时按邻接锚点生成长度。角点收起手柄。转换只写当前局部帧，保留其他节点及其他关键帧。
- 普通路径、几何组和蒙版复用现有 Vector Replace / Mask Path 命令。组、重复器、绘制项及重复节点 ID 的归属通过 item/path/node 寻址保留。参数形状继续使用已有属性栏转换为路径流程，角点宽高操作不被子工具代替。
- 点击准备命令但不修改工程，自己的松键位置有效时只提交一次。Escape、失焦、丢失按键、工程/时间/修订/目标/只读状态变化取消准备；迟到的松键不提交到新上下文。既有引擎串行命令入口负责开始/结束及错误信道，没有新增后台任务或重试协议。

**尚未完成的动画范围**：两端节点使用相同关键帧时间和缓动，或者其中一端静止时，细分在所有小数帧保持形状；相邻节点使用不同时间或缓动时，其线性组合无法直接表示为现有单一 Track，本版本明确拒绝并保留原数据。不能把这项边界当作完成了 #232 的所有合法动画路径。后续需要确定并实现完整编辑语义后，才能将 issue 标为完成；本批不关闭 #232。

## 已执行验证

首轮 7 项针对性用例通过（3.39 秒）。补充归属、参数转换和默认日志失败验证后，10 项针对性用例通过（3.10 秒）：

2. 同步动画及静止端点，在 -10 至 50 的小数帧上比较细分前后曲线；不改变无关节点轨道。
3. 失效边、开放末端、非法参数、锁定及不匹配动画时钟拒绝，原数据不变。
4. 平滑锚点、手柄长度与共线方向，角点和其他关键帧，删除后不足三个节点打开路径。
5. 0.5/1/2 缩放的曲线参数命中，闭合边和开放边区分。
6. 蒙版/普通路径 × 开放/闭合 × zh/en × 三档缩放的真实 Controls 输入：松键一次提交，重复松键、Escape、失焦、丢失按键和陈旧修订取消。
7. 原生 Dropdown 打开、键盘选择及 Escape；菜单不生成节点，中键保持查看器焦点。
8. 组中相同 path/node ID 的兄弟几何保持不变；组变换、绘制项、重复器保留。
9. 参数矩形先执行既有 ConvertToPath，再加点；绘制属性保留，两次撤销分别恢复路径和参数形状。
10. 独立真实失败子进程清除 MOTION_LOG：默认 INFO 文件、首次 Warn、59/60 阈值、80 次抑制、正常未命中恢复后再次 60 次、两条 Error stderr 和 stdout 隔离；不是伪造成功返回。
