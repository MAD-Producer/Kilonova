## 实际失败对照

`artifacts/pr-ci-followups/track-dimensions-before.log` 对原 main 动画实现执行四项新公开 API 用例，0 通过、4 失败。其中自定义 Tween 的静态值可提取组件，但一个关键帧不可提取，原 separate 在 animation.rs 的 unwrap 实际 panic；另外三项是标量分离状态、乱序键和不支持重建的类型被错误返回 Ok，不能将四项统称为产品崩溃。自定义 Tween 是公开 Rust 接口的直接构造，不冒充正常 GUI/JSON 输入可触达。

`track-axis-edits-before.log` 在 separate 修复后、轴编辑实现仍未改动时执行另外四项用例，0 通过、4 失败。upsert 和 set_at 实际返回 Err 后留下 X 轴的键或静态值改变；七种整组编辑均接受错误的标量所有者，axis_mut 也返回可编辑引用。此记录属于第二阶段原轴编辑实现，不宣称八项同时运行于未修改的 main。修复后的全部模型专项为 14 项；完整回归另计。

正常控制组检查三轴每个关键帧的帧号、值、ease、curve、无 spatial，以及负时间/小数时间样本、重复拆分、合并恢复；既有核心维度/曲线、撤销历史及真实渲染回归继续验证。完整存储不变性用 Debug 快照覆盖全部字段，避免只比较分离 Track 的 PartialEq 而漏掉被忽略的冗余存储。快照只在测试内使用，不记录用户数据。
