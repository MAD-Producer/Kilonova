## 已接入的行为

- Layer 的可选 time_mapping：缺失表示原时钟；存在时 clock 必填，remap 可选。
  当前工程格式改为 32，保留必填 version，只接受当前版本，没有迁移分支。
- layer_time 命令与公开 schema 提供绝对时长比例、连续 clip 中心倒放、显式清除/设置
  素材 remap 和重置。保留原轨道的本地键、值及曲线，不重写键数据来伪造变速。
- 同时调整 clip 时绕显式锚点缩放，保留该合成时刻的属性局部时间；重置保留当前 trim。
  相同比例是 no-op，不重定锚点、不增加 revision/undo。两次倒放恢复规范化原时钟。
- 候选 Layer 全部准备完成后才替换。核心事务继续负责整批、准备失败、真实文件发布
  失败及取消手势回滚；来源查找/映射失败保留对象、phase 和原始 cause。
- Project 属性编辑，以及效果、音量、标记和插件编辑器的已有整数入口使用属性时钟。
  非整数本地时刻明确拒绝，不能四舍五入改到另一个键。连续寻址仍是下一阶段任务。

## 保留的失败及修正

1. 初版新增工程测试 5 通过、3 失败：相同比例重定锚点/显式化 trim，两次倒放留下
   冗余 identity，serde 单元变体接受未知字段。修正实现：不变比例不重新创作数据，
   identity 在构造时规范化，空命令使用受 deny_unknown_fields 约束的空结构变体。
   原断言保留，最终 8 项全部通过。
2. 一次完整模型编译与核心编译并发触发本机页面文件不足（os error 1455 / mmap）。
   确认首轮编译任务已结束后，以单个编译作业完成模型回归；没有更改生产预算、断言或超时。
3. workspace 检查首次误把二进制名 motion-studio 当成 Cargo 包名；使用实际包名
   motion-desktop 完成检查。原命令错误和先前 schema 负号类型错误均保留。
