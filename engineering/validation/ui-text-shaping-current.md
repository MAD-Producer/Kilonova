## 当前实现边界

独立 RunShaper 使用固定 HarfRust 0.15.0，对单一字体、已解析方向的运行输出
glyph ID、UTF-8 cluster、字形偏移与 advance。字体索引显式传入，支持字体集合，
字体字节共享持有。无效字体、超长运行、无效方向及塑形引擎错误均以类型返回；
原引擎错误保留 source，不悄悄回退逐字符布局，也不记录完整用户文本。
单运行输入上限 16 KiB，在清空缓冲或启动塑形前拒绝超长文本。

这还没有替换 TextAtlas::measure、fitted_text 或 UI draw_text。当前模块不是整段
文字布局器：混合方向/脚本分段、字体回退、emoji 字体/颜色字形、塑形字形的图集
栅格化、宽度裁切及有界布局/计划缓存都待接入与验证，不能勾选 #129 最后一项。
缓冲复用也不等于整个塑形调用零分配；字体布局计划与冷路径尚未做性能验收。
正常无效输入作为返回错误交由调用者处理；接入应用时还需在真实失败边界验证
默认日志、原因、抑制和恢复，不把组件返回 Err 当成全应用可观测性已完成。

## 字体源与集合索引整合

下一步已将主字体、CJK 后备字体及显式字体构造器的实际 face index 传给塑形器，
不再丢弃 TTC/OTC 中的字体面索引。塑形源通过 FontArc 共享已持有字节，不再复制
完整字体缓冲；字体覆盖查询已使用对应塑形面的 cmap。无法建立塑形字体时从
构造器返回原原因及索引/字节上下文，不以第一个字体面替代。

TextAtlas::new 现在要求显式 face_index 并返回 Result；系统入口保持原有 Result
接口。两个既有测试夹具仅传入数据库原本提供的真实索引并处理构造结果，原有
像素、字体、溢出、分配与交互断言均未修改。

两项新增验证覆盖非零集合索引和主/后备字体映射。本机实际检查了 23 个非零

## 塑形字形 ID 的图集入口

增加显式主/后备字体槽和 glyph ID 栅格入口，不把塑形结果重新映射为字符。
新旧入口复用位图生成，两个缓存共同更新图集增长后的 UV；新缓存最多保留
8192 个键，包含不占图集的空字形。非法字号/ID、缺字体面、缺轮廓、图集或缓存
耗尽返回带字体槽及 ID 的类型化原因，失败不缓存。空格正常返回空位图和 advance。
这不是应用日志通道验收；真正接入绘制时仍需验证持续降级、恢复和默认日志。

六项新测试覆盖五种 DPI 的新旧像素/度量对照、两类缓存增长后像素与坐标保留、
非法请求无写入、同 ID 不同字体槽隔离、图集/键上限拒绝及恢复、空格与缺轮廓。
首次定向运行 2 通过/1 失败：夹具使用英文构造器却假定没有 CJK 后备。仅明确
构造缺字体面状态，保留原断言；原始失败归档。字体槽夹具选择实际安装的 Latin
字体，不假定每个平台都有 Arial，没有新增字体资产。

最终标准 Cargo 执行完整 UI 库 99、atlas_bounds 2、text_bounds 9、text_shaping 3，
共 113 项不同测试通过，0 失败/忽略。定向六项已包含在 99 项中。原有断言、预算
和测试配置未降低；显式 TEMP/TMP、单编译任务与单测试线程，MOTION_LOG=info。
实际 CPU 图集像素对照不等于窗口截图；既有 text_bounds 的 GPU/分配断言也保留。
源码/程序哈希、原始成功与失败见 ui-glyph-index-evidence。尚未切换产品文字布局，

## 字素、脚本和双向运行布局

新增 layout_line：以 em 为单位输出实际字体槽、塑形 glyph ID、源 UTF-8 cluster、
位置和 advance。字体覆盖按完整字素判断；相邻同字体/脚本/双向级别合并为运行，
避免逐字素塑形破坏阿拉伯文连写。公共/继承脚本从同级邻近强脚本解析；运行按
Unicode 双向算法的级别排序，保留数字内部顺序。Unicode 双向依赖固定为 0.3.18，
上游来源、revision、crate hash 和原许可已写入 ATTRIBUTION/NOTICE。

输入上限 16 KiB、输出上限 16384 字形。单行接口拒绝多段文本，不把错误或缺失
字体转换为逐字符成功。未覆盖的字形明确保留 ID 0 和 missing_glyphs，尚未提供
彩色 emoji 栅格能力，也没有声称所有字体与脚本已经验收。调用边界还需处理这些
降级；当前类型化错误不替代实际应用默认日志和阈值/恢复的验收。

布局缓存为每字体图集最多 128 条、1 MiB 的有界 LRU；容量按保留向量 capacity
计算，字号重置时清空。命中返回共享 Arc，不复制标签或输出数组。六项新单元
测试覆盖 NFC/分解标记等价、真实阿拉伯文字体连写及标量负对照、混合方向排序、
字素/字体槽选择、条目上限和字节预算淘汰、拒绝后正常恢复。独立分配控制验证
四类文字的 1 对 200 次命中全部零分配；这不代表冷路径或整个应用零分配。

首次独立目标编译因本机提交内存余量不足被主动取消，保留进程身份、当时余量和
原始输出，不称断言失败或运行通过。没有降低断言、预算或产品参数；之后复用
既有目标执行完整 UI 库 105、atlas_bounds 2、text_bounds 9、text_layout 1、
text_shaping 3，共 120 项不同测试通过，无失败或忽略。六项布局单元包含在
105 项中，上一阶段 113 项也被本次覆盖，均不能累加成额外通过数。
