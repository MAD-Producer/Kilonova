# 动画预设与效果菜单验收记录

对应 #225 / #265。#259 由其他 agent 负责，本分支不修改曲线视图范围和锁轴功能。开始前核对了本地分支与 PR 元数据，复用现有收藏、最近效果、批量移除、引擎任务信道和事务。

## 行为契约

- 自有 `.msanim` ZIP 格式，`animation-preset.json` 必须为当前预设版本 1；不导入或分发其他产品的预设、界面资产或文案。没有新增依赖或第三方资产。
- 保存变换属性（锚点、位置、缩放、旋转、不透明度）及选中的效果、参数与关键帧。界面分别明确“此图层变换与效果”和“仅此效果”；核心接口还允许显式属性子集。
- 按用户选择保留原始像素坐标、像素参数与锚点像素位置。模型内归一化锚点在保存时乘源图层尺寸、应用时除目标图层尺寸。没有按目标合成大小缩放动画。
- 原值在目标图层已有的父坐标系内解释；预设不修改父子链接、图层尺寸、3D 开关或时间范围。本轮没有修改渲染语义、效果包格式或像素基线。
- 最早的已选关键帧对齐播放头；相对时间按源/目标 fps 四舍五入到目标帧，保留秒数，允许至多半帧量化误差。不同关键帧若被合并到同一帧，整次拒绝。分离轴、空间切线、时间曲线与颜色曲线一起保留。
- 只替换显式保存的变换轨道，效果按原栈顺序追加并分配新 ID；不修改目标图层尺寸、名称、可见性和时间范围。所有目标在同一个事务内提交，一次撤销。
- 只携带所选效果引用的图片（含附属精灵图），不保存无关图层、源文本或完整工程。新图像 ID 避开图片、音频、视频与模型共享的全局资源空间。效果包依赖保留 plugin/version/hash，应用前由宿主核对安装状态、效果定义与公开参数 schema。
- 携带图片在文件工作线程中逐个完整解码，复用既有 `image_resources::decode_with_budget` 的独立调用预算；每次只保留一张解码结果，不修改 Session 的运行时预算、等待期限或重试策略。解码失败时不提交工程，并清理该操作的暂存图片。
- 锁定、缺失、类型不兼容、表达式控制的目标属性、缺依赖、不可移植的图层图像输入、资源错误和帧率碰撞均为明确失败，不部分提交。表达式不在本预设版本的保存范围，保存前明确拒绝其所选属性/效果。
- 原子发布完整预设包；取消或失败清理本操作独占创建的暂存文件，保留原文件。真正提交后，即使后续快照失败，也保留撤销/重做仍可能引用的资源。成功发布后的迟到取消不伪称未保存。
- 用户库是工作区配置旁的 `.presets` 目录及直接子目录；子目录用于分类。库外保存的包可通过“从文件应用预设”使用。每次显式扫描最多 512 个文件系统项、128 个预设，略过符号链接，损坏项显示失败计数并写 Error。

## 错误与观测边界

新观测：预设 IO 任务有有界 request ID、阶段、开始时间和取消状态；Info start 在进入文件/解压/处理函数前写入并 flush。默认 Error 保留原始原因和有界上下文。目录空、显式取消与过期请求属于正常结果；取消不吞掉已经发生的独立失败。单个应用只保留一个未完成任务，底层 IO 未返回时保留任务槽和状态，不通过超时重启隐藏问题。

既有覆盖：快照和最终提交经过串行 engine 的开始信号、in-flight 状态、错误回复、panic hook 和默认日志输出。资源预检与模型事务复用宿主，未改变 Present 热路径日志策略。

协议边界：窗口关闭后接收端退出，工作线程回复仍为 best effort；未接收的暂存输出会释放独占文件。没有新增每帧文件 IO、循环重试或无限错误键。文件对话框取消不产生故障。

| 审计项 | 分类与实际证据 | 剩余限制 |
| --- | --- | --- |
| AP-O1 工作线程开始/阻塞 | 新观测；受控阻塞时先见 queued/io 状态和默认 Info start，再释放处理函数 | 没有增加自动超时或重启 |
| AP-O2 缺文件、插件、schema、锁定 | 新控制器观测 + 既有引擎信道；真实失败、原原因、工程和 revision 不变；默认文件与 Error stderr 均有记录，stdout 为空 | 精确依赖不提供兼容替代 |
| AP-O3 损坏图片及恢复 | 功能预检 + 新观测；真实 PNG 解码失败清理本操作文件，随后有效 PNG 应用成功 | 一次完整解码一个资源，沿用既有预算 |
| AP-O4 panic | 新 worker catch 与既有 panic hook；真实受控 panic 保留原因、结束状态和 stderr | 不吞 panic 后的原失败，也不重启 worker |
| AP-N1 空库/取消/过期 | 正常分支；取消和过期不写工程，不记故障；独立真实 IO 错误仍保留 | 已发布后的迟到取消仍报告已保存 |
| AP-P1 原子资源与撤销 | 功能/事务边界；包替换、取消清理、资源重映射、单步撤销/重做/重开 | 已提交的资源保留供历史使用；没有实现通用资源 GC |
| AP-O5 清理失败 | 新 Error 分支保留原始失败并界定独占路径；正常取消和解码失败的实际清理已验证 | 尚未注入操作系统 unlink 自身失败，不能声称该故障已运行验收 |
| AP-U1 菜单输入归属 | 功能修复；真实双窗口的外窗被动重绘、外窗 Space、菜单 Space、IME composing、焦点丢失与取消 | 非 OS 级 IME/实体输入验收 |

新 IO 任务为单次请求错误而非连续热路径降级，不引入 60 次累计计数。目录扫描条目、资源/包大小、请求上下文与保留原因均有界。效果菜单收藏、最近使用、批量移除和原有主/浮窗测试属于既有覆盖，本轮只补入口和归属，不把原有能力计作新实现。
