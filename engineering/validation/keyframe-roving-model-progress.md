# Roving：稳定身份与连续时间模型

基于 `56400af5`，本阶段新增 `SpatialKeyTimes`、`SpatialAnimation<T>` 和不可变的
`PreparedSpatialTiming`。这是可独立保存、重开及取样的模型组件；尚未装入工程的
`Track`、核心命令、剪贴板或 UI。#260 仍打开，不能将下面的模型验收称为产品已经
支持 Roving，也不能用模型 JSON 重开替代完整工程重开。

## 数据和当前语义

每个空间键有独立的 `id`、`fixed: Option<f64>`、`reference`、数值及空间切线。
`fixed: null` 明确表示释放时间约束；缺失 `fixed` 字段会拒绝读取。首尾键固定。
`id` 在轨道内唯一且非零，编辑值或派生时间不改变它；`next_id` 持久化，删除后
不会复用身份。`reference` 是全静止区间的有序比例坐标，不是寻址 ID，也不是
有效时间。将一个键固定到当前小数时刻，不会按 reference 或有效时间重新排序
作者数组，更不会把属性值移到另一个整数帧。

当前求值策略是相邻固定键之间按真实弧长分配时间，并按各段弧长反查空间参数。
重复点可以有相同有效时间和不同 ID；全静止区间按 reference 保留作者比例。
固定化只改变所选键的时间所有权，保留当前小数时刻、其他键策略及几何。编辑固定
时间会显式解除该键的 Roving 策略；跨越另一固定键的几何重排仍需后续所有者事务。

模型只导入显式线性时间策略的耦合 2D/3D 轨道。有手动空间曲线时，采用其真实
弧长，不以端点距离代替回环。Hold、已有缓动、自动贝塞尔、拆分轴、颜色打包向量
等未完成转换语义的组合会明确拒绝，不清除原策略后假装导入成功。该限制是待办，
不是 #260 范围缩减；宿主还须识别位置/锚点语义，不能因三维数值存储便开放缩放等属性。

每份组件最多 16385 个键，时间和 reference 在有符号 32 位帧范围内使用 f64；
JSON 序列读取也限制键数，不先无限读完整个键数组。路径沿用前阶段的全局预算。
取样使用已准备的不可变几何；编辑、插入、删除及反序列化在发布新状态前完成准备。
健康取样不分配内存，不进行文件 IO，不重复准备几何。

   导出，并限制参数语义。工程保持单一当前版本检查及版本字段，不添加旧版迁移。

   拖动/菜单/取消、工程代次、撤销和预算计量。删除末段转静态及键序重排由同一所有者
