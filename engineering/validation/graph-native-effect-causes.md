# 节点编译与导出的原生效果包错误

关联 #138，分支 `fix/graph-native-effect-causes`。实现基线为 `24d06f1566a20210f9dcf829686c5beb1026cf0f`；该基线随 #454 合入主线。

## 改动与边界

图编译和效果包导出的九个适配点将 `motion_effects::Error` 转成文字后放进 `Invalid(Diagnostic)`，标准 `Error::source()` 无法再访问原生 ZIP、JSON 或注册表错误。本批使用 `Effect { diagnostic, cause }` 保存原对象。`diagnostic()`、错误码、节点/端口字段及显示文字沿用原规则；原因通过声明的 `Box<motion_effects::Error>` 暴露，不从文字重新构造。

编译器两处涉及 shader 编译与 manifest 校验，导出七处涉及内存包加载、注册、解析、旧目标检查及暂存包复读。九个适配点不等于九个独立故障。没有新增日志观察点、计数器、线程恢复、重试或默认值，也没有修改导出文件内容、渲染语义、版本规则、依赖或素材。

后台任务继续使用既有诊断/文字回复和日志信道。本批保留库层原因，不宣称已经完成整个 worker 协议的类型迁移。发布回滚的复合文字错误、按构造成立的私有 unwrap，以及其他模块的错误类型仍待处理，#138 保持开放。
