# 桌面音频与合成入口验收

本轮复用既有 `Command::SetAudio`、`Command::AudioLevels` 和 `CompositionAction::Create`，没有新建音频模型或渲染语义。基础增益的合法线性范围仍为 0–2；界面转换为 dB，0 对应 −∞，未改动的数字提交保持原值，静音开关不改增益。左右包络读取宿主公布的 dB 范围，沿原有层本地帧和混音采样路径执行。

## 可发现入口

- “窗口 → 音频”：选音频/视频图层编辑基础增益、归零、重置和静音；选音频/视频/子合成图层编辑左右声道包络。
- 每个声道提供动画开关、数字输入/拖动、上一键、增删当前键和下一键；“清除左右声道包络”明确移除两声道动画。
- “合成 → 新建合成”与 Ctrl+N 共用原来的表单和创建流程，取消不改工程，创建保留当前图层和素材。

## 自动回归

`panels::audio::tests` 通过真实宿主和完整主窗/浮窗路由验证中英文数字输入、静音/最大值、无输入的反复提交、拖动松手最终值、一轮撤销、Esc/失焦恢复、锁定、输入法/快捷键隔离、无能力禁用、声道独立、偏移帧导航、当前键增删和保存重开。重新打开的数据通过实际 WAV 解码及冻结 PCM 混音器检查增益和声道值；后续 UI 编辑不能改变已冻结的混音器。

`shell::presentation::interaction_tests::composition_menu_creates_in_the_existing_project_and_cancel_is_read_only` 从真实菜单动作进入实际表单，验证取消、创建、保留图层、保存重开和撤销。

`tools/ci_desktop.py` 的中英文所有面板原生窗口验收为音频面板生成原创立体声 WAV、真实图层和左右包络数据，捕获实际 GPU 浮窗截图。窄窗会把数值与导航按钮分行；原有样式覆盖、重新停靠、节点 GPU 预览和共享会话验收继续执行。

## 手动复测

1. 导入 WAV 或含音轨的视频，打开音频面板。将基础增益输入为 -6.0206 dB，确认约为一半振幅；静音/取消静音保留数值，0 dB 恢复单位增益，−∞ 归零。
2. 将片段移动到合成第 10 帧；在第 10 和 40 帧给左声道分别设置 0 和 -6 dB，右声道固定 -12 dB。在第 25 帧查看左声道约 -3 dB，◄/► 定位到 10/40 帧。
3. 在左声道当前键上点击 ◆ 删除，只影响该键；撤销恢复。清除包络后撤销恢复两个声道及其动画。
4. 主窗、浮窗各拖动一次，最后松手位置是提交值，一步撤销恢复整个手势。拖动中 Esc、失焦、锁定或切换目标要恢复；数字/输入法编辑中的 Space、Delete 不触发播放或删除图层。
5. 保存并重新打开，试听或导出验证。多选图层时音频面板只编辑主选；锁定不能编辑，关键帧导航保持可用。
6. 在已有图层的工程通过菜单新建合成，取消后原状不变；确认后原图层保留，新合成可保存重开并撤销。
