# 桌面时间轴音频、节奏参考与级联菜单验收

在时间轴展开图层，视觉图层有“变换”，音频、视频和子合成有“音频”分组。两组共用属性布局：分组标题下面的属性缩进一级，秒表、属性名和数值列对齐。音频行不单列前后关键帧或菱形按钮，使用秒表启用动画，修改数值添加关键帧，并在轨道中选择、拖动和删除关键帧；J/K 沿用时间轴导航。基础增益和左右包络复用共享的 SetAudio / AudioLevels；数值输入、拖动、秒表和轨道内关键帧编辑共用宿主历史。增益行的扬声器图标切换静音。音频面板改为摘要与跳转入口。数值编辑中的 Enter 不会启动图层重命名。

## 入口与持久化

- 音频分组：基础增益、静音、左右 dB、关键帧。参考标记显示在顶部时间标尺下沿，使用带编号的小标签；编号按各来源内的时间顺序排列，裁剪隐藏标记时保留编号。标签左下角对应准确时间，点击整个标签定位、拖动移动，选中后 Delete 仅删除该项。密集标记保留位置，放大后显示编号。标尺左侧“+”在当前播放头添加手动标记，Alt+点击标尺在鼠标处添加。
- 时间轴图层右键 → 悬停“音频”：视频音频分离、分离左右声道、生成节奏参考点、添加手动参考、重置声道包络。右键展开的音频属性会直接打开该级联分支。
- 右键分析标记或音频属性提供“选择/删除本音频的分析标记”，仅存在自动标记时显示；选择后 Delete 以单个原子批次删除所选分析标记，不删除图层或手动标记。取消分析仅在该图层分析进行中显示。
- 一级菜单保留，二级菜单与分类行对齐并在右侧展开；窗口右侧不足时向左展开，窄窗限制两级菜单宽度。悬停不改工程，普通功能点击执行，支持键盘导航、Esc 和外部点击关闭。
- 分离产生 L/R 音频轨，复用原素材，不重编码；每轨只输出对应声道，保持原增益、时间、包络和标记。视频保留画面并静音原音轨。单声道和已分离轨禁用该操作。
- ExtractAudio 将视频音轨提取为一个独立音频层，同时静音原视频音轨；立体声和单声道均可。有效范围按音轨实际样本截取，保留源偏移、子帧边界、增益、静音、包络和参考标记；无音轨、无有效样本、锁定或图层数量超限时原子拒绝。
- AudioMarkers / SplitAudioChannels 在共享模型、命令注册表、能力声明和历史中接入；标记和声道隔离需要格式 18。旧工程可读取，无该数据时不升级版本。
- 标记按图层本地帧保存，移动、裁剪、分割和保持秒数的帧率调整保留时间关系。重新生成只替换自动标记；手动标记、拖动修正后的参考保留。
- 标记在标尺上的位置由图层偏移换算，真实主窗/浮窗拖动音频或视频片段后可在新位置点击定位。提取时标记转移给新音频，分离声道时只保留在左声道；原视频和右声道不保留重叠副本。
- generated 保存分析来源，corrected 单独记录手动修正。重新分析保留修正点并避免与保留点重叠；明确批量删除时仍包括修正过的分析标记，手动添加的标记保留。旧记录默认未修正。

## 分析边界

复用 prepare_audio 的后台解码与 100 Hz RMS 缓存，在独立工作线程分析可见片段内的正能量变化、局部峰值和自适应阈值，抑制 120 ms 内重复攻击。最多 4096 个参考；超过上限提示缩短片段。时间换算考虑素材起始偏移、图层偏移、裁剪和合成帧率，最终吸附到整帧。静音和稳定信号不补造规则节拍。

这些点用于卡点参考，不估计 BPM，也不承诺每个音乐拍点都可识别。当前分析支持单一音源的音频和带音轨视频，子合成只提供声道包络；用户可分析内部音频图层。

工程、合成、音源、片段范围或帧率变化会丢弃过期结果；取消和失败不产生编辑。结果等待既有编辑确认后，以一个共享命令加入撤销历史。读取波形和检测不阻塞 UI 线程。

## 可核验覆盖

- 完整主窗/浮窗路由：中英文增益输入、−∞/上限、反复无改动提交、静音、拖动最终松手值、一轮撤销、Esc/失焦、锁定、IME/快捷键隔离、能力禁用。
- 声道键：本地时间、只改目标声道、导航、拖动和 Delete 不删除图层；保存重开及冻结 WAV/PCM 实际混音。
- 参考与分离：保留手动/修正标记、原子拒绝非法批次、移片/分割/改帧率、锁定、撤销重做；分离轨实际 PCM 之和等于原混音，另一声道精确为零。
- Shell 后台流程：真实原创 WAV 解码、波形分析、素材偏移/裁剪/图层偏移换算、手动参考保留、一次撤销、取消和过期结果丢弃。
- 级联菜单：主窗和浮窗中的悬停、左右边缘展开、一级内容保留、子项点击及撤销。节点添加器的左侧分类也支持悬停显示右侧内容。
- 宿主传输：修复 typed InComposition 命令在解析时丢失 composition 字段的问题；普通扁平命令保持兼容。真实桌面宿主执行右键复制及行内重命名，覆盖主窗/浮窗、中英文、IME、取消、保存重开和撤销；跨合成相同 ID 不串改。
- 子合成输入：主窗和浮窗生成的编辑命令绑定生成时的合成，增益、左右包络和秒表通过真实宿主执行，保存、撤销均不修改主合成的同 ID 图层。
- 原生 GPU 验收：时间轴浮窗使用真实音频层、包络和参考点；音频浮窗显示摘要。保留中英文、样式覆盖、重新停靠、节点预览和共享会话检查。

## 人工复验路径

1. 导入立体声 WAV，展开时间轴“音频”。输入 −6.0206 dB，拖动后松手，验证数值和撤销。静音再取消保留增益。
2. 移动片段到第 10 帧。在 10、40 帧给左声道设置 0、−6 dB，右声道固定 −12 dB；第 25 帧左侧约 −3 dB。拖动关键帧，Delete 和撤销只影响对应键。
3. 图层右键，悬停“音频”，确认一级菜单保留且子菜单在侧面。生成节奏参考点，顶部标尺显示小旗；点击定位、拖动修正，重新分析后修正点仍保留。右键小旗选择全部分析标记后 Delete，确认手动标记保留，删除一步撤销。
4. 分离左右声道，分别试听和调节；合并播放保持原音频。保存重开检查标记、包络和声道隔离。
5. 对带音轨的视频运行“音频分离”，验证新增音频层与画面对齐、原视频音轨静音，撤销一步恢复。重复主窗、浮窗和中英文入口；锁定图层时禁用编辑，分析过程中改动片段或取消均不写入过期标记。
