# Roving 类型入口与实际输出验收

接续 #260 / PR #576，源码基线 `87aad8c4`，main 基线 `49890ce0`。
开始前核对远端 PR：另一个 agent 的 #575 后台预渲染仍在进行，未修改其分支、
根工作区或构建目录。本轮不引入依赖、第三方素材、迁移、主题 token 或属性行布局。

## 交付行为

动画菜单增加 Roving 启用与“固定所选 Roving 时间”。固定保留当前连续时间和完整
取样，不退回旧整数帧存储。菜单区分全部 Roving、全部固定、部分 Roving，快捷键
`Ctrl+Alt+F8` 只标在当前实际执行的那一行。偏好设置可重映射；新绑定不会夺走已保存
的显式自定义组合，交互式冲突仍被拒绝。

耦合位置、二维锚点、全局及图层摄影机的位置／目标使用真实作者轨道的模型验证。
端点、保持区间、分离轴、非空间属性和不支持的混合选择整体禁用，不能派发部分编辑。
混合整数与空间存储可一次转换，已有 Roving 通道参与原子批次；一次撤销恢复完整工程。

初次转换后，只有相同工程身份、相同原选区、下一修订及完整预期轨道全部一致时，
才把原整数选区重新绑定到稳定 ID。worker 未结束时保留一个有界待处理记录；换工程、
换选择、取消、无关修订或不同结果会废弃记录，迟到的快照不能恢复过期选择。
正常取消和能力不足不记故障。普通动画选择与空间选择仍共用既有输入和命令路由。

## 可复现验证

本轮 **197 项不同测试通过**：动画菜单 29、快捷键及文档 12、菜单导航 5、
选区 41、时间轴快捷键 55、键盘 28、时间轴曲线 4、比较图 15、取样缓存 5，
另有原生菜单、默认栈大轨道故障和真实编码各 1 项。重复试跑不累加数量，ignored
不算通过；原生／导出用例是显式执行的手动验收，不冒充默认 CI 已覆盖。
Windows FFmpeg/GPU 测试构建与带 FFmpeg 的实际应用构建均通过，后者为 dev 构建，
不是 release 发布包。分别保留 27、29 条编译告警。样式消费者检查和 diff 检查通过。

- 实际鼠标点击菜单派发一个带来源的 `EditorAction`；中英文菜单的取消、工程／
  修订／选区失效不派发编辑。主窗与浮窗 owner 的快捷键命令相同；文本、IME、
  OS 重复键、失焦、只读和过期选择禁用。绑定冲突、重映射和旧显式绑定保留均通过。
- 原生 GPU 捕获中英文 × 普通／Roving／固定／混合共 8 张 1280×960 原图。
  隐藏原生窗口通过真实 worker 转换、固定、撤销，检查完整 project / revision /
  history；绘制本身不能改工程。这不是物理鼠标、多 DPI 或 macOS/Linux 图形验收。
- 位置、锚点、全局与图层摄影机的成功转换、固定、稳定 ID、图层时间偏移及完整
  工程撤销通过；200 个采样点逐值比较，固定不改变结果。保存重开严格比较工程。
- 默认线程栈故障回归保留 33,000 键、12 站点和原断言，225.31 秒通过。该程序与
  导出程序之间仅新增独立导出测试模块；未改变 Panels、生产逻辑、线程栈或预算。
- 真实 20 帧 MP4 冻结快照在实时工程撤销并关闭后仍完成编码。六个时点核对模型
  位置、PNG、实际解码像素的白色主体中心，偏差均小于 1 像素。第 8 帧 PNG 中心
  x=56.5，解码 x≈56.281，未启用 Roving 的负对照 x=29，明确不接受旧整数时序。
  独立进程重开严格比较完整工程，六张 PNG 逐像素相等。视频验证针对位置和时序，
  不声称有损 MP4 与 PNG 每个像素一致，也不替代全部渲染效果的基线验收。

首次导出验收的 PNG 与编码通过，但重开比较失败：测试把 Project 的 f32 短小数
JSON 当作 worker Value 的 f64 精确提升表示。夹具改为保存完整原始 worker 工程
Value；完整相等断言、像素断言及所有阈值均未更改。首次日志、图片和视频保留，
不算最终通过。其余首轮编译遗漏的泛型序列化约束、偏好命令名和测试 Platform
trait 导入已补齐，原编译输出也保留。
