# 节点画布绘制查找优化验收

本地基线：主线 `7a3ee2bd3a02fe37f2c58902cd30110f80ff1a9b`。
分支：`perf/node-paint-lookup`。本次推进 #134 的节点画布查找部分，
合集保持开放，不把其他重复布局、绘制或节点规格计算记为完成。

## 改动和边界

`paint_canvas` 原来为每张可见卡片从头扫描 `document.nodes`，在大量
可见节点时重复进行二次量级的 ID 比较。现在使用一次绘制内的借用查询器：
前 32 次查询仍执行原查找，第 33 次才构建一个 ID 到节点引用的散列表。
32 是元数据查询次数，不是像素尺寸；计数停止在 32，不会回绕。
只有超过这个查询量的绘制才分配索引。全部卡片被裁掉时不查找、不建表。

键和值借用当前文档，既不克隆节点/ID，也不跨绘制保留。表的键数最多
等于当前节点数，绘制返回时释放；编辑、删除、换组、撤销或替换文档不会
命中旧表。重复 ID 仍返回文档中的第一个节点；卡片乱序或只包含子集时
不依赖卡片与文档位置对应。缺失 ID 的查询仍为 `None`，原绘制调用者的
`unwrap` 边界保留；本次不宣称修复外部伪造可见卡片造成的既有 panic。

源码逐字对照确认：除导入、局部查询器和该查找表达式外，原 `cards`
及全部绘制逻辑保持原文。颜色、尺寸、顺序、裁剪、标签、输入、命中区、
端口观察、历史和序列化均未修改。当前函数中其他查找、规格计算与分配
仍存在；不是整个画布零分配或全部 #134 完成。

## 对照和验证

实施前检查 383 个分支引用、12 份不同画布源码、113 个工作树及开放 PR。
全部源码仍采用相同的逐卡片查找，没有相关未提交改动。#471 的剪贴板
与 #472 的工具工作不修改本段绘制，未代为编辑其他分支。创建 PR 前主线
已合入 #471；其 19 个变化路径与本次三个文件没有交叠。本地结果不替代
这个新组合的 PR CI。

临时探针保留原画布源码，只给两个函数改名，与修改后的真实绘制在同一
测试进程、同一系统字体图集中对照。中英文 × 900×600/400×400 逻辑区域
× 0.25/1/2.5 缩放 × 六种卡片场景，共 72 组。场景包含足以进入索引路径
的 64 个附加节点，以及倒序、子集、重复 ID、无效/区域外卡片和空卡片；
同时覆盖选择、预览、拖线和切线反馈。预热消除图集首次增长的 UV 差异。

全部形状、颜色、字形位置/UV 和创建顺序的调试表示逐字节一致，绘制不改
文档和 revision。拼接记录 8,035,933 字节，SHA-256 为
`6837c8778177ac75d4e1182ec5345d13fc8e379d2c528a9d0724a944c4a98598`。
这是命令对照，不冒充 GPU 像素、物理输入或系统窗口/DPI 验收。

同一探针对 1024 个折叠节点执行四轮交替次序的 20 次真实绘制。成功的
分配/重分配请求和请求字节由线程局部分配器记录，并以字符串分配校验
计数器。下表耗时为四轮中位数，单位微秒；不是发行构建、FPS、峰值内存
或跨机器性能承诺。少量可见卡片计时有波动，不能解释成统一提速。

大场景样本约减少 3.6% 绘制耗时，代价为每次绘制增加一次索引分配和
51,216 请求字节；表随绘制释放。0/1/16 张可见卡片没有新增分配。
最初每次可见绘制都建表的探针发现小场景成本上升，已改为上述延迟策略；
最终数据为冻结源码后的重新编译结果，初稿结果不作为最终通过证据。

四个新增测试覆盖重复/中文/空/NUL/缺失 ID 的首项身份、乱序/子集查询、
文档变更后的新查询器、32/33 次建表边界、300 次正常缺失后的计数上限，
以及 128/512/2048 节点与独立线性 oracle 的引用身份对照。基线比较次数
分别为 8256/131328/2098176；该次调试运行的原/新查询耗时分别为
188/276、3037/1046、40705/3380 微秒，含建表时间。128 节点的孤立查找
较慢，明确保留这个开销边界，不声称所有规模更快；计时不设脆弱断言。

移除全部临时探针后，完整 `node_editor::` 回归 144 项通过、0 失败、
0 忽略，含四个新增与 140 个既有测试。产品检查通过，桌面产品 20 项、
测试 19 项既有警告未新增。重复实验及独立日志留样不累计为新测试。
来源、样式使用、新文件格式和差异检查通过。精确提交 CI 与合并待核验。

既有真实故障测试验证端口规格/标签、菜单、检查器、请求和布局七个站点。
最终测试程序的独立默认 Info 子进程另有留样：每站点一次既有 Warn 首报、
一次 Error 阈值报告，共七条文件 Error、七条 stderr Error、stdout 零条
故障记录。原默认阈值/首报等级及错误语义保持，不把它们描述成新观察。

原始审计、源码、探针、完整对照、计时、回归和默认输出保留在本地
`.tools/node-paint-lookup`。主要记录为 `branch-audit.json`、
