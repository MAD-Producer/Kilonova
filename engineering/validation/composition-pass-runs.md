# 连续直接输入共享合成 pass

接续 #590，基线 `e99a24c6d013d8f8f1f653c6ab7c8142187b026f`，推进 #126。
开工核对开放 PR 和最近分支；其他 agent 的跟踪、视频平面及预渲染实现未改动。

## 条件与行为

旧效果合成路径对每个几何批次单独 begin/end render pass，即使中间没有生产者。
现在仅将连续、可见、没有效果 pass、没有待恢复快照、不执行 transfer 或调整的
批次合并。保留原批次顺序、几何、uniform、pipeline、遮罩和 matte 绑定。
效果执行、快照恢复、调整层与混合边界仍沿原逐批次实现执行。

附件保留已有开头 Clear、共享段的 Load/Store、viewport 和末段 timestamp
归属，只删除段内多余的 pass 边界。没有假定纹理被完整覆盖、删除 padding
清空或更改 Store/Discard。预算、纹理、缓存所有权和 draw_calls 语义不变。
不据此宣称完成 #63 的完整覆盖契约或移动 GPU 带宽验收。

## 验证

测试构建可强制执行保留的逐批次路径；该开关和共享段计数不进入产品。
旧实现上新测试实际失败：八个批次未使用共享段。实现后八个批次只建立一个
共享 pass，Unorm8、Unorm16、Float16、Float32 的完整原生像素逐字节一致，
连续三次位置编辑确实改变画面。旧路径的计数必须为零，防止对照失效。

另在四种精度、正式与预览两种路径下，依次切换遮罩、双模式 matte、混合、
效果、调整层、3D、隐藏及普通图层：64 个场景均实际进入共享段，完整像素、
draw_calls、纹理字节和资源身份与旧路径一致。场景数不是测试数。

共享段新增防御性 Result 检查，缺失图像、mask、matte 或 compositing 状态
返回带上下文的错误。受控移除已准备的实际矢量／mask 资源，验证错误文字、
丢弃未提交命令后旧像素与台账不变，以及恢复后输出；这是内部状态注入，
不冒充文件解码或设备故障。另两种防御性状态缺失未注入，记录为验证边界。
没有新增日志信道；Result 继续由既有宿主／引擎边界处理。本阶段不声称重新
执行了完整桌面默认日志文件／stderr／stdout 验收。
