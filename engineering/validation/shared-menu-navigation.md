实现源提交：`01c8fbf799d06b19cb835729fbdf82b61fc78340`（含前序 `4cfe6485`、`a1b9d8ca`、`b264ceaa`）。基于 main `8c271bd3`，独立分支 `feat/shared-menu-navigation`；开始前核对了开放 PR 和本地 worktree 的分支归属，避开其他 agent 的曲线、滚动、深度及根 worktree 属性工作。

## 功能与样式边界

- 顶栏下拉和图层右键菜单共用 `motion_ui::widgets::menu::Entry<T>`、行绘制、边界计算、键盘导航。动作由调用者每帧重建，共用组件不缓存工程命令。文字编辑菜单的固定键位也由 `TextCommand::binding` 提供。
- 勾选、标题、有效快捷键、子菜单箭头分列；分组细线占用原行底边，不添加空行。沿用已归属的 Check / ChevronRight 图标与现有配色，没有新增资产或依赖。
- 应用菜单逻辑行高仍为 32，原来绘制/点击高度 30 统一为整行；图层菜单仍为 20。不缩小现有命中容差。新增的边界、行高、内边距 token 先写入 `dark.json`，规则同步 DESIGN §8.3。
- 窄窗口允许子菜单覆盖父菜单，但父菜单失去该区域的指针输入；宽度不再被强制压为窗口一半。高度不足可滚轮、方向键、Home/End、PageUp/PageDown；子菜单靠右时向左展开。
- Enter 不重复；第一次确认只展开分支。Left/Escape 先返回父菜单；Tab、外部点击、失焦取消。IME 合成和确认帧不激活、不关闭菜单。原生浮窗仍采用窗口本地坐标与原有 owner，不跨窗口持有草稿。
- 窗口菜单的工作区分支复用现有五个预设、管理和重置动作，并显示当前预设勾选。开关、检查和菜单动作不新增工程格式。
- 工程或合成切换时关闭顶栏菜单。普通选择变化保持已有“实时重建目标”的契约；图层右键菜单仍绑定打开时的目标，目标被移除时原有 prepare 边界取消。
- 其他专用弹层（效果资源库、工程浏览器、路径节点等）保留各自已有业务布局和输入路径。本项提供可复用的数据/绘制/导航组件并接入顶栏与图层菜单，不宣称全仓弹层已经迁移。

## 回归与原始失败

首轮未冻结实现运行 `cargo test … menu -- --test-threads=1`：78 通过、1 失败、6 忽略，用时 480.14 秒。失败为 `effect_controls::removal_tests::menu_refreshes_live_targets_and_keeps_primary_and_empty_layer_scope`：错误地把选择变化视作失效而关闭了效果菜单。修复生产导航的上下文检查，只检查工程与合成；**未修改该测试或其断言**。原始日志随证据保留，不能将这轮描述为绿色验收。

组件初次编译的 `widgets::menu` 过滤为 0 项，当时尚未添加测试，只能证明编译。后续新增 4 项真实交互/边界测试；最终结果以冻结源记录为准。

第一次冻结源 `4cfe6485` 的图层菜单组为 18 通过、1 失败、1 忽略：历史 hover 测试把根与子卡片都写死为 220 像素。新增快捷键独立列后按实际文字测量卡片，旧坐标点到了错误区域。测试改为按 token、文字和共享布局定位，保留“hover 不编辑、两卡片均有文字、执行 visibility、撤销恢复、菜单关闭”的原有断言，并增加左右展开方向断言；没有删减或放宽行为断言。原生 fixture 也校准为生产主窗和浮窗都实际使用的 Timeline owner。该失败日志保留在证据中，不混入最终通过计数。

补充第五项组件测试：缺少 `context_menu` 或 `context_menu.row` 时，样式表编译在安装前返回带类名的 Err，不能将不完整主题送进绘制器。

`a1b9d8ca` 的组件、完整 UI 库、样式、导航、图层、效果、文字、最近效果及默认错误信道均通过，但显式原生验收在首个主窗工作区子菜单断言失败：只有父卡片。真实原因是 `chrome` 在菜单处理前仍允许时间轴预处理 Enter，抢先开启图层重命名，然后键盘被该文字控件持有。`b264ceaa` 在主窗预处理处尊重已打开的应用菜单，新增完整 chrome 双语回归，并保留原生两卡片断言。原失败的日志、截图、强制回溯和退出状态一并保留；不通过改图或删除断言制造通过。

## 验收范围与限制

原生截图使用实际 Windows 隐藏窗口、GPU 渲染与生产 `chrome/floating_chrome` 路由。受控输入从标准化 Input 边界进入，**不是向独立浮窗进行 OS 鼠标注入**。1/1.5/2 是可复现的绘制像素比，不等于修改系统 DPI。截图不能单独证明命令执行，另有真实 worker 的保存重开与单步撤销断言。

§12 中与本项相关的 token、行内列对齐、overlay 层序、禁用/勾选态、窗口边界、双语、输入法和工程历史逐项验证；不宣称完成 Masks/Path 全矩阵、OS Reduced Motion 集成、查看器坐标或全仓性能整改。未改渲染器、timeline 时值/吸附或工程数据语义。
