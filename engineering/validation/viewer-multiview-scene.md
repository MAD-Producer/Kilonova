## 本轮行为

`Scene::sample_view` 显式接受 `ViewCamera::Composition`、`Camera(id)` 或
`Observer(&observer)`。相机选择属于本场景，不写工程或 session 全局观察状态。
旧 `sample(..., Option<&Observer>, ...)` 接口继续委托相同取样实现。

- 合成模式继续按时间和活动区间选择合成摄影机；没有活动摄影机时保留既有默认。
- 命名相机按当前合成中的准确 ID 解析。零只选择真实创建的旧式工程摄影机；
  不存在、被删除或指向非相机对象时返回带对象、合成、时间、解析阶段和原因的错误。
  不静默替换成活动或默认相机。明确选择的相机可以在隐藏、锁定或非活动区间被观察。
- 复用同一次层级解析中的相机取样，保留父级变换、相机图层本地时间、导入源动画、
  原生投影、letterbox 与景深参数；不增加全局相机切换、资源解析或文件读取。
- 子合成始终保留自身的活动摄影机；相同数值 ID 在父、子合成中互不混淆。
- 选择先于绘制图层构建，3D 投影、深度排序、场景投射和拾取使用一致视角；
  2D 图层仍用原来的平面合成投影。

`ExposureScenes::new_for_view` 同时固定曝光任务的视角：相机 ID 保留到每个
快门/接收者子帧，观察状态只在构造任务时复制一次，不借用之后还会改变的 UI 状态。
中心和子帧复用既有缓存与来源目录，子合成仍走自己的相机。原 `new` 和子任务
`new_shared` 保留旧参数和同一执行路径，不在健康轮询中增加复制或日志。

## 已执行验证

场景与曝光专项 11 项通过，其中包含 4 项实际 GPU 测试：

1. 两个相机与独立构造的旧式相机输出逐像素相等；先后渲染不改变原场景。
   在各像素检查几何命中与实际红色区域，另验证不同相机必须得到不同画面和命中。
2. 前后相机翻转 3D 遮挡及拾取的前景对象；同一 2D 覆盖层的像素和命中位置不变。
3. 导入相机在移除原始源文件后仍与原生相机输出逐像素一致，反向寻帧完全一致；
   错误地替换为活动相机必须产生不同像素，避免全黑图或无效夹具通过。
4. 所选动画相机的实际曝光输出与独立构造的旧式相机曝光任务逐像素一致，
   切回活动相机的负对照必须产生不同输出。

CPU 专项覆盖父级和分数本地时间、隐藏/锁定/非活动相机、删除及错误类型、
无效取样时间、子合成 ID 作用域、导入投影与 letterbox、缺失源解析器原始错误。
工程保存重开和完整对象相等断言保留。
另检查四个分数快门时间、中心缓存、任务开始后修改原观察参数不会改变任务、
相机解析失败保留曝光阶段和取样时间，以及失败后不能继续返回场景。
