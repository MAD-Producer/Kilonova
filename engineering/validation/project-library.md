## 已实现的模型与命令

- `Project.library` 是工程级组织数据，不属于任何一个合成，也不随合成切换交换。
  文件夹有独立 ID 和父 ID；成员身份区分合成、图片、视频、音频、模型和字体。
  未分配的资源在根目录；枚举来自工程的全部资源记录，不依赖图层引用。
- 新建、重命名、移动文件夹、批量移动成员及删除文件夹走 `project_library`
  共享命令和现有原子历史。删除容器把子目录和成员移到其父目录，不删除资源。
  已在目标目录的移动不改变存储顺序，不增加历史。
- 文件夹最多 512 个、深度最多 16 层；成员、名字长度和批量请求有界。
  缺失目标、重复身份、重复成员、循环、超深和无效名字拒绝整个事务。
  校验不通过时不自动修剪或修复输入。
- 成功移除素材或合成时只移除该成员的组织引用；同一次撤销恢复资源和目录归属。
  资源替换继续沿用稳定身份和归属。组织操作不访问源文件。
- 历史大小缓存单独更新组织字段，保留未改变的动画 payload 缓存；原有历史预算、
  淘汰、撤销/重做语义不变。
- 工程只接受当前版本，保留 `version` 字段；`library` 是必填字段，不增加迁移。
  本分支格式为 30：节点图像 PR #527 已使用 29，最终集成必须保留两边字段和较新
  的当前版本。采样投影不携带目录，因为它不是完整工程，不能单独保存或校验。
