# 面板图层身份：实现与待完成验收

关联 #134，基于 #598 堆叠。本轮只修复实际面板入口中的两处缺失 ID panic，不关闭整个 issue。

## 功能修复

效果参数面板和动画/缓动面板在读取图层 ID 前校验其为 u64；损坏输入不生成行或编辑命令，已有数值或缓动手势只取消一次，不把无事务的文本草稿当成待回滚事务。有效状态恢复后正常绘制。保留合法的 ID 零和 u64 上限。

## 新增观测

两个固定 site：effects.layer_id、curve.controls.layer_id。每个控件实例独立记录连续失败次数，上限 60；首次 Debug、第 60 次 Error，此后抑制，任何合法 ID 重置。Error 使用既有日志基础设施进入文件和 stderr；日志只包含类型、原可用对象 ID、代数/修订及固定原因，不包含输入字符串或完整 JSON。

无新增线程、阻塞操作、重试或协议；无需新增 worker in-flight 状态。取消已开始的手势为正常功能边界，不额外记录故障。此处不能复用现有 observation::Counter 的进程生命周期计数，因为本需求要求实例隔离与恢复重置。
