# 节点源超时后的结果处理

节点源刷新超时不代表工作线程取消。超时后保留原接收端并交给既有节点结果队列；相同快照再次刷新时复用在途请求，保留原有的保存意图。若复用的回复早于其他编辑，先确认保存，再通过现有状态请求获取较新的工程快照。超时仍返回错误；断开连接和后台保存失败仍按原错误处理，不自动重试或重启工作线程。
