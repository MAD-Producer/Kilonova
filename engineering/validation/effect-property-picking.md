# 效果参数拾取与数值显示验收

分支：`feat/panel-layout-consistency`。本批在已有检查器列布局上增加效果参数交互。
不包含变换位置拾取、时间轴表头整改或工程/效果包格式变更。

## 功能边界

- 效果列表中 `effect_opacity` 显示为“不透明度 / Opacity”；参数 ID、包内容和哈希不变。
- 效果数值的整数省略小数部分，非整数显示两位；进入文字编辑使用原值，提交和存储不先舍入。
- 使用现有元数据辨认源像素坐标参数，在同一行添加位置按钮。相对偏移、大小和半径不因同为 Vec2 而成为绝对点选参数。
- 位置从当前合成视图反投影到图层平面，再转为源图像左上角坐标；复用现有父级/相机投影和视图缩放、平移映射。
- 颜色按钮读取已完成合成预览的一个像素，排除 UI、手柄和背景棋盘格；解码线性预乘值后转换为编辑器使用的直通 sRGB。
- 预览取色是 SDR 显示结果，不能用来恢复高精度工程中超出显示范围的 HDR 数值。
- 点击一次产生一个现有效果编辑事务，可撤销/重做。选择前后验证工程身份、版本、时间、图层、效果、锁定和参数类型。
- 拾取模式独占点击；Esc、右键、视图外点击或上下文变化会取消。没有持续按住的拖动状态。模式允许检查器与合成浮动窗口之间转移焦点，转移本身不会提交。
- 闭合颜色行保留色块和取色按钮，只在不完全不透明且空间足够时显示 alpha；十六进制值和完整 alpha 在悬浮与颜色编辑器中查看。
- 用户选定参考 B 后，将效果关键帧导航从每行左侧移到选中行右侧；宽面板始终预留相同的导航空间，切换选择不移动数值。窄于主题 320px 阈值时隐藏导航，保留秒表与键盘导航。渐变参数使用“起点、起始色、终点、结束色、形状、散射、原图混合、不透明度”，不改效果包元数据。位置按钮采用原创圆心准星图标，和取色按钮共享值列末端动作位置。
- 主题效果行高为 30px；枚举保持整行垂直命中范围、112px 最大宽度和透明 idle 下拉。取消左侧导航预算后，值列最小预算为 108px，并回收最末数字单元的多余间隙；标签保留主题下限。所有参数仍在原属性行内，不增加行或缩小原有垂直命中范围。
- 用户进一步指出数值关联弱后，增加 `effect.value.max_width` 与 `effect.number.cell_width` 限制值组扩张；效果单值、坐标与枚举内容统一左起点。宽面板空余空间不再扩展 XY 间距；窄面板保留既有坐标文字空间、30px 行命中高度、20px 动作槽和拖动阈值。共享数值字段悬停出现中性细轮廓，idle 保持透明，文字编辑才有输入背景。共享色块改用主题 muted 中性边框，hover 使用 focus 边框；不新增字面颜色或绘制尺寸。

## 错误与信道记录

| ID | 类别 | 行为与证据 |
|---|---|---|
| EP-1 | 复用已有覆盖 | 新 `effect_pick` 命令经过现有串行 worker 的 Info start、in-flight、完成清理与 panic 回复；没有 UI 线程 GPU 等待。 |
| EP-2 | 新增错误上下文 | 参数类型错误保留原因并附 object/effect/parameter/frame；使用默认日志级别验证文件 Error、stderr Error 和 stdout 隔离。 |
| EP-3 | 新增显式失败 | 点击不能反投影的图层平面时，记录对象、效果、参数、帧与 unproject 阶段；给出面板提示，不编辑工程。测试移除真实快照投影数据，验证两个错误输出端。 |
| EP-4 | 正常分支 | 预览未就绪、过期 ticket、超出参数值域属于取消，返回原因并向用户反馈；不当作 Error，不读取旧预览，不自动重试。 |
| EP-5 | 资源/阻塞边界 | 仅显式点击时复制一个像素，readback staging 固定为一个对齐行，使用现有资源 admission、所有权和 readback 观测。设备等待仍由原 worker/watchdog 负责；本批不新增超时或重启。 |
| EP-6 | 协议边界 | GPU map 回调接收者退出时允许丢弃回复；业务命令保持现有 respond 语义，不吞掉业务错误。 |

EP-5 的设备故障、不可返回驱动等待和 worker panic 未在本批逐项注入；这些属于现有基础设施覆盖边界，不能以健康 GPU 结果宣称全部验证。

## 首轮失败与修正

原始日志保留在 `artifacts/effect-property-picking`，不作为通过证据：

1. 测试文件的 include 路径错误、数值控件测试遗漏 Input 导入，修正测试构建代码。
2. 首次真实 GPU 取色返回线性 RGB，导致编辑器显示变暗。修正生产颜色转换，保留原像素断言。
3. 精度切换的第一帧改变 host view revision，故不能作为稳定 retained stamp。测试原先忽略取消回执，误把未修改的黑色默认参数当作取色结果。夹具增加下一次正常 UI Present，像素、四种精度与历史断言保留；另外直接验证无稳定前帧时返回 `preview_pending` 且工程不变。
4. 早期窄面板截图把 220px 逻辑宽度绘到 960px 输出，被非等比拉伸。修正截图窗口与输出尺寸一致；早期图保留但不交付为视觉验收证据。
5. 既有帧采样测试把悬浮文字锁定为三位小数。按新的呈现要求更新四个预期文字，保留所有时间、图层偏移、插值取样和真实行 readout 断言；未改生产采样或缓存逻辑。
6. 密度调整首轮将枚举命中框固定为 26px，导致 32px 行密度下原有点击落空。恢复整行命中，保留既有离散值选择、键盘切换、撤销与多密度断言。旧失败日志保留。
7. 实机截图发现数字字段内部 padding 仍会使窄面板的两位小数变为省略号。值列最小预算调为 116px，并将测试改为验证扣除真实字段 padding 后的文字空间，最终 220px 截图能完整显示两组坐标；标签仍可能截断。
8. 原生 Shell 的失焦路径会调用通用取消，从而清除拾取模式。新增专用失焦取消，只保留无按住状态的单击拾取，其余手势仍取消。真实主/浮动窗口 ID 事件回归保留原有指针、IME、按键清理断言，并验证此模式跨失焦保留。
9. B 的首轮实际截图中，准星的 1.6 原始线宽在 16px 绘制尺寸下小于一个设备像素，主轴线落在采样点之间而消失。改为 2 原始线宽，并增加真实截图的上/左轴线可见性断言；不改图标渲染器或全局抗锯齿策略。
10. B 的选中行导航第一次点击未发出命令：原有 `render` 会在每次按下时先清空通道，导致导航在命中测试前消失。改为保留选择完成命中测试，只有该次点击未选择任何参数才清理通道。新增真实行导航事务、撤销恢复、隐藏导航不能加键，以及选择前后字段不位移断言。保留首轮失败日志 `b-native.log` 和截图，不降低原断言。
11. 紧凑值组验收期间，共享 target 被外部清理，链接报告缺失 `libarboard-*.rlib`（LNK1181），且已生成的测试 EXE 同时消失；E 盘空闲由约 3.8GB 增至约 171GB。保留 `cluster-confirm-build.log` 的原始失败，重新生成依赖后继续真实构建与截图，不将该失败解释为已通过的测试，也不调整产品错误处理或验收断言。
12. 重建后的测试 EXE 因 FFmpeg DLL 装载失败返回 `0xC0000135`，旧 EXE 同样无法启动；将已固定的 FFmpeg DLL 复制回测试 EXE 与程序旁后恢复运行。保留空输出与退出状态记录，不改产品依赖版本。
13. 真实悬停截图暴露缓存数值编辑器没有转发 Hovered 状态，且取消编辑后仍会绘制范围下划线。共享数值适配器改为转发实际悬停状态，范围下划线只在拖动时显示；新增缓存数值字段边框像素断言。未改数值、命令、拖动阈值或撤销语义。

## 验证结果

带 FFmpeg 的锁定离线 dev 构建和测试构建通过，分别保留原有 28 / 25 条 warning。数值精度 1 项、效果参数与实际 GPU 拾取 3 项、既有效果控制回归 39 项、共享数值的效果/相机拖动与撤销 2 项、真实主/浮动窗口事件路由 1 项通过；总计 46 项。样式消费者检查、56 枚图标生成一致性检查及 diff 空白检查通过。B 的原生测试同时验证选中行实际加键和撤销、隐藏导航不能加键、选择不移动字段、两个拾取动作对齐、220px 数字内部空间及准星轴线的真实像素可见性。新增 360px 与 520px 字段位置/宽度完全一致、单值/枚举/坐标共同起点、黑色色块边框与缓存数值悬停轮廓的像素断言。220/360/520px 普通、悬停、输入截图和弹出下拉、点选状态均由实际 GPU 捕获。比较图仅裁切拼接原始截图，不缩放或重绘。

最终命令、日志与原生截图见同目录结果 JSON。用户选择参考 B 并要求精简信息与改进位置按钮；本批实现该方向，保留原生实机截图供用户确认，不将生成参考图当成产品验收图。
原生 GPU 输入测试通过生产 chrome / floating_chrome 和引擎信道，不等同于完整操作系统鼠标与多窗口焦点矩阵。
本机已有 Epic Vulkan overlay 注册项失效日志不在本次修复范围内，未过滤相关输出。

未完成项：全屏 OS 输入回放、真实多 DPI 与多屏焦点矩阵、GPU 故障/挂起注入、父级旋转/3D/动画偏移的新增端到端点选用例。本批复用对应投影和命令实现，但不将已有模块能力等同于本批新增组合路径的完整验收。示例渐变的精简标签在 220px 截图中完整显示；其他任意长名称继续使用省略与完整悬浮文案。最终 B 样式等待用户查看，不冒充用户认可。
