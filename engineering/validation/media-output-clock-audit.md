# 媒体边界清单与导出采样时钟

推进 #131，与 #396 的原生采样现场留存合批。开始前复核开放 PR 和工作树：#395／后续曝光分支正在处理 GPU 资源预算，精度分支保留渲染语义工作。本次仅收敛三个桌面媒体文件中的输出采样率来源，不修改 GPU 预算、颜色转换、窗口或面板。

## 实现与故障边界

冻结导出的逐视频帧混音上界原来独立使用 `48_000`，现改为 `motion_media::OUTPUT_RATE`。桌面 FFmpeg 的输出采样率常量也从该共享值派生，AAC 编码时间基、编码器采样率与输入 PCM 帧采样率均使用这一派生常量。当前值仍为 48000，数值输出、时钟舍入、音视频同步及工程格式不变；这是消除重复常量，不是已经复现的播放音画错误修复。

现有共享常量为固定且能由 FFmpeg 的 u32／i32 字段表示的 48000；没有把任意外部采样率转换为这些字段，也没有新增允许用户配置输出采样率的协议。测试夹具中的 48000 仍保留为独立预期，不为通过测试同步改成实现常量。

没有新增错误、计数器或日志路径；现有 FFmpeg 错误、混音失败及源文件故障保持原回复信道。本次不添加重试、重启、静默降级或新的等待期限。
