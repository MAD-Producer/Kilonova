# 受管合成中的数值蒙版覆盖率

本批继续 #83：二维纯色、原文件图片和矢量现在能在已声明的 Float32
工作空间中应用图层蒙版，不再因为存在蒙版而进入旧效果合成器或被一律拒绝。
创作颜色仍只经过原生输入程序；蒙版是数值覆盖率，不经过 OCIO、sRGB
解码或显示变换。预乘 RGB 和 Alpha 一起乘覆盖率，然后执行工作空间叠加。

沿用已有的路径栅格、羽化、扩展、反转、不透明度及六种混合模式。
None、禁用和未闭合路径仍是正常的无覆盖操作；没有修改模型采样语义。
缩小预览使用其实际适配尺度准备蒙版，源路径和羽化值仍保留源像素单位。
这里没有引入效果程序，也没有改变旧非受管合成、track matte 或三维准入。

| 编号 | 分类与处置 | 证据与限制 |
| --- | --- | --- |
| MMC-01 | 功能接入 | 已转换的工作颜色与独立覆盖率在直接合成管线结合；原文件图片保持独立的颜色/Alpha/精度身份，矢量 paint 使用既有 working-space 栅格，不重复转换 |
| MMC-02 | 数值对照 | 三组原配置、两种输入 Alpha、负值和超一高光，六种模式及反转，共 589824 个像素；原生 CPU 色卡不可变，覆盖率由独立标量公式计算，沿用绝对 0.0001 加相对 0.0002 容差 |
| MMC-03 | 羽化和初始值 | 原尺寸及半尺寸预览共 71680 个像素比较 None、六种模式的初始覆盖、正负扩展及离散 Gaussian 参考；不把一个 GPU 路径的结果当作另一个 GPU 路径的参考 |
| MMC-04 | 混合来源 | 16-bit 图片与矢量采用不同蒙版、不同覆盖率，在同一工作目标中与原 CPU 参考比较；删除配置及原图片后再采样，144 个像素检查无文件重开和中间回读 |
| MMC-05 | 缓存生命周期修复 | 蒙版和矢量分别持有编码 guard，只有成功提交后才提交缓存状态。普通提前返回或 panic 会使下一次准备清除蒙版就绪指纹；不清除主错误、不吞 panic，也不隐式重试当前操作 |
| MMC-06 | 失败负对照 | 实际放弃 encoder 和受控 panic 后重新编码必须产生新像素；故意在提交前提交 guard 的错误生产者必须保留错误旧覆盖率，检查能识别该错误，再显式恢复 |
| MMC-07 | 资源准入 | 在分配/编码前检查覆盖输出与最大 scratch 池、其他来源及冻结工作图像的合计 source 预算。缩小预算不能被缓存命中绕过；拒绝保留目标像素和旧输出文件，恢复预算后可显式重做。原有全局 allocation 准入继续独立限制在途和候选资源 |
| MMC-08 | 既有观察复用 | 没有新日志站点或逐帧 IO。覆盖错误继续沿已有 prepare/render/export 原因链；非 Present 开始与在途状态、默认文件日志、Error stderr、stdout 隔离由既有 worker 负责。普通空蒙版和缓存命中不记故障 |
| MMC-09 | 实际 worker | 新 PNG worker 测试从真实工程冻结输出，以不足的覆盖预算触发 compose 错误，检查请求/阶段/耗时/原因、完整工程与历史不变、旧文件保留，随后恢复并检查透明像素；删除 Error、stderr、原因或污染 stdout 的负对照必须失败 |
| MMC-10 | CI 与回归 | 三平台原生 `authored::` 门禁包含新像素测试；新增真实 worker 检查位于打包前。既有蒙版资源/typed import、矢量缓存和截图快照清理回归继续运行，断言与容差保持不变 |
| MMC-11 | 样式与来源 | 没有面板、样式、依赖或第三方资产修改，DESIGN §0.7 无本批整改项；源码和数值参考独立编写，沿用已登记的 OCIO 运行时身份与许可 |
| MMC-12 | 待完成 | #83 尚有其他消费者、工程输出与平台显示资格缺口；本批不能代表这些路径已集成，不能据此关闭 issue |

144 个混合来源像素。二十项原生 authored 回归、十六项蒙版缓存/准入、
三项矢量规划、两项快照清理、三项旧蒙版集成、两项真实默认信道 worker，
共四十六项不同 Rust 测试通过；双后端重复不重复累计。工具检查二十七项。
原始信道输出保存在 `default-log-channels/managed-mask-worker/`，正常取消、
受控阻塞及恢复的既有 PNG worker 也再次通过。

源码、差异、不可变参考身份、固定原生运行时身份及全部原始输出一同归档。
旧提交的绿色 CI 不作为新提交资格。Windows Vulkan/DX12 不证明 Metal 或
OS/HDR，既有编译警告和外部 Vulkan overlay 注册问题没有在本批处理。
