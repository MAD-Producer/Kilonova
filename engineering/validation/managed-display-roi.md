# 受管显示的逐单元局部预览

本批继续 #83，把现有 ROI 检查接入受管显示的窗口呈现和显示截图。
区域使用合成图像的归一化坐标，随实际平移、缩放及留边映射，再限制在
对应视图单元内。第一单元清空整个附件，其余单元保留先前单元；区域外
不保留上一帧像素。区域不是新的颜色空间，不重复执行 OCIO 或 Alpha 转换。

ROI 随每次编码传入，不存入已完成显示组或可复用 presenter 的检查状态。
独立单元仍使用独立位置 uniform。修改、关闭 ROI 不改变渲染组的身份、
工程或播放时钟，也不重新采样同一完整组；平移、缩放本身仍遵守原有
预览尺寸和缓存协议。普通单视图的桌面请求现在显式转送 ROI，不能只
设置旧 presenter 后在受管组中忽略它。
