# 持续节点拖动的同帧卡片复用（#134 增量）

基于 #601 堆叠。开始前核对开放 PR、其他分支近期节点变更及根工作树的节点目录状态；#575、#587、#599 的完整文件清单未修改 node_editor。没有编辑其他工作树或审查他人 PR 代码。

此前即使工程身份、修订和视口都未变化，只要处于节点拖动中，一次 draw 仍会重建整套 Card、端口规格和字符串。现在仅在“进入和离开画布输入时都仍是已有节点拖动，且完整几何 stamp 未变”时，校验本帧所有 Card 与当前节点的数量、顺序、ID 和指针身份，再用已保存的世界高度与端口行坐标重新投影位置。

保存的原始指针只比较身份，从不解引用；所有卡片仍只在当前 draw 内存活，不建立跨帧缓存。先验证全体身份，再修改坐标；身份不匹配沿用原重建，是正常复用拒绝，不是错误或静默故障。按下、释放、取消、历史提交、结构/视口变化仍走原重建逻辑。本批没有修改既有 >=2 重建断言，也不宣称这些变化帧只构建一次。

每个 Card 新增一个世界高度 f32，每个 Socket 新增一个世界行坐标 f32，可能受结构体对齐产生额外字节；它们有当前图大小的界限，不积累历史。不会将构建次数减少称为整个 UI 零分配或 FPS/内存峰值结论。

当前节点编辑器回归 179 passed、0 failed、0 ignored，其中 2 项新增：中英文、两种区域、三个缩放、折叠/展开下连续 12 次拖动，每次只构建一次 Card 集合，并独立重建全部几何比较，释放一次提交、一次撤销恢复原文档；另验证失配/乱序/缺失卡片在任何修改前拒绝更新。带 FFmpeg 的测试程序编译通过。

完整绘制指令的前后比较、原重建路径负对照、正式程序构建、最终证据归档与 CI 仍待完成，先提交草稿，不以定向测试完成整个 #134。

## 错误与观测边界

| ID | 分类 | 处置 |
|---|---|---|
| NG-REUSE | 性能修复 | 持续位置拖动复用本帧已解析的端口和几何元数据；独立新构建几何保持一致。 |
| NG-IDENTITY | 正常分支 | 数量/顺序/身份不符时不更新任何卡片，随后执行既有重建；不新增错误日志或重试。 |
| NG-OBSERVE | 既有覆盖 | 每帧首次 cards 与绘制的原端口错误观察保持；不吞 Err/panic，不增加线程、超时、健康帧日志、文件 IO 或 in-flight 协议。重复 cards 的移除也移除其重复解析，不能将计数次数等同于秒。 |
| NG-HISTORY | 功能保持 | 原释放、取消与撤销逻辑不变；按下或结构变化的原重建断言保留。 |
| NG-PENDING | 待验证 | 完整绘制/性能对照、正式程序、最终 CI、全部 #134 和其他分支运行时集成仍开放。 |
