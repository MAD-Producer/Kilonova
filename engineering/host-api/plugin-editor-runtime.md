# 插件编辑器 M2：原生布局与参数预览

M2 提供可运行的参数/着色器预览；作者工程仍使用 M1 的 `.msplugin`。
这里没有拖拽排版、节点连线、WGSL 源码编辑、安装/发布按钮。

```powershell
motion-studio.exe --plugin-preview parameter-workbench.msplugin --locale zh
motion-studio.exe --plugin-check parameter-workbench.msplugin
```

完整示例位于 `crates/motion-graph/examples/parameter-workbench.msplugin`。
包名、源代码和示例数据均为本仓库自行编写；没有引入依赖或第三方资产。

## 已实现

- `Preview` 渲染行、列、分组、标签页、分栏、说明、参数与预览槽。显式尺寸作为最小尺寸，
  权重分配剩余空间；不足时滚动和裁剪，不缩小数值控件，不为同一属性增加第二行。
- 折叠与标签页状态按组件 ID 保存；多个控件绑定同一参数时共享一个值。
  数值、二维/三维向量、颜色、布尔和枚举复用已有原生控件/颜色预览样式。
  下拉框宽度受已有 `effect.enum.max_width` 限制，数值分量宽度固定且相邻排列。
- 所有新布局尺寸先定义在 `dark.json`，没有新颜色。窗口初始尺寸从面板/画布 token 组合，
  没有放宽主题尺寸的校验上限。宽窗左右分区；窄窗上下分区。显式预览槽使用作者布局，
  隐藏的预览标签页不绘图；独立示例源为正方形，预览保持其比例。
- 预览值独立于作者默认值和用户工程。连续拖动一次撤销；颜色弹层整体应用一次撤销；
  Esc、失焦、移出窗口和调整窗口尺寸取消活动手势。撤销/重做/重置只影响示例上下文。
  历史上限 128 项；参数/组件数量沿用已有契约上限。
- 源文件读取、编译和图像解码在 CPU 准备线程上执行。原子阶段状态在进入调用之前发布；
  Info start 在文件中持久化，普通完成使用 Debug。发生错误显示原生提示并记录原始原因。
  panic 不转成成功；其原始原因交由现有进程钩子记录，作用域清理阶段状态并记录中止。
- 节点与 WGSL 都经 `PreparedPlugin` 和既有 GPU 预算/SDK 预览通道安装。参数请求先校验
  安装时的契约，仅更新 uniform 并失效时间缓存，不重新编译管线。无效值保留旧画面，
  过期 stamp 是正常的 superseded 回复。参数和窗口尺寸更新各保留一个在途请求。
- 插件着色器内容在原生控件之前合成，背景避开实际预览区域；弹层可覆盖预览。
  既有节点编辑器继续使用原有合成路径。首帧有一次性的 Info start 与可观察状态；
  surface 的正常未呈现回复保留绘制需求，具体降级原因/抑制沿用引擎现有观测。

## 边界

这是独立示例入口，不是 M4 的独立作者编辑器。关闭不改写源文件，也不保存预览值。
界面明确标出“未连接工程”；插件作者提供的参数名/选项文本保持原样，宿主按钮支持中英文。
时间固定为 0；时间轴槽明确显示需要宿主时间上下文。没有假造播放、关键帧或项目连接。

主工作区/浮动窗口嵌入、宿主项目参数手势、插件包中的新布局发布、实时源代码重载、
拖拽尺寸编辑以及粒子对象能力留在 M3–M5。当前颜色弹层编辑 RGBA，不提供系统吸管。
Windows 实机启动/关闭及 GPU 输出已单独验收；OS 显示设置中的真实 200% DPI 切换、
IME、跨平台、键盘遍历和长名称覆盖仍需后续验收。200% 绘制截图不冒充真实 OS DPI 验收。

原生读取/编译/解码不返回时，阶段和开始时间保持可诊断；本阶段不增加超时、线程终止
或自动重启。关闭仍可能受这些原生调用本身约束。

证据、初次失败和已有设计问题的处置见 [M2 验收](../validation/plugin-editor-m2.md)。
