# 路径自动切线与对应点契约（#270）

## 当前模型核实

`VectorPath` 为一组带稳定 ID 的 `PathNode`；每个节点的六分量轨道保存位置与相对入/出切线。形状路径与蒙版复用该结构。节点动画按 ID/轨道采样，拓扑不是逐关键帧的无身份点数组。已有首顶点操作只旋转整条路径的节点顺序，不能用于猜测两个不同轮廓之间的点匹配。

## 本次目标

新增独立命名的“自动切线”，不声明复刻其他产品算法。形状与蒙版使用同一确定性采样函数：先采样各节点位置，再按相邻弦长计算共同的切线方向，入/出手柄分别按该侧弦长限制。开放路径使用单侧端点；闭合路径环绕邻点，首顶点旋转不得改变轮廓。零长度边生成零手柄，禁止除零或引入非有限值。计算使用 f64，输出保持现有 f32 约束。

自动模式与手动模式必须是显式模型状态，通过真实命令进入历史和保存。自动模式保留原始手动手柄，切回手动模式明确恢复这些手柄；不能声称模式切换保持原形状不变。自动模式仅允许编辑节点位置，手动手柄入口应禁用或隐藏，避免显示已被采样覆盖的可编辑数值。

## 对应点与动画

同一节点 ID 是唯一对应点，不做最近点重排、逐帧重新配对、光流或无依据的“智能形变”。点的时间插值沿用作者设置的现有轨道；自动切线是在每个采样时刻重新计算的几何约束，不能把普通线性插值重新命名为智能插值。

增删点作用于整条作者路径的拓扑。既有插点操作保留各关键帧形状的契约必须继续验证；自动模式中插点后会按新邻接重新求切线，因此不能保证与插点前几何完全一致，界面和验收样例应明确区别。首顶点变化只改变闭合路径接缝；不改变节点身份、各轨道关键帧、开闭状态或方向。复制/粘贴、形状与蒙版互转要保留模式，拒绝无效目标时不产生部分修改。

## 成本与限制

单次切线生成 O(N)，一次输入校验后再修改输出；不建立跨帧缓存、匹配矩阵或后台任务。路径数和节点数沿用既有限额。重复点可退化为尖点；自动模式不保证无自交、轮廓面积不变或任意时间曲线无过冲。对非法值、节点上限和非法闭合路径返回带操作上下文的模型错误，由既有命令/采样错误信道传播，正常重复点不是故障。

自动模式加点在编辑帧及整条路径各节点关键帧的并集上采样原曲线，定位新锚点；新节点使用线性关键帧和零初始手动手柄。原节点的轨道、手柄及时间曲线不变。新点在这些时刻落在原曲线上，但重新计算的切线以及时刻之间的线性轨道都可能改变轮廓；不是逐子帧保形。分轴几何轨道暂不支持自动插点，会通过既有错误入口明确拒绝。删除顶点重新计算相邻切线，少于三个点时沿用既有规则打开路径。静态加点成本 O(N)，动画加点为 O(KN)，K 为有界的关键帧并集；不是播放热路径。

非等比缩放或斜切会改变弦长约束，无法保证跨坐标系转换后与原自动曲线一致，因此“复制为…”在这些变换下明确拒绝有损转换。平移、旋转、反射和等比缩放保留模式，不偷偷烘焙动画。

## 编辑入口

在合成查看器中使用钢笔或蒙版工具，右键路径顶点，选择“使用自动切线”。右键菜单随后显示“恢复手动切线”；这会恢复保留的作者手柄，轮廓可能变化。自动模式仍可拖动、框选和微移锚点，但不显示或命中手动手柄；平滑点/角点工具会提示先恢复手动模式。模式改变沿用已有编辑命令、锁定、撤销/重做和保存通路。

编辑投影分别携带显示几何和自动模式的作者几何，拖动锚点只使用后者作为种子，避免把自动生成的手柄覆盖回手动轨道。手动模式不额外发送这份几何数据。没有新增属性行、布尔按钮、枚举循环按钮或样式值。

## 已执行样例

`motion-model/tests/path_tangent_sampling.rs` 对开放/闭合路径各连续采样 1002 个时刻，包含关键帧边界和区间外端点，核对节点对应、锚点轨道、相邻样本跳变量与工程不变性。这是指定样例的稳定性验证，不是任意作者曲线的无过冲保证。

本机 debug 构建对 2048 点路径采样 100 次记录为 91153 微秒，约每次 0.91 毫秒；只观察模型采样，不包括 JSON 投影、布局或 GPU 成本。没有把墙钟耗时设为 CI 断言或性能承诺。

## 完成门禁

- 数学对照：直线、弯曲、非均匀点距、重复点、反向尖点、开放端点、闭合接缝旋转与有限坐标边界。
- 模型对照：手动模式不变；自动采样与导出/冻结一致；稳定 ID、点数/首顶点变化、复制/互转与历史；保存重开不丢状态。
- 编辑入口：中英文主窗与原生浮窗，选择、锁定、失焦/取消和忙状态；右键菜单必须提供多张真实 GPU 截图。
- 失败路径：非法命令/采样保留原始原因，默认文件日志/Error stderr/stdout 隔离；不得靠修改已有断言通过。
