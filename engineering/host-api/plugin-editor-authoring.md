# 插件编辑器 M3：逻辑与界面作者工作区

```powershell
motion-studio.exe --plugin-editor parameter-workbench.msplugin --locale zh
```

在独立原生窗口编辑 M1 的 `.msplugin`，沿用 M2 的 `Preview`、现有节点编辑器、
原生多行文本编辑器和效果编译/GPU 通道。没有增加依赖或第三方资产。
三个页签共享一个作者草稿；运行时示例值有独立历史，不写入参数默认值。
顶部另有离线“使用教程”页（F1），完整步骤见 [使用教程](plugin-editor-tutorial.md)。
组件库以真实原生控件缩略图展示行、列、分组等部件，并提供用途说明和悬停大预览。
示例子项仅用于说明，拖入后的容器仍为空；设计模式的空容器有放置提示。

WGSL 可通过 `MOTION_WGSL_ANALYZER` 连接独立安装的本机语言服务，提供补全、定义定位和诊断。
固定验收版本的上游 hover 仍返回空结果，界面如实显示无说明；不宣称已实现类型悬停。
虚拟文档包含真实宿主和公共参数声明；最终编译权限、预算及 GPU 校验不由 LSP 决定。
在窄窗口中公开参数/WGSL 分页，保留文本编辑、输入法和撤销行为。

## 操作

- **逻辑 / 节点来源**：复用节点画布、连线、分组、公共参数和检查器，显示生成的只读 WGSL。
  保存取根图快照，编辑子图不会将子图误存为整个插件。文件操作及作者撤销由工作区统一处理。
- **逻辑 / WGSL 来源**：原生多行输入、选择、滚动、剪贴板、文本撤销和语法着色。
  左侧编辑公共参数的名称、类型、单位、范围、步长、默认值、枚举选项和动画标记。
  ID 保持稳定；已有布局/代码引用的参数不能直接删除。类型变化不能破坏已有控件绑定。
- **界面 / 设计布局**：组件库或公共参数拖入中间面板；从结构树或画布拖动已有组件，
  移动到行、列或分组中。插入位置有提示；分栏边界可拖动，选中框右下角可调整尺寸。
  检查器编辑尺寸模式、间距、对齐、文本、绑定、标签页和分栏轴/比例。
  分栏两侧和标签页根是固定结构，可以向其内部放控件。
- **界面 / 交互预览**：控件只修改独立示例值；作者拖拽关闭。顶部撤销/重做作用于示例值。
- **预览与诊断**：真实 GPU 输出与同一原生参数面板。编译错误显示原始阶段和可取得的行列；
  “定位源码”跳到 WGSL 作者位置。编译失败保留旧有效 GPU 效果，不把错误草稿当成运行产物。
- **保存**：Ctrl+S 或保存按钮，Ctrl+Shift+S 另存为；写入在后台执行。
  无效 WGSL 仍可保存为草稿。保存结果只确认它对应的快照，不能清除较新编辑的脏标记。
  关闭未保存内容时显示保存、放弃和继续编辑选项；保存失败保留内容与提示。

设计模式中，Esc、失焦、移出窗口或调整窗口尺寸取消活动拖动。
名称等短文本用 Enter 确认、Esc 取消；文件操作先提交有效编辑。
WGSL 使用原生文本撤销，离开编辑后纳入作者历史。作者历史覆盖节点、源码、公共参数和布局，
一次连续布局手势合并为一步；上限 128 项及约 32 MiB 序列化快照预算，至少保留最近一步。
源码本身沿用作者工程的字节、节点、参数和布局容量限制。

## 编译和错误边界

单个后台工作线程处理源读取、保存、编译和资源解码；请求/回复队列各一格。
编辑暂停后编译新 revision，旧回复作为正常取代请求丢弃。
进入可能阻塞的阶段前发布请求号、阶段和开始时间，并将 Info start 写入文件。
普通完成为 Debug，失败保留原因并写文件和 stderr，stdout 不输出产品日志。
GPU 安装和参数更新复用既有引擎请求；拒绝不改写作者默认值。

行列来自 Naga 的真实 span，经相同 ABI 和参数前导代码映射回作者源。
若错误发生在生成部分或 legacy 规范化后不能精确匹配作者文本，显示阶段与原因，
不编造来源行列。着色仅为呈现词法，不参与编译正确性判断。

原生编译/文件调用不返回时保留 in-flight 状态；没有隐式超时、重启或线程终止。
工作线程 panic 后草稿和旧预览仍在窗口中，但该后台工作线程不自动恢复；同进程后续后台文件
操作不可用。这是剩余恢复边界，不能将“草稿仍在内存”表述为磁盘自动恢复。

## 阶段范围

本次交付独立作者工作区及可复用控制器；主工作区嵌入、浮动宿主窗口、真实实例绑定与断连
属于 M4。新包安装/发布、资源管理器和粒子对象能力属于 M5。没有将独立示例接到用户工程。
当前结构树可访问隐藏页的子树，检查器可以切换页；标签页标题的自由重命名、完整键盘拖放、
块注释跨行着色与资源清单可视化尚未实现。节点图片导入命令尚未接作者资源通道，
会显示明确错误并保留草稿；已有源文件内嵌资源仍由现有准备器读取。

实际验收与限制见 [M3 验收记录](../validation/plugin-editor-m3.md)。
