# 图层时间映射实现契约（#257，实施中）

本文件描述目标行为与验收要求，不代表功能已交付。分支已实现第一阶段连续时钟内核，
尚未接入工程字段、编辑命令、媒体执行或界面。当前 main 只有图层区间、offset、
视频/音频 source_offset 和跨合成帧率换算；伸缩、倒放、时间重映射仍未实现。
实现分支为 feat/layer-time-mapping；其他 agent 的 #82 预渲染分支不在本任务内修改。

## 必须统一的四个时钟

1. 合成时钟 C：预览、导出、嵌套合成与声音输出的唯一外部查询时间。
2. 图层经过时间 E = C - clip.offset：clip 的 [in, out) 只决定是否参与，不偷偷改 offset。
3. 属性时钟 L：伸缩和倒放后的图层本地时钟。变换、效果、路径、蒙版及音量关键帧、
   摄影机、表达式的属性读取都使用同一个 L。变更不能把参数动画与视频拆成两套速度。
4. 素材时钟 S：以 L 为输入进行可选时间重映射，再加素材 source_offset；素材 fps、
   视频 PTS 和 PCM 采样率仅在对应边界转换。重映射的自变量不能再次经过自身。

无时间变换时，C→L、source_offset、关键帧位置、预览和导出逐样本结果必须与现状一致。
嵌套合成逐层组合时钟；不能只改根视频的寻帧而遗漏声音、曝光子采样或子合成。

## 编辑与持久数据

- 伸缩使用明确百分比，100% 为原速，200% 为时长两倍；倒放是显式方向。
  更改锚点、是否同时调整 out、保持当前帧位置必须由命令规则决定，不能依赖面板临时状态。
- 关键帧保存本地时钟身份；时间轴绘制与编辑必须使用可逆映射。现有普通帧协议只接受
  整数，因此须补能表达分数合成时间或稳定本地关键帧身份的接口。不得通过 round/floor
  悄悄移到邻帧、合并两个关键帧或宣称精确拖动。
- 时间重映射使用已有曲线/插值机制，支持保持和连续区间、冻结以及非单调往返。
  变换关键帧与素材重映射关键帧的轴语义必须明确。
- 单个命令/批量命令原子修改、验证及撤销；锁定图层和不可用类型明确返回错误。
- 保留工程 version，仅接受当前版本；新增格式随版本更新，更新实际手写 fixture。
  不增加旧工程迁移或隐式兼容分支，不改效果包版本或渲染精度语义。

## 视频、音频与区间

- 正反向都使用半开区间。倒放第一帧/最后一帧、首末 PCM 样本、trim、source_offset、
  音视频不同起点、VFR PTS、子帧 clip 和不同 fps 嵌套必须有独立预期。
- 负向映射的区间端点是排他的，不能把源 duration 本身当作一个有效样本，也不能
  通过减一整帧来修复音频末样本；视频与音频必须按各自采样时基处理端点。
- 第一版计划按采样位置变速，音高随速度变化；保持音高属于另一个 DSP 能力。
  已向用户询问，尚未收到回复；先按该建议推进，若选择保持音高须调整处理契约。
- 音频任意重映射需要计算块内实际源采样覆盖，不能假定 begin/end 单调，也不能
  为一秒输出无界读取整个素材。缓存读块、工作量和保留键均有界；冻结段的音频策略
  要明确，不能把同一 PCM 值循环输出为直流。
- 预览、离线 PNG/视频导出、音频播放、冻结导出和后台预渲染使用相同映射。
  时间变更须使缓存/来源身份失效，不能复用旧映射下的已完成帧。

## UI 与错误边界

复用现有参数行、曲线编辑器及原生菜单。新增属性按 DESIGN.md 与 dark.json 的
行规则和 token 实现；UI 修改提供主窗、浮窗、中英文及窄面板实际截图。
右键菜单若有变化，另提供打开及二级菜单的实际截图。

解析、验证、采样、素材缺失、不可逆写入、缓存读失败和 worker panic 均走已有错误信道，
保留 cause、operation、对象/源、phase、elapsed 和请求身份。非 Present 操作沿用 Info start
与在途状态；健康 Present 不加逐帧 Info。失效、取消和正常无样本不升级为故障。

## 完成证据

- 模型：正负速度、零/非有限/超限拒绝、复合映射与逆映射、保存重开及无变换字节/值对照。
- 编辑器：普通和曲线关键帧、蒙版/路径/效果、分离轴、连续时间关键帧的定位、冲突和原子 undo。
- 媒体：真实 CFR/VFR 视频、已知 PCM 波形、非单调 remap、首末样本、不同起点和嵌套 fps。
- 渲染：预览/导出/曝光在相同请求时间取得同一来源，实际像素/PCM 对照；缓存失效恢复。
- UI：真实双窗口输入、焦点/取消、两种语言；数值、曲线与最终媒体输出一致。
- 故障：默认 Info 文件、Error stderr、stdout 隔离；阻塞前发布在途状态，失败保留原因。
- CI：当前提交完整必需检查通过后才合并，合并后核实 issue 的每项要求再关闭。

不得把只读模型 helper、模拟成功回复或单独编译成功称为本 issue 已完成。

## 第一阶段内核与后续接线

`motion_model::layer_time` 已提供经过构造/反序列化验证的不可变 `LayerClock`、
`TimeStretch` 和 `TimeRemap`。比例按有界有理数保存；属性键的逆映射与素材 remap
分离。素材 remap 使用双精度的键时刻、值和速度，不把时间值降成 f32。
沿用已有 Easing/Curve 的定义；普通属性采样的历史浮点语义没有改变。

素材坐标在嵌套中保持连续；最终叶子才换成解码器微秒或原生 PCM 坐标。
倒放坐标表示排他边界，因此减去的是一个解码微秒或一个原生 PCM 样本，
不减一整个合成帧。冻结保留画面请求，PCM 位置返回正常的 None，要求调用方静音。
这个 None 不是丢帧或解码故障，不应计入错误阈值。

已有正向视频时间换算直接复用 `VideoClip::source_time_us`，保持原取整顺序。
未变速音频后续必须保留现有有理数采样快路；新 PCM 坐标 helper 的位置对照
不等于现有混音器输出的逐位相等证据，也不代表已经接通声音播放或导出。

第二阶段已接入 Layer、当前工程版本 32、项目验证、原子命令及保存/撤销。
这是开发分支上的数据与编辑事务阶段，尚未完成音视频执行或可见编辑入口。
连续时间/本地身份关键帧编辑、同一媒体映射、后台预渲染失效与 UI 仍须继续接入。
目前不在菜单宣称伸缩/倒放/重映射可用，不关闭 #257，也不把部分媒体行为作为交付。
