# 插件编辑器使用教程

软件内顶部 **使用教程** 或 **F1** 可离线阅读快速上手、布局与交互、代码辅助与排错。
查看教程和页面导航不会改写作者工程。

## 从示例完成一次编辑

1. 用 `motion-studio.exe --plugin-editor crates/motion-graph/examples/parameter-workbench.msplugin --locale zh`
   打开仓库示例。先按 **Ctrl+Shift+S** 另存为自己的 `.msplugin`。
2. 进入 **界面 → 设计布局 → 组件**。缩略图按真实布局的测量边界展示结构，悬停可看原生控件大示例；
   容器中的示例子项只用于说明。按住“分组”拖到画布，出现插入标记后松开，得到空分组。
3. 切换左侧 **参数**，拖入“强度”或“颜色”。这是绑定已有公开参数；增加新参数须到逻辑页。
4. 在结构树中选择分组，右侧检查器编辑标题、间距、对齐及尺寸。
   可从树或画布拖动组件进行跨组移动。分栏的两侧、标签页的页面根是固定容器，向其内部放内容。
5. 用 **窄面板 / 宽面板** 查看同一份布局。在较窄的窗口中，左侧通过结构/检查器页签切换。
   空容器显示放置提示；不要把缩略图中的示例值误认为已绑定的数据。
6. 切到 **交互预览（示例值）**，调整参数；到 **预览与诊断** 看实际 GPU 画面。
   这些临时值不会修改公开参数的默认值。
7. 按 **Ctrl+S** 保存，关闭后重新打开 `.msplugin`，继续编辑。

组件如何选择：

| 部件 | 用途 | 插入后的状态 |
| --- | --- | --- |
| 行 | 横向排列子项 | 空容器 |
| 列 | 纵向排列子项 | 空容器 |
| 分组 | 带标题、可折叠的区域 | 空容器，可编辑标题 |
| 标签页 | 多个参数页面 | 一个空页面，检查器可继续加页 |
| 分栏 | 两个可调比例区域 | 两个固定空容器 |
| 效果预览 | GPU 视口槽位 | 共用当前预览输出；缩略图棋盘格仅表示槽位 |
| 说明 | 静态提示文字 | 检查器可编辑文字 |

## 修改逻辑

工程的权威来源是节点或 WGSL 之一。节点来源使用原有节点画布；生成的 WGSL 只读。
WGSL 来源直接编辑源码，左侧管理参数名称、类型、范围、单位、默认值和稳定 ID。
窄窗口通过“公开参数 / WGSL”切换，不压缩两栏。

参数的访问函数由 `parameter_function(id)` 生成。例如 ID `amount` 对应
`param_amount()`；特殊字符按字节转义，不要用显示名称猜测函数名。
当前示例以 `plugin_fx(p: vec2<f32>) -> vec4<f32>` 为入口，通过 `sample_source(p)` 读取输入。
源码必须遵守现有宿主 shader ABI；不能新增任意资源绑定。

编辑暂停后自动检查，也可手动点击 **检查预览**。错误显示阶段、原始原因和可确定的行列；
点击 **定位源码** 返回错误。检查失败保留上一份有效 GPU 画面，因此“还能看到画面”
不等于当前草稿已通过。错误草稿仍然可以保存。

## 设置本机语言服务

1. 从 [wgsl-analyzer 官方发行页](https://github.com/wgsl-analyzer/wgsl-analyzer/releases)
   安装符合操作系统的可执行文件。本轮验证固定版本 `2026-09-30`；来源和 hash 见根目录 ATTRIBUTION.md。
2. 在启动编辑器的环境中设置路径，例如 PowerShell：

   ```powershell
   $env:MOTION_WGSL_ANALYZER = 'C:/Tools/wgsl-analyzer.exe'
   ./motion-studio.exe --plugin-editor ./my-plugin.msplugin --locale zh
   ```

3. 打开逻辑页，确认 **WGSL 语言服务已连接**。
4. 在源码中把光标放到符号处：**Ctrl+Space** 请求补全，↑/↓ 选择，Enter/Tab 或点击结果插入；
   Esc 先关闭建议。**符号说明** 读取光标处的类型/说明；**F12 / 转到定义** 定位作者源码中的定义。
   宿主和参数辅助函数显示只读声明。语言诊断列表可点击定位。
   注意：固定验收版 wgsl-analyzer 的 hover 实现仍返回空值，编辑器会明确显示无说明，
   不能将“符号说明”按钮视为已经具备类型悬停；请用定义定位查看声明。

语言服务收到包含真实宿主声明和公开参数辅助函数的虚拟文档；不在磁盘写临时 shader。
LSP 的 UTF-16 位置会映射到原生编辑器的 UTF-8 源码。过期回复不改写较新草稿；
无法安全应用的片段或附加编辑会明确拒绝。最终是否可运行由项目 Naga/GPU 校验决定。

未设置路径时属于正常未启用状态，不是假装已连接。配置错误、进程退出或协议错误会显示失败原因；
源码和原有编译预览可继续使用。本轮不提供自动下载安装或静默重启。
当前提供的是显式补全/符号说明/定义和诊断，尚未实现自动悬停弹层、重命名、格式化、
代码操作或片段占位符编辑；不要将它们误写成已实现的能力。

## 撤销、取消和关闭

- 一次布局拖动是一条作者撤销。按 Esc、失焦或改变窗口尺寸取消当前拖动。
- 正在输入源码时 Ctrl+Z 使用文本历史；离开文本后，源码提交进节点/布局/参数共用的作者历史。
- 交互预览的示例值有独立历史，不与作者工程同时撤销。
- 文件名后的 `*` 表示有未保存内容。关闭时可选择保存、放弃或继续编辑；保存失败保留草稿。
- 语言服务的卡住请求会保留阶段与耗时；关闭该编辑会话时清理子进程。没有自动超时重启。

当前仍是独立示例环境；主软件实例连接属于 M4，资源管理和安装包发布属于后续阶段。
