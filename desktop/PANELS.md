# 桌面面板与共享编辑状态

桌面端的停靠面板与原生浮窗调用同一个 `panels::render_panel`。面板读取工程快照、产生 `Action`，Shell 通过 Engine 工作线程调用共享编辑命令；面板不创建 Session、GPU Device 或独立工程历史。

## 组件边界

| 目录 | 职责 |
| --- | --- |
| `app/src/panels/` | 项目、合成、时间轴、属性、效果、曲线、路径、蒙版、音频等面板、内联表达式编辑与工具栏 |
| `app/src/node_editor/view/` | 节点画布、连线交互、节点库、属性、工具栏；复用同一个 NodeEditor 文档与撤销栈 |
| `app/src/shell/` | 动作分发、窗口与呈现、节点异步任务、媒体任务、退出保护、原生验收 |
| `app/src/engine.rs` | 唯一 Session/GPU 工作线程与调用桥接 |
| `app/src/workspace.rs` | 停靠树、隐藏面板、浮窗归属、浮窗尺寸与位置、工作区保存 |
| `ui/src/dock.rs` | 稳定面板 ID、双语标题、注册表、默认布局 |
| `ui/src/theme.rs` | 灰黑色板、强调色与紧凑尺寸 |

`ProjectState`、`PropertiesState`、`TimelineState` 保存各面板自己的搜索、滚动和交互状态。工程选择、播放时钟及共享编辑器保持联动。拖动数值、图层片段、曲线或路径继续使用原来的 begin/commit/cancel 事务；面板切换和失焦会取消尚未提交的交互。

## 面板与当前能力

- 项目、合成、时间轴：打开、保存、导入、选择、图层创建、播放、拖动、裁剪、关键帧显示
- 属性：2D/3D 开关、父子级、摄影机模式与属性、数值输入与拖动
- 效果和预设、效果控制：共享包目录、搜索、添加、参数编辑与动画
- 曲线：独立 XYZ、关键帧、进度/速度曲线、二次/三次贝塞尔、弹性、复制和粘贴
- 时间轴值曲线：Shift+F3 同面板切换片段和属性值曲线，沿用时间尺与左侧图层/属性列表；P/S/R/T 与 U 筛选，明确选中关键帧后进行缓动和删除
- 路径与钢笔、蒙版：共享投影与路径编辑状态，路径转化、蒙版参数和画布操作
- 音频、对齐：已有共享命令的入口，修改可撤销
- 表达式：在对应属性下内联编辑，默认收起；右键属性或 Alt+秒表展开，启用开关保留源码并可撤销，旧独立面板 ID 9 迁移到属性
- 节点编辑器、节点属性、节点预览：同一节点文档、异步校验/编译/导出、16 个可编辑源图示例、GPU 实时预览
- 信息、预览控制、素材浏览器：实际快照信息、播放与质量控制、已导入素材列表
- 字符、段落：显示已有文字及字体信息、复用系统字体/导入字体的文字创建流程；尚无独立的段落样式模型与文字重排命令
- 渲染队列：提供当前导出状态、PNG/工程包与可选 MP4 导出及取消；尚未提供持久化多任务队列

## 工作区与浮窗

窗口菜单列出所有注册面板。面板标题可拖动到另一面板中央成为标签页，或拖到边缘形成分割；拖到工作区外或点击 `↗` 可创建原生浮窗。`×` 隐藏停靠面板，窗口菜单可重新打开；关闭原生浮窗会重新停靠。

布局使用 `desktop-layout-v2.json`。原来的 `desktop-layout.json` 保留。浮窗恢复时只使用仍在已连接显示器范围内的位置；工程与节点文档不随面板关闭而删除。

## 验收

```sh
cargo test -p motion-desktop -p motion-ui --locked -- --test-threads=1
python tools/ci_desktop.py --binary target/debug/motion-studio --output artifacts/desktop
motion-studio --panels-smoke artifacts/desktop/panels-zh.json --locale zh
```

`--panels-smoke` 逐个创建注册面板的真实原生浮窗，等待实际呈现、保存截图并重新停靠，检查归属和工程版本。常规验收还覆盖两种语言、共享 MCP 会话、节点动态像素变化与错误保留旧预览。

## 交互反馈与耗时诊断

数值在按下时保留显示，水平移动超过 3 个逻辑像素后开始拖动事务；只有松开且未拖动的点击才进入文本输入。输入层保留一次手势中的最大位移，避免低帧率下“拖出又拖回”被误判为点击。Escape 和窗口失焦取消数值拖动，提交仍是一个撤销步骤。

时间轴、属性与历史操作通过工作线程异步回复，按原顺序执行。连续待执行的绝对定位只保留最后一次；编辑、保存、撤销和事务边界隔开定位合并。面板分隔线悬停与数值变化使用短暂高亮，时间指示器在直接拖动和播放时直接跟随，动画结束后停止主动刷新。时长由样式表中的 `motion.*_ms` 设置，不改变工程采样或导出。

界面刷新复用最近一次成功的合成纹理。工程版本、视图、帧、窗口、画幅尺寸和质量变化会失效；其他引擎操作也保守失效，压力降级保留的旧帧不进入此缓存。该优化只复用当前画面，没有实现跨帧缓存或节点缓存。

实时窗口的 MCP `motion_state` 返回 `desktop.uiPerformance`：`compositionRenders`、`compositionReuses` 和 `lastPresentUs`。超过 16 ms 的同步等待及超过 30 ms 的呈现写入标准错误的 `[motion-timing]` 记录。原生验收中的 `retainedUiProbe` 实测九次相同画面的刷新，要求一次合成和八次复用，并记录工作线程往返耗时。

## 数值曲线节点的后续接口

建议添加数值重映射节点：输入数值 `x`，输出用户绘制的 `f(x)`。曲线可用于亮度、深度、位移、动画强度等数值流。节点保存输入/输出范围与曲线数据，面板编辑可撤销、可复制；公开参数与编译器负责导出 `.msfx`。

时间轴的速度曲线需要积分得到进度，不能直接当成数值重映射。共享现有曲线数据、编辑控件和求值方法时应保留这一区别，并验证 CPU 与 WGSL 采样一致。本次没有新增该节点算法或宣称它已支持导出。
