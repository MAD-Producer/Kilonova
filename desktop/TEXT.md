# 字符与段落编辑

选择文字图层，在“字符”和“段落”面板编辑同一份草稿。

- 字符：字体、字号、行距、字距、外描边和多行文字。
- 段落：文字框宽度、左／中／右对齐、左右缩进和首行缩进。
- “应用”在引擎工作线程重排文字并预检资源，成功后一次替换文字、字体、样式和栅格资源。连续修改草稿只生成一次工程撤销记录。
- “取消草稿”重新读取当前图层。数值输入的 Escape 取消当前字段，文字框内的撤销／重做只影响草稿；工程撤销在草稿输入结束后生效。
- 文字框中 Enter 换行，Ctrl+Enter 结束文字输入。输入法组合期间不提交。
- 切换原生窗口时结束当前字段的输入状态，保留文字和排版草稿，不自动应用。

字号、行距、字距、宽度和缩进均以源图层像素为单位，独立于窗口 DPI。行距 0 表示使用字体的自动行距。外描边沿用文字填色，使用方角；当前没有独立描边颜色。填色沿用已有颜色弹窗和独立撤销事务；有未应用的排版草稿时，先应用或取消草稿再修改填色。

字体菜单列出工程已登记字体和内置 IBM Plex Mono；“选择字体文件…”支持 TTF、OTF、TTC。字体集合可输入从 0 开始的字体索引。中文需要自行选择具备中文字形的字体。内置字体不提供中文字形，应用失败时保留原文字、字体、样式及历史，并在面板显示原因。

应用期间停止播放；窗口事件线程继续接收输入，布局任务使用既有引擎工作线程和请求观测，不在绘制函数里读取字体或生成图片。一次只提交一个任务。工程、合成、修订或选择改变时，过期草稿不能写入新上下文；取消后重新载入。

## 数据与宿主接口

工程版本为 27，仅接受当前版本。`Content::Text` 的 `style` 是必填数据，不提供旧工程迁移。

`TextStyle` 保存 `font_size`、`width`、`line_height`（`null` 表示自动）、`tracking`、`alignment`（`left` / `center` / `right`）、`indent_left`、`indent_right`、`indent_first`、`stroke_width`。

`font_text` 可传 `style` 生成可复用栅格；提供 `style` 时，以其中的字号和宽度为准。省略 `style` 的既有接口保留原行为。

`font_edit_text` 请求包含 `object`、当前 `revision`、`text`、`font`、`style`；可附加 `font_path` 和 `face_index` 选择新字体。当前修订不符返回 `cancelled: true`，不会部分提交。桌面端额外使用工程路径、文档世代和合成身份约束请求。

字号范围 4–256，宽度 1–8192；自定义行距 4–1024，字距 -256–256，描边 0–32。缩进必须有限且留下可写宽度；每次最多 4096 个字符，栅格受既有 8192 边长和 16MP 内存上限约束。字体导入、字形缺失、重排和资源预检失败都保留原工程内容。

排版沿用既有从左到右逐字形、字偶距及换行能力；本改动没有新增复杂文字塑形、双向文字、可变字体轴、字重合成或两端对齐。无额外样式的文字继续使用既有栅格实现，避免改变已有像素语义。
