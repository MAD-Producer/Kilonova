# Motion Studio 桌面快捷键与接入规划

开发起点为 `origin/main` 的 `c0f1253`，提交前已合并主分支 `9f3094d`。实现分支：`codex/desktop-shortcuts-20261011`，跟踪 [issue #107](https://github.com/MAD-Producer/motion-studio/issues/107)。

## 当前已实现

时间轴关键帧菱形或值曲线关键帧可单击选择；选中关键帧后 Delete/Backspace 只删该关键帧。曲线模式没有选中关键帧时不会回退为删除图层。F9 操作转换为进度贝塞尔插值，按选中点的入段、出段分别设置水平手柄；当前命令不能编辑合成零帧之前的区间，此时保留原数据并提示。值曲线使用模型采样器及图层本地时间映射，显示属性原始值；表达式和约束后的结果未叠加到此图。

节点主体用于选择，标题栏用于拖动，右上角箭头折叠/展开。连线悬停使用实际提交的类型、单位、循环和预算校验，非法预览显示红线与原因；无效重接保留原连接。临时预览不修改文档、撤销栈或导出输出。节点组的保存和导出使用完整根图；折叠节点保留连线，但隐藏可编辑端口。当前图模型只允许一个 Color Output；包含它的节点或节点组复制会提示错误并保持原图。未接入的工具模式、其余关键帧扩展、贴图链和快捷键改键继续记录在 issue 中。

## 完整键位规划

下面保留原提案的规划状态，当前可用行为以“当前已实现”表及 `app/src/shortcuts.rs` 为准。

默认方案面向 Windows，常用工具、属性和时间轴操作参考专业合成软件的通用习惯，节点区沿用 Motion Studio 的现有工作流。工具激活和创建图层是不同操作。

状态：**保留**＝当前代码已有明确绑定；**改绑**＝已有功能调整默认键位；**新增**＝需补快捷键路由；**后续**＝还需要补工具模式、选择模型或操作入口。保留项仍需统一焦点和修饰键处理。

### FX Console 效果搜索浮层

Ctrl+空格调用紧凑的效果搜索浮层，定位在鼠标附近并避让窗口边缘；不切换现有工作区或强制打开完整效果库面板。打开后直接聚焦搜索输入，沿用深灰界面、微软雅黑、现代搜索图标与克制的边框。

| 输入 | 操作 |
| --- | --- |
| Ctrl+空格 | 打开浮层；已打开时关闭并恢复原焦点 |
| 键入中文 / 英文 | 即时搜索效果名称、英文名称、ID、分类与来源 |
| ↑ / ↓ | 选择上一 / 下一结果，超出可见范围自动滚动 |
| Enter / 左键结果 | 添加所选效果到当前可编辑图层，成功后关闭 |
| Esc / 点击浮层外 | 关闭浮层，不应用效果；关闭点击由浮层消费 |
| Ctrl+A / Ctrl+C / Ctrl+V | 搜索输入内的选择、复制与粘贴，由输入控件处理 |

- 结果显示效果名称以及分类/来源；无搜索词时优先展示最近使用或常用项。效果数据、应用命令、版本与 hash 复用效果库目录。
- 浮层显示目标图层名称。无有效目标或图层锁定时仍能搜索，但禁用应用并提示选择可编辑图层；应用失败保留搜索与反馈，不能显示为已添加。
- 区分目录加载中、加载失败、没有匹配结果和目标不可编辑；中文界面也能按完整英文名称搜索。
- Ctrl+空格按应用级浮层命令路由，节点画布聚焦时也可打开；应用目标仍是工程图层。Shift+A 继续负责节点添加菜单。
- 文本编辑、输入法组合和模态对话框先按焦点规则处理；按住 Ctrl+空格不反复开关。开关浮层不会触发空格播放。
- 回车与重复按键只应用一次，编辑进入同一工程历史；后续多选图层应用需要明确的批量事务。

当前 `app/src/panels/fx_console.rs` 已支持鼠标附近浮层、再次 Ctrl+空格关闭、跨面板焦点路由、中英文与分类搜索、输入框编辑、↑↓、Enter 应用、Esc/外部点击关闭和目标锁定检查。最近使用排序及进一步的目录加载、应用失败反馈仍属后续规划。

## 接入规则

1. 优先级为弹层、文本/数值输入、当前面板、应用命令；同一次按键只能执行一个动作。
2. 保存当前文档时先提交有效输入；非法输入保留错误反馈，不保存未提交的旧值。Escape 取消当前事务。
3. Delete、复制粘贴和撤销始终作用于当前选择所属的编辑器；文本编辑不得删除图层或节点。
4. Ctrl、Alt、Shift 精确匹配，不能因为当前代码忽略 Alt 而把误触视为兼容键位。
5. 对逐帧、微移和滚动允许重复；新建、复制、删除、播放切换、撤销和重做不因系统自动重复连续触发。
6. 工具临时切换需要 KeyReleased 与保持状态；主键盘和小键盘分开识别；输入法组合期间不运行单字母编辑命令。
7. 菜单、工具提示和快捷键设置读取同一个命令目录；后续支持改键、冲突检测、重置与预设。
8. 所有编辑继续使用现有 begin/commit/cancel 与同一文档历史，快捷键不绕开权限、有效选择或操作状态检查。
