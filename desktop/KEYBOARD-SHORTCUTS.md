# Motion Studio 桌面快捷键与接入规划

本文区分当前行为与尚未接入的规划。完整解析目录见 [默认键位参考](DEFAULT-KEY-BINDINGS.md)，由 `shortcuts::documentation_tests` 与真实解析器核对；面板路由另由主窗/浮窗交互测试守护。

## 当前已实现

时间轴关键帧菱形或值曲线关键帧可单击选择；选中关键帧后 Delete/Backspace 只删该关键帧。曲线模式没有选中关键帧时不会回退为删除图层。F9 操作转换为进度贝塞尔插值，按选中点的入段、出段分别设置水平手柄；当前命令不能编辑合成零帧之前的区间，此时保留原数据并提示。值曲线使用模型采样器及图层本地时间映射，显示属性原始值；表达式和约束后的结果未叠加到此图。

节点主体用于选择，标题栏用于拖动，右上角箭头折叠/展开。连线悬停使用实际提交的类型、单位、循环和预算校验，非法预览显示红线与原因；无效重接保留原连接。临时预览不修改文档、撤销栈或导出输出。节点组的保存和导出使用完整根图；折叠节点保留连线，但隐藏可编辑端口。当前图模型只允许一个 Color Output；包含它的节点或节点组复制会提示错误并保持原图。未接入的工具模式、其余关键帧扩展、贴图链和快捷键改键继续记录在 issue 中。

## 节点焦点下的应用命令

主窗和原生浮窗规则相同；文本输入、输入法、弹层和正在进行的节点手势优先。

| 命令 | 节点上下文规则 |
| --- | --- |
| Space | 三个节点面板均切换共享节点预览，仅触发一次 |
| Ctrl+O/S/Shift+S | 打开/保存/另存节点文档，先提交有效节点字段 |
| Ctrl+Z/Shift+Z、Ctrl+D、Delete/Backspace | 保留节点文档语义，不回退编辑工程图层 |
| Ctrl+Alt+N、Ctrl+N、Ctrl+I/K、Ctrl+Y、创建文字/空对象/调整图层 | 允许对应的工程操作 |
| Ctrl+Alt+M | 允许导出工程视频；缺少 FFmpeg 时不执行，并保留既有告警 |
| PageUp/Down、Ctrl+左右、End | 导航工程时间；导航接受系统重复 |
| Home、普通方向键 | 保留节点适配/微移语义，不导航工程时间 |
| Ctrl+Shift+D | 节点上下文屏蔽图层分割；返回时间轴操作 |
| Ctrl+Space | 应用级效果搜索，目标仍是工程图层 |

## 接入规则

1. 弹层、文本/数值输入、当前面板、应用命令依次取得输入；同一按键执行一个动作。
2. 复制、删除和撤销使用当前文档与选择；空选择不会回退到另一个编辑器。
3. Ctrl、Alt、Shift 精确匹配；播放、复制和编辑类动作忽略系统重复。IME 组合及确认帧不触发快捷键。
4. 连续数值与指针编辑继续使用 begin/commit/cancel，取消不写历史。
5. 样式调试 `Ctrl+R` 重载已选择的覆盖文件，主窗和浮窗同步，失败保留当前样式。

路径钢笔在放置新点时可按 Alt 只移动出手柄；松开 Alt 恢复对称。再次按 Alt 保留当前入手柄。释放鼠标结束本点放置，点击首点闭合；Esc 取消草稿，不修改工程。

表达式在时间轴/属性/效果参数下内联编辑，默认收起。右键属性选择“编辑表达式”，或 Alt+点击属性前的秒表，展开源码和启用复选框；Enter 提交，Esc 或关闭按钮丢弃未提交草稿并收起。关闭编辑区不删除表达式，移除使用单独的右键命令。停用保留源码、目标、seed 和 profile；应用编辑不自动重新启用。非法源码重新启用失败时保持原状态，仍可修改后再应用。

## 合成查看器导航

- 滚轮 / Ctrl+滚轮：以鼠标位置缩放画布；中键拖动：平移画布。
- 左下倍率：单击输入百分比或拖动调整；“适合 / Fit”恢复自动适配窗口。
- Esc 或失焦：取消尚未结束的平移/倍率拖动；这些视图操作不写工程或撤销历史。
- 右键拖动保留观察操作；观察视图中 Alt+滚轮调整观察摄影机缩放。Space 保持原有播放语义，输入倍率时由字段取得键盘输入。
