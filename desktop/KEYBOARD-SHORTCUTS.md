# Motion Studio 桌面快捷键与接入规划

本文区分当前行为与尚未接入的规划。完整解析目录见 [默认键位参考](DEFAULT-KEY-BINDINGS.md)，由 `shortcuts::documentation_tests` 与真实解析器核对；面板路由另由主窗/浮窗交互测试守护。

## 当前已实现

主窗与原生浮窗共用键位解析。Ctrl、Shift、Alt 精确匹配；文本输入、输入法组合和弹层优先。系统自动重复用于逐帧、关键帧导航、图层选择、节点微移及输入框编辑；批量图层排列不响应重复。节点文件操作会先提交有效字段；工程数值编辑期间需先用 Enter 提交字段。

编辑 → 偏好设置 → 快捷键可按应用、动画、节点和查看器工具作用域改键。下表列出默认值；改键后以设置页和菜单中的实际提示为准。录入、解除绑定、恢复命令默认值、导入预设与重置只修改草稿；点击应用立即更新所有窗口，无需重启，取消保留原配置。页面支持撤销/重做改键（Ctrl+Z / Ctrl+Shift+Z），不写工程历史。预设是带版本的 JSON；冲突、系统/文本保留键或非法文件会明确拒绝并保留已有配置。导出保存当前草稿，可在应用前备份。

此页列出当前命令解析器中有默认键位的动作。Escape、Enter、文本字段光标移动、效果搜索 Ctrl+Space / Ctrl+Alt+Space 及鼠标手势继续由原控件处理；不把这些结构性交互作为可改键动作。节点字段编辑时保留已有 Ctrl 文档操作提交规则；不带 Ctrl 的自定义字母键优先用于文本输入。Shift 在逐帧、节点微移和属性显示命令中保留其步长/追加语义。

使用原生 `TextEditor` 的字段另有应用内文本缓存：Ctrl+C/X 复制/剪切所选文本，Ctrl+V 在字素光标处粘贴；值字段初次编辑或 Ctrl+A 选择整个字段，时间轴搜索与效果搜索从现有查询末尾继续输入。文本与图层、关键帧、节点缓存相互独立，主窗和浮窗共用，切换工程后仍保留；此缓存不接入操作系统剪贴板。文本草稿的 Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y）只撤销/重做字段编辑，一次剪切或粘贴对应一步；提交字段后继续使用工程撤销。缓存内容及每个草稿历史栈分别限 16 MiB，历史每栈至多 128 步；超限明确拒绝，不截断正文。

属性数值、蒙版数值、节点检查器字段及节点卡片的向量输入，以及文字／合成设置／新建合成对话框也使用上述文本草稿操作。数值拖动仍保留原有阈值、范围与单次事务；Enter 或原有提交动作才修改文档，对话框取消不修改工程。合成时长在活动编辑字段中使用原始帧数，非活动字段继续显示时间码。节点字段的复制、剪切、粘贴和草稿撤销不会操作节点子图；Open／Save／Save As 仍先提交有效字段。

主窗活动文本字段打开“编辑”菜单时，菜单提供文本撤销、重做、复制、剪切、粘贴及全选；仅作用于打开菜单时的同一草稿，不操作图层或关键帧。打开／关闭菜单不提交字段，Escape 只关闭菜单，随后仍可继续编辑；切换其他菜单沿用原来的字段提交规则。草稿、工程、修订或面板失效后菜单禁用，不转移到新字段。文字输入使用保留的 Ctrl 键位，不随工程快捷键改绑；原生浮窗继续使用这些键位，模态对话框不开放主窗菜单。路径独立剪贴板及完整系统事件／打包验收仍待完成，不能据此宣称 #204 已完整完成。

时间轴关键帧菱形或值曲线关键帧可单击选择；选中关键帧后 Delete/Backspace 只删该关键帧。曲线模式没有选中关键帧时不会回退为删除图层。F9 操作转换为进度贝塞尔插值，按选中点的入段、出段分别设置水平手柄；当前命令不能编辑合成零帧之前的区间，此时保留原数据并提示。值曲线使用模型采样器及图层本地时间映射，显示属性原始值；表达式和约束后的结果未叠加到此图。

节点主体用于选择，标题栏用于拖动，右上角箭头折叠/展开。连线悬停使用实际提交的类型、单位、循环和预算校验，非法预览显示红线与原因；无效重接保留原连接。临时预览不修改文档、撤销栈或导出输出。节点组的保存和导出使用完整根图；折叠节点保留连线，但隐藏可编辑端口。当前图模型只允许一个 Color Output；Ctrl+D 包含它时会拒绝创建副本。Ctrl+C/X 可缓存输出子图，但粘贴到已有输出的图会明确拒绝；粘贴到空图可恢复完整输出。剪贴板仅包含选区内部连线，外部连线不自动重接；公开参数及递归组接口重新生成 ID。Image 节点使用目标图的输入图像，不迁移外部文件资产；工作色彩空间或 alpha 契约不一致时拒绝粘贴。其余关键帧扩展和贴图链接入继续记录在 issue 中。

版本 1 的已存键位和导入预设若已把新增图层命令的默认键位分配给其他命令，读取时保留原有显式映射，让冲突的新图层命令处于未绑定状态。交互改键与恢复默认仍严格检查冲突；新增命令可在偏好设置中另行绑定。无选中图层或主选被搜索隐藏时，向下导航从过滤结果顶部开始，向上从底部开始；虚拟旧摄影机行不参与图层范围选择，真实摄影机图层正常参与。

## Node canvas view preferences

The node toolbar's View menu and the canvas context menu expose checked grid and minimap options. The grid is initially visible; the minimap is initially hidden. G/N use no modifiers and do not repeat; Ctrl+G still groups nodes.

The minimap fits the current viewport and all nodes. Click or drag inside it to navigate; Esc, focus loss or a lost release cancels an unfinished drag. Small canvases hide the overlay until there is enough room. Both options are stored in the workspace layout, shared by docked and native floating editors, and retained when opening or switching graphs. They do not change graph source, compilation stamps, permanent output or undo history.

## 接入规则

1. 弹层、文本/数值输入、当前面板、应用命令依次取得输入；同一按键执行一个动作。
2. 复制、删除和撤销使用当前文档与选择；空选择不会回退到另一个编辑器。
3. Ctrl、Alt、Shift 精确匹配；播放、复制和编辑类动作忽略系统重复。IME 组合及确认帧不触发快捷键。
4. 连续数值与指针编辑继续使用 begin/commit/cancel，取消不写历史。
5. 样式调试 `Ctrl+R` 重载已选择的覆盖文件，主窗和浮窗同步，失败保留当前样式。

路径钢笔在放置新点时可按 Alt 只移动出手柄；松开 Alt 恢复对称。再次按 Alt 保留当前入手柄。释放鼠标结束本点放置，点击首点闭合；Esc 取消草稿，不修改工程。

编辑已有路径时，Shift/Ctrl+点选追加或切换节点；在空白处 Ctrl+拖动框选，Shift+拖动追加框选，Ctrl+Shift+拖动切换框内节点。拖动已选节点移动整组，拖动路径段移动两端锚点并保留相对手柄。Delete/Backspace 批量删除当前路径点；Esc、失焦或切换工程/合成取消正在进行的拖动。矩形等参数形状的角点继续调整宽高，不参与自由路径点框选。

表达式在时间轴/属性/效果参数下内联编辑，默认收起。右键属性选择“编辑表达式”，或 Alt+点击属性前的秒表，展开源码和启用复选框；Enter 提交，Esc 或关闭按钮丢弃未提交草稿并收起。关闭编辑区不删除表达式，移除使用单独的右键命令。停用保留源码、目标、seed 和 profile；应用编辑不自动重新启用。非法源码重新启用失败时保持原状态，仍可修改后再应用。

## 合成查看器导航

- 滚轮 / Ctrl+滚轮：以鼠标位置缩放画布；中键拖动：平移画布。
- 左下倍率：单击输入百分比或拖动调整；“适合 / Fit”恢复自动适配窗口。
- Esc 或失焦：取消尚未结束的平移/倍率拖动；这些视图操作不写工程或撤销历史。
- 右键拖动保留观察操作；观察视图中 Alt+滚轮调整观察摄影机缩放。Space 保持原有播放语义，输入倍率时由字段取得键盘输入。

### 查看器工具边界

工具栏的选择、钢笔、蒙版和变换入口与查看器工具快捷键共用激活转换；形状和文字按钮激活工具，图层菜单中的新建动作保持直接执行。当前 Q 组包含矩形 / 椭圆；其他内置形状仍由已有形状新建入口提供。文字工具复用现有设置对话框，不宣称画布内文本编辑或点击位置排版已经实现。

工具选择及查看器缩放、平移属于临时界面状态，不写工程格式。矩形和椭圆只在完整拖动释放后向宿主提交 AddShape，使用当前查看器映射得到源尺寸和中心；切换工程、合成、时间、映射、原生输入窗口或失焦时取消未提交绘制。后台窗口仅重绘不能抢走正在交互窗口的工具所有权。

查看器快捷键优先于该面板的属性显示快捷键；时间轴 / 属性面板和节点作用域保持各自原语义。工具提示显示实际生效的改键。中键平移和 Alt 缩小均为临时修饰，不改变当前选中工具；Space 继续用于原有播放切换。


查看器观察摄影机工具：C 在自由观察视图中循环环绕／平移／推拉，在顶视或侧视中循环平移／推拉；底部工具图标与提示反映实际模式。鼠标右键仍可临时环绕（顶视／侧视为平移），中键保持独立画布平移。拖动按画布源坐标归一化，在不同查看器倍率下保持一致；松开提交整轮手势，Esc、失焦、输入窗口／工程上下文变更取消。观察工具活动且查看器获得焦点时，撤销／重做、菜单和工具栏使用独立观察历史（最多 64 轮）；切换视图、播放帧或工程上下文后清空这份临时历史。观察操作不改工程脏标记、作者摄影机、工程撤销记录或导出；工程摄影机仍通过既有属性编辑。
新增查看器工具的默认键若与 Animation 显式改键重合，让位于显式改键，并从工具提示中隐藏；解除该显式改键后恢复默认。两个 Animation／Viewer 显式改键不能占用同一组合。
