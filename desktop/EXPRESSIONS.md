# 属性表达式与跨图层引用

在属性行右键选择“在多行编辑器中打开…”，或使用已有的表达式展开入口。
编辑器的链接图标可以拖到当前窗口中已经展开的属性行；右键菜单的
“插入属性引用…”也可以先进入拾取，再点击目标属性。释放后返回编辑器，
只替换当前选择或在光标处插入代码；检查后点击“应用”或按 Ctrl+Enter。
Esc、失焦、释放到空白处或丢失鼠标释放事件会取消拾取，保留草稿。
拾取限于发起它的原生窗口，不跨主窗和浮窗接管输入。

引用是可编辑的 `propertyValue(target, seconds = time)` 调用。例如：

```js
// 读取对象 8 当前合成时间的缩放；返回 [X, Y, Z]，单位为百分比。
propertyValue({kind: "property", object: "8", property: "scale"})

// 在当前时间前半秒读取对象 8 的位置 X，再加 20 像素。
propertyValue({kind: "property", object: "8", property: "position", axis: "x"}, time - 0.5) + 20

// 读取效果实例 17 的原生参数值；参数名取自该效果包定义。
propertyValue({kind: "effect", object: "8", effect: "17", param: "p0001"})
```

对象与效果 ID 必须是带引号的完整十进制字符串，不能换成 JavaScript
Number。重命名和图层重排不会改变引用；复制图层中的表达式仍指向原来的
明确 ID。参数名区分大小写，不能使用界面译名代替包内名称。

时间使用合成秒，包括负时间；宿主按被引用图层自己的偏移换算到局部轨道。
未提供第二个参数时读取当前合成时间，不使用引用方的局部时间。查询返回
目标自身表达式的结果；整向量查询合并活动的分轴表达式，分轴查询也可读取
整向量表达式的相应分量。不透明度返回 0–100 的百分比，效果参数沿用其
原生单位和范围。关闭效果会停用该效果参数的表达式，查询仍读取原参数轨道。

被引用表达式保留自身目标、上下文和随机种子；同一帧重复引用不会继承调用方
对全局对象或原型的修改。需要读取当前属性自身的原始动画时使用 `value`
或 `valueAtTime(seconds)`。通过 `propertyValue` 读取自身或建立间接循环，
包括把循环移到其他时间，都会被拒绝。

缺失目标、无效时间、循环、范围错误及预算耗尽返回原始原因；JavaScript
`try/catch` 不能把原生采样失败变成成功。应用失败保留原表达式和历史，
运行时失败也不改写存储的工程。删除引用目标不会自动替换表达式代码，
只有实际执行到失效调用时才报错。

执行仍使用同一个受限运行时：64 MiB 堆、512 KiB 栈、每个根表达式 20 ms、
整帧 100 ms。依赖调用共享根表达式的时限；单次帧/校验会话最多 16 层求值、
1024 次属性查询，下一会话重新计数。引用描述符最多 2048 字节，完整表达式
仍受 8192 字节上限约束。没有新增自动重试或工作线程重启。
