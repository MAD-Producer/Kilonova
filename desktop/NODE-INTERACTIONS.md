# 节点编辑器交互与快捷键

基线：`origin/main` 的 `c0f1253`，跟踪 [issue #107](https://github.com/MAD-Producer/motion-studio/issues/107)。

当前已实现：精确修饰键与输入优先级、Ctrl+滚轮、Home/F/Ctrl+0、方向键微移、全选/取消选择、Ctrl+D 子图复制、Delete/X、标题栏拖动、Shift+A 分类搜索与打开位置落点、Shift+= 分层排版、连线合法性预览、Alt+右键切线、显式右键菜单及 Ctrl+Shift+左键临时输出预览。主窗和原生浮窗使用同一文档、键位和撤销栈；节点属性、节点预览独立浮窗中的文件快捷键也指向节点文档。

下文同时包含后续交互约定。节点内控件、图像贴图链、节点组与折叠尚待实现。现有单输出模型禁止复制 Color Output，操作原子拒绝并提示，不留下部分副本。

输入来自用户提供的节点编辑器参考；键位与行为按 Motion Studio 的工作流采用。缩放按用户最后确认的 **Ctrl+滚轮** 执行。Blender / Node Wrangler 用于参考交互，不将它们的所有原生键位或材质模型声明为本项目现有能力。

## 1. 作用域与输入优先级

以下增强键位仅在节点画布聚焦、没有文本输入或模态菜单占用时生效。

命中顺序：弹层与内部控件 → 端口 → 折叠按钮 → 标题栏 → 节点主体 → 画布空白。

- Ctrl+T 在节点区建立贴图链，在合成区激活文字工具。
- Shift+A 在节点区打开添加菜单，在时间轴按属性展开规则处理。
- G、N、X 和方向键采用节点区的含义，编辑节点文字时仍为输入或光标操作。
- Ctrl+D 在节点区复制节点，在图层区复制图层；空选择不回退到另一个编辑器。
- Ctrl+空格调用应用级 FX Console 效果搜索浮层，显示当前工程目标图层；Shift+A 负责节点添加。FX Console 接管输入后节点删除、移动和画布快捷键暂停。
- 控件弹层、连线拖动、框选和节点移动拥有各自的指针捕获；同一按键或指针事件执行一个动作。

## 2. 画布视口

| 操作 | 默认输入 | 行为 |
| --- | --- | --- |
| 平移 | 中键拖动 | 移动视口，不修改节点位置或选择 |
| 备用平移 | Shift+中键拖动 | 同样平移 |
| 缩放 | Ctrl+滚轮 | 向上放大、向下缩小，鼠标位置对应的画布坐标保持不变 |
| 滚动 | 普通滚轮 | 保留画布滚动；不再把 Alt+滚轮作为默认缩放键 |
| 横向滚动 | Shift+滚轮 | 水平移动视口 |
| 全部适配 | Home | 平移并缩放，将全部节点完整放进可视区域，留出边距 |
| 选择适配 | F | 适配选中节点；无选择时适配全部 |
| 100% | Ctrl+0 | 恢复 100% 缩放，保持稳定视图锚点 |
| 节点微移 | 方向键 / Shift+方向键 | 移动选中节点 1 / 10 画布单位，不移动视口 |

缩放和平移使用当前画布矩形与屏幕/画布转换函数，不能把侧栏、标题栏或浮窗偏移算进节点坐标。Ctrl+滚轮在数值控件或弹层中先交给控件，不穿透到画布。缩放范围为 0.0001%～250%，全部适配最高 120%；最低值允许远距离布局完整入画，到达边界后鼠标锚点仍保持稳定。

普通滚轮规则按最后确认的 Ctrl+滚轮缩放方案确定，与用户原参考的直接滚轮缩放有所调整。

## 3. 节点选择和移动

- 左键节点主体单选。端口与内部控件点击不改动节点选择。
- 空白处左键按下并拖动形成框选；普通框选替换选择，Shift 框选追加选择。
- Shift+左键切换节点选中状态；再点取消。单击空白清空选择。
- 只有标题栏启动节点移动；主体用于选择，参数控件用于编辑。
- 拖动已选节点标题栏时先保留多选集，确认是拖动后所有选中节点使用同一画布位移。普通单击再落为单选，避免按下标题栏就丢失其余选择。
- 多节点移动保持相对位置；一次拖动只提交一次撤销记录。Escape 恢复操作开始前的位置；失焦和关闭画布也取消未提交手势。
- 节点微移按画布单位执行，不能因视口缩放而改变保存的位移量。

## 4. 复制、剪贴板与删除

| 输入 | 行为 |
| --- | --- |
| Ctrl+D | 复制选中节点，整体向右下偏移一个固定画布位移，选中新副本 |
| Ctrl+C / Ctrl+V | 复制节点片段；粘贴时在鼠标画布位置或可见视口位置建立副本 |
| Ctrl+X | 成功写入可粘贴片段后删除选中节点 |
| Delete / X | 删除全部选中节点，并清理所有接入与引出连线 |
| Backspace | 保留当前删除兼容键；文本编辑时仅删字符 |

节点片段只包含选中节点以及两端都在选中集合中的连线。复制生成新的节点 ID 并重映射内部端口引用；连接到外部节点的连线不复制。资源与公开参数引用保留现有引用关系，不重复导入文件或破坏公开参数槽位。

创建副本、连接和布局应组成一个事务；资源或数量约束失败时整体不提交。删除及剪切后清理无效选择、正在编辑的字段和临时预览目标。复制节点组时递归重映射内部节点，属于节点组支持的后续范围。

## 5. 添加节点与图像拖放

Shift+A 在鼠标位置打开分类添加菜单；菜单显示在窗口范围内，但创建落点保留打开菜单时的画布坐标，不能因为菜单避让屏幕边缘而改变落点。

- 分类采用本项目节点目录：输入、数学、矢量、颜色、图像/纹理、转换、输出以及后续材质分类。
- 选择菜单项，在记录的画布坐标创建节点；类型与公开参数沿用现有节点描述。
- 键入搜索、箭头选择、Enter 确认、Escape 取消由添加菜单处理；菜单打开期间不运行画布删除或移动快捷键。
- 图片从资源管理器拖进节点画布时，导入图像资源并创建图像纹理节点；导入工程的其他文件继续走对应文档流程。
- 创建节点前验证文件类型与资源结果；导入失败给出反馈，取消或失败不留半成品节点。多图拖入按结果提示并使用明确事务边界。

## 6. 连线

左侧为输入、右侧为输出。连线使用水平出入端口的三次贝塞尔曲线：控制点沿源端口向右、目标端口向左延伸，再根据两端距离调整弯曲程度。命中与切线使用同一条绘制曲线。

### 新建与替换

1. 输出端口左键拖动，显示橡皮筋预览线。
2. 悬停目标输入时，以本项目的值类型、端口语义和循环校验判断合法性；不能只按颜色判断。
3. 合法端口高亮；类型、单位或循环不合法时预览线变红并给出简短原因，松开不修改原图。
4. 释放到合法输入提交连线。一个输入最多一条线，已有线在成功提交时原子替换。
5. 输出支持一对多连接，不设置单输出口单线限制；现有整图节点/连线预算继续生效。
6. 新连线释放到空白处取消；Escape 取消整个拖动。

### 端点重接与断开

- 拖动已连接输入端点时，先保留原线作为可恢复状态。
- 释放到新的合法输入时重接；释放到空白处断开原连接；Escape 或非法目标恢复原连接。
- 当前未连接输入反向拖到输出的能力继续保留，使用同一校验和事务。
- Alt+右键划线时预览切线轨迹，松开后批量删除划过的连线，整次手势一个撤销步骤；Escape 取消。
- 单输出连接多条线时，“从输出端点向外拖”仍表示新建连接，不能隐式断开全部输出。断开特定线使用其输入端点或切线手势。
- 当前普通右键直接断线行为改为显式右键菜单，避免打开菜单时立即删除连接。

切线容差按屏幕像素计算，适配缩放；只处理实际画布中的连线。非法连接、超出预算或操作取消都保留原有输入连接，不能先删除旧线再发现新线不合法。

## 7. 节点内部控件

内部控件使用现有参数模型与编辑事务：颜色块打开拾色器，滑块/数值修改参数，下拉框选择合法枚举值。图像的 sRGB / Non-Color 选择须由资源与色彩空间实现支持，不能只添加不生效的下拉框。

点击或拖动控件不移动节点，控件捕获输入后不传播至画布。输入框内方向键、X、Delete、Backspace、Ctrl+A/C/X/V 按文本规则执行；Enter 提交，Escape 取消。连续拖动数值只提交一条撤销记录。

当前参数检查器已经有编辑流程；节点主体中的可交互滑块、颜色和下拉控件仍需增加独立命中区域。

## 8. 高频增强

| 输入 | Motion Studio 行为 | 接入范围 |
| --- | --- | --- |
| Ctrl+Shift+左键节点 | 临时预览点击节点的输出；再点同一预览目标恢复 | 新增预览目标路由 |
| Shift+= | 对选中节点按依赖关系从左到右分层排版 | 新增布局命令 |
| Ctrl+T | 添加 UV → 映射 → 图像纹理链并自动连接 | 图像资源、映射节点和目标端口支持后接入 |
| Ctrl+Shift+T | 从多张贴图建立材质贴图组 | 材质节点和色彩空间支持后的扩展 |
| Alt+右键划线 | 批量切断经过的连线 | 新增手势与批量命令 |

临时预览使用独立目标与预览版本，保留永久输出、图文档、文档版本和导出配置。单输出节点直接预览；多输出节点显示端口菜单，也可直接 Ctrl+Shift+点击输出端口。再点相同输出、点击永久输出节点或选择“恢复永久输出”返回完整图。预览面板标明节点与端口；快速切换时旧编译结果不能覆盖新目标。目标被删除或其端口失效时自动恢复完整图。

类型可视化采用明确转换：颜色保留 RGBA；浮点以 0～1 灰度显示；二维向量显示 RG，三维向量显示 RGB；布尔值显示黑/白；像素距离以零距离为中灰、按图层尺寸缩放；图像按当前像素坐标采样。只编译所选输出的依赖子图；当前 N1 校验、采样和资源预算继续生效。目标切换或编译失败时保留上一次有效图像，并显示状态与诊断。临时预览不生成永久重连的撤销记录，保存和导出仍校验完整图。

Shift+= 是本项目采用的“分层自动排版”动作。只移动选中节点，保留连线与外部节点位置；无选择时不自动移动全部图。节点间留出控件与连线空间，整次排版可撤销。

Ctrl+T 按现有 UV、图像采样及端口语义建立贴图链；用户参考中的 BSDF 完整材质流程需要材质节点配套能力后接入。未支持的目标节点禁用此操作并说明适用条件。

## 9. 节点组与折叠

| 输入 | 行为 |
| --- | --- |
| Ctrl+G | 将选中节点组成子图，并映射跨边界的输入/输出端口 |
| 双击组节点 / Tab | 进入子图 |
| Ctrl+Tab | 返回父图 |
| Alt+G | 解包选中组，恢复内部节点与外部连接 |
| 右上角折叠按钮 | 折叠 / 展开节点 |

节点组需要图模型、类型校验、编译/导出与编辑器导航共同支持。分组与解包保持输入、输出语义和运行结果；跨组连接及递归子图同样进行循环校验，整次操作可撤销。先补真实子图能力后启用快捷键。

折叠后只显示标题，隐藏控件和可点击端口；端口定义、参数和已有连接保留。已有连线汇聚到标题左右的不可编辑锚点，继续可视化；新建连接前先展开节点。折叠作为视图状态保存，不改变着色器语义。
