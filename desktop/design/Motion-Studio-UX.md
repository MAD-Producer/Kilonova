**用户模型**

- **主创作者**：熟悉 AE / Premiere 的动效设计师，追求快捷键驱动的连续操作
- **学习者**：用过剪映/CapCut 但没接触过节点与曲线，被专业术语劝退的高频用户

### 4.3 撤销 `【补】`

- 所有编辑操作入栈，栈深 **128 条或 32MB**（取先到者）
- 拖手柄 / 拖关键帧这类连续手势，**整段拖拽记为一步**（`begin_gesture` / `end_gesture` 包住）
- **手势进行中禁止撤销**（`undo()` 返回 `Error::Gesture`），松手后才生效
- 撤销粒度跨面板：时间轴、属性树、绘图区共享同一历史栈
- 面板停靠、工作区切换、视图缩放 **不入撤销栈**

### 4.4 拖放与停靠 `【稿】`（`5:5968`）

- 从面板头右侧 `⋮` 或工具栏拖出面板，产生**幽灵面板**（`5:6218`，保留标题栏 + 半透明内容）
- 幽灵面板头显示 `停靠` 与关闭按钮（`5:6222`、`5:6223`）
- 停靠目标高亮蓝色区域，提示文案：`拖到右侧蓝色区域：分割停靠效果控件`（`5:6217`）
- 松手后原位置留下分隔占位，被停靠面板以 **50/50 分割** 插入
- 落到主 dock 外 → 转为浮动窗口（§5.5）

**分割比例**：左右 50/50，上下按悬停的 1/3 带高亮。比例可用鼠标拖分隔条二次调整。

### 4.5 反馈原则 `【补】`

1. **操作提示常驻**：每个复杂面板底栏右侧有 `5:2566` 式的提示句，如 `拖动手柄调整缓动 · 滚轮缩放时间轴`。这是学习者的救命索，不要做成 tooltip。
2. **拖拽必出读数**：任何改变数值的拖拽，在指针附近弹出读数卡（§5.8.4）。
3. **破坏性操作二次确认**：删除图层、覆盖工程、清空关键帧需确认；单帧删除不确认。
4. **状态栏兜底**：`自动保存完成`（`5:4188`）常驻右下，任何长耗时操作在此显示进度。

##### C. 手柄的数学模型 `【补】`

单个关键帧 `K`（时间 `t`，值 `v`）的贝塞尔段由 `K` 及其出/入手柄控制：

```
控制点 P1 = K + L_out · (cos α_out, sin α_out)
控制点 P2 = K_next − L_in  · (cos α_in,  sin α_in)
```

- **角度 α** = 该端的**瞬时速率方向**。数值图表中 Y 轴向上为正 → α 向上表示值在增加。
- **长度 L** = 缓动"力度"。L 越大，两端越平缓（更像 ease-in-out）；L = 0 → 硬切换。
- **两侧链接时**（默认）：`α_in = α_out`，`L_in : L_out = t_in : t_out`（时间加权）。

**速度图表中的特殊性** `【补】`
速度图表里 Y 是速率本身，因此：
- 拖手柄**向上** = 该端速率增大 = 出点时"冲出去更快"
- 拖手柄到 **Y = 0** = 该端瞬时停止，表现为该关键帧变成"驻点"（画面在此刻完全静止），是制造"停顿感"的手法
- **L 在速度图表中不改变速率值**，只影响贝塞尔参数化（即该段用多少时间走完）——所以在速度图表里手柄的"长度感"是误导性的，这是必须写进帮助文档的一点

**典型预设的曲线形状**（供设计稿画参考图）

| 插值类型 | 数值图表 | 速度图表 |
|---------|---------|---------|
| 线性 | 直线，两端 α=0 | 水平直线 |
| 缓入 Ease In | 前平后陡（α_out 上扬） | 前低后高（上升段） |
| 缓出 Ease Out | 前陡后平 | 前高后低 |
| 缓入缓出 | S 形 | 中间高、两端 0 |
| 瞬间 Hold | 阶跃，右端 α=±90° | 阶跃 + 垂直线 |
| 自定义贝塞尔 | 手柄自由 | 手柄自由 |

##### D. 影响权重 `【稿+补】`

底栏常驻 `入点影响 33.3% · 出点影响 33.3%`（`5:2564`），属性树有 `入点影响` / `出点影响` 两个下拉字段（`5:2601`、`5:2606`，字段高 18）。

- 这是**时间权重 vs 速度权重**的分配比例，两者合计恒为 100%
- 33.3/33.3 是等分（手柄时间等分）；拖动手柄或按 `Ctrl` 锁定比例时实时重算
- 支持的档位 `【补】`：`10% / 25% / 33.3% / 50% / 66.7% / 75% / 90%`，或"自动"
- 该值**只在当前有选中关键帧时显示**，无选中时底栏显示 `未选中关键帧`

##### E. 插值类型 `【稿+补】`

属性树 `插值类型` 字段（`5:2596`）下拉枚举：

`线性` · `贝塞尔` · `缓入` · `缓出` · `瞬间` · `保持`

- **瞬间（Instant）**：跳变到下一帧值，图表上是垂直线段，无手柄
- **保持（Hold）**：在当前帧保持值直到下一帧，图表上是水平线段
- 选这两项时，手柄点与手柄连线**隐藏**（不可拖）
- 切换插值类型会重建曲线，**属于可撤销操作**
