## Ardot 原生界面落地

设计来源：`cocraft://localhost/file/735166999160131?node_id=0%3A1`，读取 2026-10-12 的主工作区、首页、合成设置、数值图表和节点画面。稿件只读，不修改设计源。

- 主工作区：24px 标题与菜单、32px 工具栏；项目／效果控制上下排列，合成居中，动画区贯穿左部；右侧属性、预览、效果库、字体按稿排列。共享布局支持拖动和浮窗。
- 首页：最近本地工程、搜索与新建／打开入口；工程记录来自真实打开的目录，不填入设计稿中的演示资源。
- 合成设置：640×510 对话框，名称、预设、尺寸与锁定比例、帧率、持续时间校验；持续时间支持帧数或时码。高级／3D 页仍为说明，未宣称完整后端设置。
- 工作区：默认、动画、节点、绘制、所有面板；独立保存各预设的停靠／浮窗状态；管理窗口设置 21 类面板可见性并保存命名布局。命名布局载入 UI 与覆盖提示仍待补齐。
- 效果库：分类、全部／收藏／最近页、紧凑效果行；保留真实插件目录、应用动作与持久化收藏。
- 合并时间轴图表：同一 `Panel::Timeline` 内点击“曲线编辑”或 Shift+F3 切换，标题保持时间轴；共享图层、关键帧、播放头与撤销栈，两种视图分别保留缩放／滚动。独立“曲线”面板仍是缓动参数工具，并非此入口。
- 动画图表：独立顶部工具栏，320px 图层／属性树展开到轴，所选轴使用真实值域；速度／数值观察、适配、底部时间刻度与播放头；绿色曲线、黄色关键帧和圆形手柄。图表网格可切换，片段轨道区继续不显示参考竖线。关键帧插值与影响百分比读取实际缓动。点击／拖动仍使用同一图层、通道、帧和核心撤销事务。

`--smoke` 的 `designScreens` 输出这些界面的真实 GPU 截图。设计验收不写入工程数据。多关键帧框选、多通道同时编辑、独立合成多实例，以及完整节点画面排布与媒体 S3 后端不由本批宣称完成。原快捷键 issue #107 的剩余清单不自动关闭。

后续曲线规格需要避免数学冲突：速度显示是值随时间的导数（帧导数乘 fps）；缓入缓出的速度通常为中间高、两端低；两端各 33.3% 的影响不意味着二者相加恒为 100%。Hold 的跳变处没有有限导数。不能为了模仿图形把速度直接当数值重映射，也不必为只读百分比换算修改工程格式。
